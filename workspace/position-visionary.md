# Product Visionary — 입장문 (Round 1)

## ① 쟁점별 입장

**쟁점1 (글 쓰는 유저 vs 읽고 반응하는 유저)**
목표는 "글쓰기"가 아니라 **반응의 축적**이다. 1-9-90은 자연 법칙이지만, 지금 gongnori는 90도 못 붙잡고 있다(소비 전환 1%). 콜드스타트는 진짜 문제지만 해법은 "글을 쓰게 강제"가 아니라 **반응 마찰을 0에 가깝게 낮추는 것** — 이모지 한 번, 픽 이유 한 줄. 그게 쌓이면 9(댓글)와 1(글)은 자연히 따라온다.

**쟁점2 (지금이 이른가)**
이르지 않다. 오히려 지금이 골든타임이다. 진성 유저 83명은 "이미 매일 앱을 여는 사람들"이다. 이들에게 필요한 건 새 유저 유입이 아니라 **이미 온 사람이 떠나지 않을 이유** 하나다. 규모가 작을 때 만든 습관 루프가 시즌 오픈 때 500→5000명에 그대로 복제된다. 지금 안 만들면 다음 이벤트도 같은 절벽을 반복한다.

**쟁점3 (봇 단신 뉴스의 역할)**
퇴출 대상이 아니라 **원재료다.** 문제는 뉴스 자체가 아니라 뉴스가 "읽고 끝"이라는 것. research.md의 Discord 아이스브레이커 패턴(#7)처럼, 뉴스 하단에 즉답 가능한 질문/이모지 반응 슬롯 하나만 붙이면 소비→반응 전환이 열린다. 양으로 채우는 게 문제지, 존재 자체는 자산이다.

**쟁점4 (1순위 가교)**
**b. 매치데이 앵커 스레드**를 1순위로 민다. 픽 분포(예측 100~200건/일이라는 이미 존재하는 활동)를 자동으로 콘텐츠화해서, 유저가 "내가 예측한 경기에 다른 사람들은 뭘 골랐지"를 보러 재방문하게 만든다. 글쓰기 요구 없이 소비만으로 루프 완성.

## ② 내가 미는 가교 설계

**1. 매치데이 앵커 스레드** — 경기 등록 시 자동 생성되는 게시글. 상단에 실시간 픽 분포 바(홈승/무/원정승 %, 예측자 수), 라이브 스코어 위젯 임베드, 경기 종료 후 결과+적중률 자동 갱신. 유저 행동(슬립 제출)이 자동으로 스레드에 반영 — "당신은 소수파입니다(23%)" 같은 코멘트 자동 삽입(research #4 사회적 증거 변형). 댓글창은 기본 열려있지만 강제 아님.

**2. 뉴스 이모지 즉답 슬롯 (research #7 변형)** — 봇 뉴스 카드 하단에 버튼 3~4개(예: "기대돼요🔥" "걱정되네요😰" "글쎄...🤔"). 클릭 = flair score +1, 클릭 즉시 집계 %가 보인다("이 팬 62%가 기대돼요 선택"). 로그인만 하면 원클릭, 텍스트 입력 없음 — 마찰 최소화된 반응.

## ③ 예상 공격 + 선제 방어

**예상 공격 (현실주의자/회의론자)**: "매치데이 앵커 스레드는 1인 개발 리소스 대비 과한 신규 시스템 아니냐. 경기당 자동 생성 로직 + 실시간 집계 + 결과 갱신은 사실상 새 서브시스템이다."

**선제 방어**: 이미 존재하는 인프라의 조합일 뿐이다 — betman 경기 데이터(2시간 sync), wisetoto 라이브스코어(매분), prediction_slips 집계 쿼리, posts 테이블. 새로 만드는 건 "경기 1건당 게시글 1개 자동 생성 + 집계 렌더" 하나뿐이고, vertical slice로 **픽 분포 바만 먼저** 배포하면 반나절 스코프다. 사행성 아님(집계는 정보이지 배팅 유인이 아님), 콘텐츠는 자동 한국어 템플릿.
