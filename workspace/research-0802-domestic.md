# 국내 스포츠 커뮤니티·예측 플랫폼 이벤트 상품 구조 리서치

## 조사 범위
- K리그 공식 승부예측 이벤트
- 스포츠토토 북중미 축구대회 프로모션
- SPOTV 스포 타임 베이스볼
- 다음 스포츠 비더레전드
- 기타 소규모 스포츠 팬 이벤트

## 패턴 목록

### 1. **계층식 경품 + 데일리 소액 추첨** (스포츠토토 북중미 축구대회 이벤트)
- **메커니즘**: 고가 상품권(10만원 5명) → 중가(5만원 10명) → 식품/카페(20~100명) 피라미드. 매일 승부예측 참여 자동 응모, 3일/5일/7일 연속 참여 시 상위 경품 상향.
- **왜 먹히나**: 누구나 최소 기프티콘 획득 가능성 (데일리 확률) + 연속 참여 리텐션 훅 (3일 구간 목표).
- **gongnori 각도**: 예산 200만원 규모에선 SK 상품권(50만) / 올리브영(50만) / 기프티콘 100여명(100만) 구성으로 적용 가능. 핵심은 "누구나 탈 확률" vs "일부 고가" 이원화.
- **출처**: https://sportstoto2026event.kr/

### 2. **스코어 정확도 기반 등급별 경품** (K리그 공식 승부예측)
- **메커니즘**: 11경기 100만원(상금 누적 이월) → 10경기 입장권 2매(추정 10~30명) → 9경기 스코어센터 쿠폰. 정확도 높을수록 상위 경품, 정답자 복수일 때 배분.
- **왜 먹히나**: 명확한 성과 기준(맞춘 경기 수) + 누적 상금 이월로 긴장감 유지. "거의 맞췄어도 뭔가 받는다" 심리.
- **gongnori 각도**: 정산/배당도 있는 환경에선 "우승 슬립" 한정 호칭(상금 대체 무형 보상) + 입장권 대신 "팀 경기장 기여도" 기념품 구성으로 변형.
- **출처**: https://www.kleague.com/news_view.do?seq=84775

### 3. **실시간 문자 참여 + 당일 치킨 기프티콘 추첨** (SPOTV 스포 타임 베이스볼)
- **메커니즘**: 매 경기마다 실시간 문자로 경기 예측 참여 → 추첨으로 치킨 기프티콘(5~10명 추정) 증정. 경기마다 새로운 기회, 참여 장벽 매우 낮음(문자 1건).
- **왜 먹히나**: 참여 마찰 극소화 + 즉시 결과 공개 + "다음 경기는?" 반복 루프. 방송 중계와 이벤트 동기화.
- **gongnori 각도**: 라이브 경기장(메타버스/미팅방) 활성 시 "경기 종료 15분 후 응원 코멘트 랜덤 추첨 기프티콘" 실시간 이벤트로 적용. 팬덤 활동과 경품 동시 추진.
- **출처**: https://www.spotv.net/news/news_detail.asp?idx=7183

### 4. **연속 정적중 누적 상금 풀** (다음 스포츠 비더레전드)
- **메커니즘**: 40경기 연속 안타 예측 성공 시 5천만원 풀(적중자 수만큼 배분). 고난이도 → 고상금 모델. 참여자는 수천 명일 수 있지만 상금 실제 수혜자는 극소수.
- **왜 먹히나**: 로또 심리 + "거의 갔는데 한 경기만 떨어짐" 좌절감 → 재참여. 누적 과정에서 커뮤니티 토론 활성화.
- **gongnori 각도**: 승률 높은 유저(호칭/레벨) 전용 "도전 미션" 누적 상금제로 변형. 예: 7일 연속 5승 이상 100명/5일 70명/3일 50명 누적 배분. 진입장벽(호칭)으로 예산 통제.
- **출처**: 검색 결과 (다음 스포츠 공식 미확인, 구체적 URL 미보유)

### 5. **소규모 카페·상점 협력 데일리 소액 추첨** (에크(Eek) 카페 월드컵 이벤트 사례)
- **메커니즘**: 경기 예측 정답자 중 추첨 → 1등 1명(2만원 이용권) + 2등 5명(음료). 참여 기준 단순(승패만 선택), 현장 이벤트 병행. 협력사 브랜딩 동시 강화.
- **왜 먹히나**: 소액이어도 즉시 사용 가능한 실물 + 시간 압박(당일 공개) + 장소 결합(오프라인 모임 유도).
- **gongnori 각도**: 오프라인 팬 이벤트나 온라인 커뮤니티 파트너십 시 "GS25 기프티콘 20명 / 메가커피 50명 / 유니폼 교환권(기존 굿즈) 5명" 같은 **친숙한 브랜드 기프티콘** 조합으로 예산 200만원 구간 달성 가능.
- **출처**: https://www.threads.com/@eek.cafe/post/DZuSLEFmXoq/

### 6. **통산 누적·스냅샷 리더보드 + 한정 호칭 + 현장 경기 입장권** (월드컵 이벤트 하이브리드)
- **메커니즘**: 월드컵 기간(3주) 누적 예측 기준 상위 10명 리더보드 공개(신분 보호) + 종료 후 TOP3만 공개. 호칭(예: 굿너/콥키드/블루스) 한정 해제 + 경기 입장권 현물 지급. 기간 한정의 절박감과 희소성 결합.
- **왜 먹히나**: "나도 혹시?" 심리의 지속 + TOP3 발표 순간의 카타르시스 + 호칭은 평생 자산(시즌 종료 후에도 유지).
- **gongnori 각도**: 시즌 중 3주 간 예측 누적 대회 형식. TOP 50 "리더보드 노출" + TOP 10 "한정 호칭 언락" + TOP 3 "유니폼/스팀카드 선택". 예산은 호칭·리더보드가 0원(무형), 상품권 + 기프티콘 100만원선.
- **출처**: 스포츠토토 + 월드컵 컨퍼런스 통합 (구체적 URL 미확인, 패턴 재구성)

### 7. **제한 요청 응모 + 이월 안함 쿠폰제** (스코어센터 K리그 쿠폰)
- **메커니즘**: 9경기 정적중 시 스코어센터 앱 3개월 이용권 쿠폰(추정 수십 명). 쿠폰은 이월 불가, 발급 시 즉시 활성화. 당첨자는 추첨 아닌 자격 기반(실제 달성자).
- **왜 먹히나**: 낮은 난이도 (9/11) → 그럼에도 불가능 (심리적 거리감 유지) + 쿠폰 즉시성 (배포 복잡도 낮음).
- **gongnori 각도**: 예측 커뮤니티 활동 기준 "7일 5개 댓글 이상 + 3경기 정적중" 시 "프리미엄 기능 1개월 무료" 쿠폰. 신규 멤버 온보딩 + 댓글 활성화 동시 달성. 경품비 0원(기존 서비스 연장).
- **출처**: https://www.kleague.com/news_view.do?seq=84775 (스코어센터 쿠폰 언급)

## 규모 대비 예산 비율 분석

### 스포츠토토 북중미 (대규모 이벤트)
**추정 참여자**: 수만 명  
**추정 총 경품비**: 400만원~  
**당첨자 분포**: 약 215명 (5+10+20+30+50+100)  
**당첨률**: 1~2% (수만 분의 215)  
**배분 특징**: 고가(5명) + 중가(10명) + 소액 추첨(150명)

### K리그 공식
**추정 참여자**: 수천 명  
**추정 총 경품비**: 150만원~ (상금 100만 + 입장권·쿠폰)  
**당첨자 분포**: ~100명 (11경기 1~5명 + 10경기 10~30명 + 9경기 30~50명)  
**당첨률**: 1~5%  
**배분 특징**: 명확한 성과 기준 (경기 수)

### 소규모 팬 커뮤니티 (gongnori 규모)
**추정 참여자**: 500~1,000명 (신규 유입 + 기존)  
**예산 목표**: 200만원  
**권장 당첨자**: 150~250명  
**당첨률**: 15~30% (높아야 활성화 유인)  
**권장 배분**: 
- 상품권 고가(5~10만원): 5~10명 (50~100만원)
- 기프티콘 중가(5~15만원): 30~50명 (50~75만원)
- 카페/편의점 소액(3~10만원): 80~150명 (50~75만원)
- 무형(호칭/쿠폰): 전원 (0원)

## 미확인 항목

- **정확한 참여자 수 데이터**: 대부분의 플랫폼이 공개하지 않음. 추정만 가능.
- **팬캐스트 구체적 이벤트 사례**: 팬캐스트는 팬 커뮤니티 플랫폼이나 승부예측 이벤트 공개 정보 부족.
- **크블/케이베이스볼 리그 구체적 경품 구조**: 리그 공식 승부예측 이벤트 미발견. KBO 홈페이지 등록 여부 불명확.
- **네이버 스포츠 데일리 이벤트 상세 경품 구성**: 참여 방식(자동 응모) 외 구체적 경품 구조는 미확인.

## 핵심 패턴 5개 (gongnori 적용 순서)

1. **"누구나 탈" 심리**: 당첨률 15~30% 확보 → 낮은 난이도 예측 + 소액 데일리 추첨 (스포츠토토 패턴)
2. **명확한 성과 기준**: 경기 수/정적중 수로 등급화 → 복권이 아닌 "실력" 심리 (K리그 패턴)
3. **시간 압박 + 반복**: 당일 결과 공개 + "다음 경기는?" 루프 → 데일리 참여 유인 (SPOTV 패턴)
4. **무형+유형 혼합**: 호칭/쿠폰(0원) + 기프티콘(실물) 조합 → 예산 효율성 극대화 (월드컵 하이브리드)
5. **규모 제한으로 예산 통제**: 호칭/레벨 조건부 이벤트 → 전체가 아닌 활성 유저 집중 (다음 비더레전드 변형)
