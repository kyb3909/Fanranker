## 3. 반박 소명 문안 (심사관 제출용)

### A4 — 카카오 로그인 문서 선기재
> 이용약관 제4조 및 개인정보처리방침 제1항의 카카오 로그인 기재는 본 비즈앱 신청의 목적인 카카오 로그인 도입을 위한 선행 기재입니다. 카카오 로그인 동의항목 심사는 수집 항목과 목적이 개인정보처리방침에 기재되어 있을 것을 전제하므로, 도입 이전에 방침에 반영하는 것이 오히려 정합적 순서라고 판단했습니다. 오해 소지를 줄이기 위해 방침 문구를 "카카오 로그인 도입 시 제공받는 항목"으로 조건부 명시하도록 수정하였으며, 로그인 기능 활성화와 동시에 확정 문구로 갱신하겠습니다.

### R8 (부분 반박 — 배수 표시 구조)
> 지적하신 금전 프레임 어휘("수익률", "수익금")는 전부 점수 어휘("점수율", "획득 점수")로 교체했습니다. 다만 경기별 배수(×2.00) 표시 자체는 난이도에 따른 점수 가중치를 안내하는 게임 규칙 요소로, 무료 포인트의 획득 점수를 계산하는 데 필수적인 정보입니다. 배수 없이 "적중/미적중"만 제공하면 점수 산정 근거를 이용자에게 숨기게 됩니다. 화면 어디에도 금전 단위·환전 수단이 존재하지 않으며(약관 제6조의2), 표시 명칭도 "배당"이 아닌 "배점"으로 통일했습니다.

### R11 (소명 — 종료 이벤트)
> 지적하신 월드컵 이벤트 페이지는 2026년 7월 19일 종료된 1회성 이벤트의 안내·결과 페이지로, 현재 신규 참여가 불가능한 상태였습니다. 해당 이벤트는 경품 기준을 정비한 현행 약관 제6조의2(2026-07-29 개정) 시행 이전에 기획·종료된 것으로, 현행 약관과의 불일치를 인지하여 관련 페이지 전체를 비공개 처리했습니다. 이후 진행하는 모든 경품 이벤트는 약관 제6조의2 제3항에 따라 예측 성적과 무관한 서비스 이용 활동 기준 추첨으로만 운영합니다.

### R12 (부분 반박 — 프리미엄 구독)
> "프리미엄 예측 정보" 문구가 포함된 구독 상품은 서비스 화면 어디에도 노출되지 않는 미출시 상태입니다(구매 진입 UI 및 안내 페이지 부존재 — 저장소 전수 검색 기준 렌더 코드 0건). 골드 충전 화면 또한 실결제가 연결되지 않은 준비 화면이었으나, 오인 소지를 인정하여 화면 자체를 제거했습니다. 유료 결제와 승부 예측 기능은 상품 설계 차원에서 분리하며, 향후 유료 상품 출시 시 예측 관련 정보는 상품 구성에 포함하지 않겠습니다.

### R13 (부분 소명 — 확인 방식)
> 만 14세 이상 확인을 회원가입 1단계의 별도 필수 체크 항목으로 추가하여 미확인 시 가입이 불가능하도록 했습니다. 생년월일 수집은 개인정보 최소수집 원칙에 따라 도입하지 않았으며, 이는 연령 확인 체크 방식을 채택한 국내 주요 커뮤니티 서비스의 통상 관행과 동일합니다.
