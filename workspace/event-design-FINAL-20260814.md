# 구너스 레이스 — 최종 설계 스펙 (3인 토의 종합, 2026-08-14)

## 확정 명칭·카피 (구너 검수 P0 반영)

- 이벤트명: **구너스 레이스** ("건너스"는 오표기 — 전면 교체). 서브타이틀 병용: "레이스 포 14"
- 상품명: **앙리의 14번** — "경품/증정/당첨" 금지, **획득 어법** ("단 1장. 1명. 1위가 가져갑니다")
- 상품 연출: 단독 무대(다른 보상과 같은 표 금지), 실물 사진, **COA(정품 인증서) 문구는 본문 승격**
- 전 리그 프레이밍: **"리그는 38경기가 아니라 380경기다"** / "아스날은 심장으로, 나머지는 눈으로" ("자부심" 어휘 폐기)
- 타팀 팬: 자기선언 허용 + 카피로 뒤집기 ("타팀 팬도 참가할 수 있습니다. 다만 6주 뒤에도 타팀 팬일 수 있을지는 보장 못 합니다.")
- 톤: 물건이 셀수록 카피는 낮은 목소리 (느낌표·홈쇼핑 어휘 금지 — 사이트 드라이 톤과 일치)

## /season 개편 — 한 URL, 상태별 인라인 전환 (리다이렉트 금지)

- **S0 비로그인**: 세일즈 스프레드 — 다크 히어로(앙리의 14번 4:5 실물 스틸 + 박물관 플레이트 캡션 + COA 라인, ~440px) → 참가 방법 3단계 → 로그인 CTA. 3파전 잔재(팀 선택·팬덤 수사) 전량 제거.
- **S1 로그인·미신청**: 같은 세일즈 지면 + **원클릭 참가 버튼** (팀 선택 없음 — gooner 자동). ⚠️ `traffic_source: getAttribution()` 반드시 이식 (누락 시 귀속 소급 불가).
- **S2 신청 완료 = 레이스 허브**: 히어로가 ~110px 컴팩트 밴드로 접힘(참가자 신호). 우선순위: ①내 순위+변화Δ(localStorage 1단계) ②다음 행동 스트립(오늘 픽하러 가기) ③메인 매치+아스날 소식 2 ④지금 뜨는 글 ⑤TOP5. 모든 콘텐츠 링크 ref=event.
- **S3 종료 후**: 결과 화면 (1위 발표 — 월드컵 podium 방식 준용, 추후).
- 경기 없는 날 채움: 사가 티커 + 이적 마감(9/1) 카운트다운 상단, EPL 순위·라이벌 워치 위젯 (2차).

## 시스템 정리

- 등록 API `app/api/event/season/register`: z.enum → **["gooner"]** (페이지 개편과 같은 커밋).
- `/event/gunners-season` → **redirect /season** (허브 이원화 금지). standing-panel(TOP5+내순위)은 /season S2 로 이식하되 **computeRaceStanding 에 등록자 필터 추가** (event_registrations join — 신청자만 랭킹).
- 완료 모달 레이스 스트립 목적지: **/season?ref=pick** 으로 교체 (1줄 유지 — 기사 카드를 폴드 밖으로 밀지 말 것).
- `lib/event/gunners-season.ts`: title '구너스 레이스'로. 파일/슬러그 리네임은 안 함 (URL 유지, 표기만).
- 홈 배너(매치데이 밴드): 카피 유지 가능하되 "앙리의 14번" 어법 정렬 권장.
