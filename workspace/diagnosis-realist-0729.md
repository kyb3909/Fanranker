## Realist

### 데이터 진단

- **훅 루프에서 끊긴 고리**: 트리거는 있었다(유튜버 홍보, 7/1 전후 외부 트리거). 액션도 나왔다(등록 459명 중 300명이 최소 1건 슬립 제출 = 65%, 마찰이 낮다는 뜻). 보상도 구조적으로는 존재한다(배당 결과라는 변동 보상). **끊긴 곳은 "재트리거"와 "투자(investment)" 두 단계다**:
  - 투자 실패: 등록자 459명 중 글/댓글 1회라도 쓴 사람 1.5%(7명). 커뮤니티 레이어가 정체성/관계를 저장하는 장치로 전혀 작동하지 않았다 → 다음 방문을 부를 "자산"이 안 쌓임.
  - 재트리거 부재: 7/6 주 -72% 절벽과 종료 즉시 0명은, 이 유저들을 다시 불러들이는 자체 채널(알림/디코 메시지)이 그 시점에 실제로 발화했는지 데이터가 없다. "홍보 효과 자연 감쇠"는 그럴듯한 해석이지만, **재트리거를 시도했는데 실패한 것인지 애초에 시도가 없었던 것인지는 구분이 안 된 추정이다.**
  - 봇 뉴스 실측(52건/7일 → 조회 0.7, 댓글 0)은 이 진단을 다른 각도에서 재확인한다: 커뮤니티 보드 자체가 "반응이 안 붙는 공간"이라는 게 이벤트 데이터와 별개로 독립 검증됐다. 즉 새 이벤트의 "커뮤니티 활동 3회 필수" 게이트를 지금 그대로 얹으면, 유저는 요건을 채우기 위해 글/댓글을 쓰겠지만 그게 **또 조회 0.7·댓글 0짜리 죽은 액션**이 될 위험이 크다 — 게이트 자체는 채워지는데 훅 루프의 "투자" 단계는 여전히 공허할 수 있다.

- **진단 완성을 위해 측정해야 할 것**:
  1. 7/6 주 절벽 코호트에게 그 시점에 재방문 유도(디스코드/알림/이메일)가 실제로 발화됐는지 로그 확인 — 없었다면 "감쇠"가 아니라 "방치"다.
  2. 디스코드 다이제스트의 클릭→로그인→행동 전환율. 이미 있는 채널인데 이게 재트리거로 기능하는지 실측된 적이 없다.
  3. 예측완료 모달의 현재 실제 카피/CTA — 커뮤니티 유도 요소가 있는지 없는지부터 확인해야 "보강"인지 "신설"인지 갈린다.
  4. 봇 콘텐츠를 리버풀/첼시 담벼락에 우선 노출했을 때 신규 유저의 "글/댓글 3회 게이트" 충족 행동이 진짜 반응(투표/댓글)을 동반하는지, 아니면 형식적 클릭만 남기는지 — 소규모라도 사전 관찰 필요.

### 실현 가능성 분류

- 🟢 **Quick win (기존 인프라로 며칠)**:
  - 예측완료 모달에 "커뮤니티 활동 3회" 진행률 + 폴 위젯 CTA 삽입 (기존 모달·기존 폴 인프라 재사용, 로직 추가 수준)
  - 이벤트 전용 폴(리버풀 vs 첼시 대항 질문) 편성 — 1탭 반응이라 마찰 최저, 게이트 요건을 "진짜 반응"으로 채움
  - 디스코드 봇에 매치데이 kickoff 45분 전 알림 cron 추가 — 기존 디스코드 인프라 + cron 패턴 재사용
  - /admin2 채널 퍼널 카드로 재방문율(D+1/D+3/D+7) 실측 뷰 추가 — user_acquisition 원장 이미 존재, 쿼리/카드만 추가
  - 봇 뉴스·떡밥 노출 로직을 팀 flair 매칭으로 우선순위 조정(리버풀/첼시 신규 유입에 맞춤) — 기존 파이프라인 필터만 조정, 킬스위치 이미 있음

- 🟡 **Medium (새 테이블/로직 필요)**:
  - 매치데이 공식글 자동 생성(경기 킥오프 전 스레드 + 결과 스레드) — 뉴스에이전트 패턴 재사용 가능하나 신규 트리거/템플릿 로직 필요
  - 예측→관련 뉴스/분석글 브리지(F14, Amazon cross-sell 패턴) — 새 추천 쿼리 + UI 카드
  - "댓글/투표 유도 장치"(예: 예측 후 "이 경기 어떻게 보세요?" 프롬프트) 신설 — 새 UI 컴포넌트 + 로직

- 🔴 **Heavy (비추)**:
  - 봇 콘텐츠 20+40/일 전량 수동 검수 재도입 — 인력 소모, 이벤트 임박 시점에 시간 대비 효과 낮음
  - 개인화 변동보상/추천 엔진(ML 기반) — 지금 필요한 건 알고리즘이 아니라 배관(재트리거 연결)
  - 라이브룸 등 체류 공간 신규 구축 — 브리핑에서 이미 후순위로 확정된 사안, 중복 논의 불필요
  - 스트릭/배지 시스템 신규 설계(새 테이블+크론+UI) — 이벤트 전 시간 내 무리, 기존 재방문 배관도 안 깔린 상태에서 장식만 추가하는 꼴

### 최고 ROI 각도

- **자동발행 봇 물량 자체는 이번 이벤트 참여율의 레버가 아니다.** 봉 콘텐츠는 "냉담한 방문자에게 죽은 사이트로 안 보이게" 하는 배경 텍스처 역할이지, 이미 등록한 유저를 다시 불러들이거나 커뮤니티 게이트를 진짜 투자로 채워주는 장치가 아니다. 실측(조회 0.7, 댓글 0)도 이 역할조차 지금은 못하고 있음을 보여준다. 물량을 늘리는 데 남은 시간을 쓰는 건 데이터가 가리키는 문제(재트리거·투자 단절)와 무관한 곳에 투자하는 것.
- **최고 ROI는 이미 있는 자산 3개(퍼널 계측 + 예측완료 모달 + 디스코드 봇)를 서로 연결하는 배관 작업이다**: 예측 직후 저마찰 커뮤니티 액션(폴 클릭)을 모달에 심어 게이트를 "진짜 반응"으로 채우고, 디스코드로 경기 시점에 맞춘 재트리거를 쏘고, 퍼널 카드로 D+1/D+3/D+7 재방문율을 실측해 7/6 같은 절벽이 재현되는지 즉시 확인하는 것. 새로 만드는 것 없이 기존 파이프를 잇는 이 작업이, 확정된 다음 큰 작업(시즌 오픈 이벤트)과 겹치지 않으면서 반면교사 데이터가 지목한 정확한 실패 지점(38% 무행동, 1.5% 커뮤니티 전환, 종료 후 0명)을 직접 공략한다.
