# gongnori 차별화 콘텐츠 브레인스토밍 결과

> 안건: "눈길을 단번에 사로잡아 가입·재방문하게 만드는 차별화 콘텐츠." 30개 아이디어 기각 후.
> 세 관점(Visionary / Contrarian / Realist)의 대립을 벼려낸 최종 종합.

---

## 1. "진짜 문제"의 정의 — 세 관점의 충돌이 만든 결론

### 충돌 지점
- **Visionary**: "국내에 없는 포맷(AI 캐스터·부검 리포트·심야 라디오)을 만들면 '이거 뭐야?'가 터진다." → 콘텐츠 자체의 참신함을 믿음.
- **Contrarian**: "콘텐츠 → 재방문이라는 인과 모델 자체가 4번 실측과 모순된다. 유저 밀도 0인 방에 아무리 좋은 포스터를 붙여도 '썰렁한 방의 포스터'다." → 콘텐츠 무용론.
- **Realist**: "끊긴 고리는 보상(콘텐츠 매력)이 아니라 **트리거 재발화**다. 피크 217명일 때조차 콘텐츠 소비는 0이었다 — 사람이 많을 때도 콘텐츠는 훅으로 작동한 적이 없다." → 병목은 콘텐츠가 아니라 owned 발송 채널.

### 평균 내지 않고 뽑은 결론 — Contrarian과 Realist가 서로 다른 길로 같은 지점에 도착했다
두 사람은 **"콘텐츠를 하나 더 만드는 것으로는 이 벽이 안 뚫린다"**에 독립적으로 수렴한다. 이게 이번 브레인스토밍의 핵심 신호다. 그 위에서 진짜 문제를 이렇게 정의한다:

> **gongnori에는 검증된 재방문 엔진이 단 하나(예측)뿐이고, 유저가 떠난 뒤 다시 불러올 owned 재트리거 채널이 0개이며, 유저 밀도가 0에 가깝다. 30개 기각 아이디어가 전부 실패한 이유는 그것들이 하나같이 (a) 유저가 '찾아가서 소비해야 하는' 목적지형 콘텐츠라 밀도·사회적 증거를 전제했고, (b) 무의식적으로 유일하게 작동하는 엔진(예측)을 배제했기 때문이다.**

### 가장 날카로운 한 방 (Contrarian, Realist가 보강)
**"베팅/예측 연관"을 기각 축에 넣은 것 자체가 위험 신호다.** 핵심 루프는 이미 "소식→재접속→게임(예측)"으로 확정돼 있는데, 콘텐츠는 예측과 무관해야 한다는 암묵 전제로 30개를 걸러왔다면, 그건 **소비전환 1.5%로 이미 죽은 담벼락과 똑같은 실패 구조를 '콘텐츠'라는 이름만 바꿔 반복**하는 것이다. 예측이라는 유일하게 검증된 동력에 기생하지 않는 콘텐츠는 태생적으로 '안 보는 게시판 하나 더'가 된다.
(컴플라이언스 주의: 여기서 "예측 연관"은 배당·현금·사행성이 아니라 **유저가 이미 남긴 슬립 데이터·예측 행위 자체**를 소재로 쓴다는 뜻. 점수 경제 원칙과 충돌하지 않는다.)

### 그래서 이기는 콘텐츠가 반드시 통과해야 할 3개 필터
30개가 못 넘은 관문이자, Top 3의 선정 기준:
1. **밀도 면역**: 유저 n=0 또는 n=1에서 100% 작동한다 (사회적 증거·타인 참여 불필요). — Contrarian
2. **트리거 내장 or 채널 탑승**: 그 자체가 재트리거이거나, 이미 도달하는 owned 채널(예측 완료 화면, 디스코드 23:05 다이제스트, 유튜버)에 실려 나간다. 온사이트 '발견'에 기대지 않는다. — Realist
3. **예측 기생**: 검증된 유일 루프(예측)에 붙거나, 사이트 밖으로 나가 공유되는 것. 목적지형 게시판을 하나 더 만들지 않는다. — 종합

## 2. 차별화 콘텐츠 Top 3

> 세 후보 모두 위 3필터를 통과하도록 재설계했다. 특히 "목적지 게시판"이 아니라 **예측 완료 순간에 주입되거나 사이트 밖으로 나가는** 형태로 규율했다.

---

### 🥇 1위 — 예측 완료 직후 "개인 서사 카드" (Personal Prediction Mirror)

**한 줄**: 유저가 이미 만든 자기 데이터(슬립 히스토리)를 근거로, 예측 제출 직후 "당신은 이번 시즌 언더독을 3번 믿었고 2번 배신당했습니다" 같은 **1인칭 서사 카드**를 즉석 생성해 보여준다. 콘텐츠가 아니라 '거울'.

**왜 1위인가 (3필터 완벽 통과 + 최대 레버 위치)**
- **밀도 면역**: 유저 1명만 있어도 100% 작동. 1% 소비율 문제와 원천적으로 무관하다 (Contrarian이 직접 민 후보).
- **트리거 위치가 최적**: 메모리에 명시된 "최대 레버 = 예측 완료 직후 주입" 지점에 정확히 꽂힌다 (Realist가 요구한 "재트리거 가능한 순간").
- **예측 기생**: 유일하게 검증된 루프 위에 얹는다. 배당·현금 언급 0 → 컴플라이언스 안전.
- Visionary의 페르소나 목소리·카드 디자인을 입히면 "이거 뭐야?"까지 확보 → 세 관점의 교집합.

**"이거 뭐야?" 순간**: 슬립 제출 버튼을 눌렀는데, 배당표 대신 "구너 3년차, 당신은 빅매치에 유독 약합니다 — 상위전 승률 22%" 같은 나를 꿰뚫는 한 문장이 카드로 뜬다. 스포츠 앱에서 '나를 분석당하는' 경험은 낯설다.

**1주 vertical slice**
- 신규 DB 불필요 — `prediction_slips` 히스토리 집계 쿼리 + 결정론적 문구 템플릿 5~8종(언더독 편향/빅매치 약점/연속 적중/팀 충성도 등).
- 예측 완료 모달(F16 자리)에 카드 컴포넌트 1개 추가, `html-to-image`로 클라이언트 렌더(서버·AI 그림 비용 0).
- 1주차는 문구 규칙 기반(LLM 없이), 페르소나 톤은 2주차. 다운로드/공유 버튼 포함(사이트 밖 유출 = Contrarian의 "소비를 밖에서" 원칙).

**성공/폐기 지표**
- 성공: 카드 노출 유저의 **다운로드·공유 클릭률 ≥ 15%**, 또는 카드 본 유저의 D+3 재방문이 안 본 유저 대비 유의미(+15%↑).
- 폐기: 공유 클릭률 한 자릿수 & 재방문 차이 노이즈(±10%) → "거울"조차 훅이 아님 → 즉시 접고 owned 발송 채널로 전환(Realist 공통 폐기 신호).

**구현 난이도**: 🟢 (기존 슬립 데이터 + 프론트 렌더, 신규 인프라 0)
**리스크**: 슬립 표본이 적은 신규 유저는 서사가 빈약 → "가입 첫날엔 약한 카드" 폴백 문구 필요.

---

### 🥈 2위 — 라이벌전 도발/프리뷰 카드 (Share-Out Card)

**한 줄**: 빅매치 전날, 상대 팬덤 약점 1개 + 풍자 카피 + 기존 팀 뱃지/픽셀 에셋을 **고정 템플릿에 텍스트만 갈아끼운** 정적 카드를 자동 생성. 담벼락 게시가 아니라 **SNS로 캡처해 나가는 것이 본체**.

**왜 2위인가**
- Visionary(#4 도발 카드) × Contrarian("소비를 밀도 있는 사이트 밖에 둬라") × Realist(A "배당 제외 프리뷰")의 종합. 목적지 게시판이 아니라 **사이트 밖으로 나가는** 콘텐츠라 밀도 0 문제를 우회한다.
- 기존 팀 뱃지·stadium 픽셀 에셋 재사용 → "AI 그림 퀄 의존" 기각 축 회피. LLM은 카피 문구에만.

**"이거 뭐야?" 순간**: "내일 토트넘전, 이거 스샷 각인데?" — 스포츠 앱에서 밈처럼 퍼가고 싶은 한 장이 자동으로 나온다. 대부분 앱은 일정표만 준다.

**1주 vertical slice**
- 고정 카드 템플릿 1개(Canvas/SVG 서버 렌더), 상대 뱃지 슬롯 + 카피 슬롯.
- 내일 아스날 빅매치 1건 하드코딩 → 상대 최근 약점 1개(standings/최근 5경기, **배당 제외**) → LLM 카피 3안 → 1클릭 검수 → PNG → 담벼락 게시 + 다운로드 버튼.

**성공/폐기 지표**
- 성공: 카드 다운로드·외부 공유 수 대비 유입(UTM 쿼리)으로 **신규 세션 1건이라도 추적**되면 유효 신호. 공유 후 방문 전환 관찰.
- 폐기: 공유 0 & 다운로드 한 자릿수 → 브랜드 인지 0에서 공유 훅이 안 돎(Contrarian의 Wordle 경고 현실화) → 접거나 유튜버 공급용 재료로 용도 변경.

**구현 난이도**: 🟡 (서버 이미지 렌더 + 빅매치 판별 필터)
**리스크(Contrarian 경고)**: 브랜드 인지 0 상태에서 공유물을 받은 사람이 "이게 뭐야"만 하고 끝날 수 있다. **공유 0이어도 담벼락 자체 재미로 성립**하도록 설계하고, 공유를 주력 베팅으로 삼지 말 것.

---

### 🥉 3위 — 경기 부검 리포트 (Autopsy Report, 디스코드 배포 탑승)

**한 줄**: 경기 종료 직후 betman 스탯 + 크롤 뉴스를 조합해 "왜 이겼나/졌나"를 **사망진단서 포맷**("사인 / 결정적 순간 / 예후")으로 자동 작성. 담벼락에 두지 말고 **디스코드 23:05 다이제스트에 실어 밖으로 밀어낸다**.

**왜 3위인가 (그리고 왜 순수 콘텐츠 후보는 3위까지인가)**
- Visionary(#2)의 장르 참신함 + 발행 속도 구조적 우위(사람이 안 쓴다)는 진짜다. 기존 뉴스 파이프라인(`data/agents`) 재사용 → 🟢.
- 단, 이건 본질적으로 "목적지형 콘텐츠"라 Contrarian의 '빈 게시판' 함정에 가장 가깝다. → **온사이트 발견에 기대지 않고 반드시 디스코드 다이제스트(이미 도달하는 owned 채널)에 실어야** 3필터를 통과한다. 이 규율이 붙어야만 Top 3에 든다.

**"이거 뭐야?" 순간**: 경기 끝나고 스포츠 매체가 아직 기사도 안 올렸을 때, "출혈사 — 과다출혈: 실점 3회, 지혈 실패" 블랙코미디 진단서가 이미 떠 있다. 스포츠 저널리즘에 없던 장르.

**1주 vertical slice**
- 아스날 경기 1건, betman sync 완료 이벤트 → 스탯 pull → 고정 프롬프트 템플릿 → 초안.
- 기존 desk review 큐(`agg_reservoir` drafted) 태워 1클릭 발행 → **동시에 디스코드 웹훅으로 push**. 신규 테이블 0.

**성공/폐기 지표**
- 성공: 발행 48h 내 view_count가 일반 뉴스봇 기사 평균의 **2배 이상**, 그리고 디스코드 링크 클릭 → 사이트 재방문(로그인 세션) 전환 관찰.
- 폐기: 뉴스봇 평균과 동급 이하 & 디스코드 클릭은 있는데 재방문 0 → 콘텐츠가 아니라 "사이트에 올 이유" 부재 문제(Realist) → 콘텐츠 추가 중단, owned 채널로 전환.

**구현 난이도**: 🟢 (기존 파이프라인 + 프롬프트 신규)
**리스크(Contrarian)**: 디스코드 배포를 빼고 담벼락에만 두면 즉시 '안 보는 게시판'이 된다. 배포 규율이 생명.

---

### 순위의 논리
1위는 **밀도·채널·예측 3필터를 유일하게 전부, 자연스럽게** 통과한다(거울+예측완료 주입). 2위는 밀도 문제를 '밖으로 나가서' 우회하지만 공유가 브랜드 인지에 걸린다. 3위는 콘텐츠 참신함이 가장 크지만 '디스코드 탑승'이라는 목발이 없으면 무너진다. **위로 갈수록 유저 밀도·브랜드 인지에 덜 의존한다** — 이게 이번 진단의 정확한 우선순위 축이다.

## 3. 하지 말아야 할 것 (세 관점 합의)

1. **"콘텐츠 하나로 재방문이 풀린다"고 믿지 마라 — 발송 채널 없이는 어떤 콘텐츠도 도달 자체가 안 된다.** (Realist·Contrarian 공통) 이번 Top 3와 **병렬로** owned 재트리거 채널(예측완료 화면 / 디스코드 DM·다이제스트 / 카카오·이메일)과 **최소 계측(URL별 view_count + UTM류 유입 파라미터)**을 깔아라. 이게 없으면 성공/폐기 판단 자체가 불가능하다.

2. **죽은 담벼락을 이름만 바꿔 다시 짓지 마라.** 커뮤니티 활성화를 전제한 포맷 전부 금지: **일일 퀴즈(#1, 기각 축과 이미 충돌)**, **UGC 큐레이션(#6, 원료가 되는 UGC가 1.5%뿐)**, **예상 포메이션 토론방(#9, 댓글 안 붙으면 빈 방)**. 세 관점이 명시적으로 경고했다.

3. **반사적으로 예측을 콘텐츠에서 배제하지 마라.** "베팅/예측 연관 = 기각"이라는 축이 담벼락과 같은 실패를 반복시킨 주범이다. 예측은 유일하게 검증된 재방문 엔진 — 콘텐츠는 이 위에 얹어야 한다. (점수 경제·현금 없음 원칙은 그대로 지키되, 슬립 데이터·예측 행위는 최고의 소재다.)

4. **브랜드 인지 0 상태에서 '공유 바이럴'을 주력 베팅으로 삼지 마라.** (Contrarian, Wordle 경고) 공유물을 받은 사람이 "이게 뭐야"만 할 위험. 공유는 부스터일 뿐, 공유 0이어도 값이 성립하도록 설계하라.

5. **빅매치·소재가 없는 날 억지로 만들지 마라.** 인터내셔널 브레이크·소재 빈약일엔 자동 스킵. 억지 생성은 품질 저하로 차별화 자체를 죽인다. (Realist·Visionary 공통)
