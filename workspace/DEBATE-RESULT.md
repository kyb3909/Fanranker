# 커뮤니티 가교 토론 — 종합 심판 결과 (DEBATE-RESULT)

> 2라운드 난상 토론(입장 3 + 반박 3)의 종합. 영범님이 이것만 읽고 실행을 결정할 수 있게 정리했다.
> 결론 한 줄: **"커뮤니티를 만들지 말고, 예측 재방문 루프의 끊긴 보상 고리부터 잇는다. 1순위는 적중카드(d). 나머지는 계측이 살아난 뒤 조건부."**

---

## 1. 토론 지도 — 무엇이 충돌했고, 무엇이 무너졌나

### 라운드 1 삼자 대립 구도
| | Visionary | Contrarian | Realist |
|---|---|---|---|
| 목표 | 반응의 축적 (글쓰기 아님) | 커뮤니티 폐기 → 예측 리텐션 | 훅 루프(재방문) 복구 |
| 1순위 | **b 매치데이 앵커 스레드** + 뉴스 이모지 | **d 적중카드** + c 시즌예측 병행 | **e 뉴스↔예측 브리지** + d 조합 |
| 시기 판단 | "지금이 골든타임" | "너무 이르다" | "이른 게 아니라 타겟 오류" |

### 라운드 2에서 무너진 주장 (반박에 격파됨)
1. **Visionary "지금이 골든타임, 진성 83명은 이미 매일 앱 여는 사람" → 완파.**
   Contrarian이 brief 4-2의 "종료 후 활동 등록자 **0명**"으로 격파. 83명은 과거형 라벨이지 현재 활성 유저가 아님. Visionary는 반박하지 못했다. → **"골든타임" 전제 폐기, "부검 시점"이 정확.**
2. **Visionary b "반나절 스코프" → 완파.**
   Realist가 "자동 생성 게시글 + 라이브 갱신 + 결과 코멘트 = 생애주기 cron 신규 서브시스템"으로 반박. Visionary 스스로 라운드2 최종 권고에서 **"신규 스레드/페이지를 만들지 않는다"**로 후퇴 — 사실상 원안 철회.
3. **Contrarian "너무 이르다" → 스스로 정정.**
   "시기 문제가 아니라 예측 루프에 보상/재트리거 고리가 없는 **구조적 결함(타겟 오류)**"으로 표현 수정. Realist의 프레이밍을 수용.
4. **Contrarian "e는 죽은 것 옆에 죽은 것 붙이기" → 스스로 취소.**
   "이미 활동이 있는 대상(betman 경기)으로 향하는 CTA는 내 원칙과 부합한다"며 **e 전면 기각을 철회.**
5. **Contrarian "c 시즌예측 병행" → 완파.**
   Realist가 "신규 예측 타입 + 신규 UI + 9개월 후행 = b보다 공수 큼, 1개월 예산 불가"로 격파. Contrarian도 최종 권고에서 c를 "활동 회복 후 재검토"로 밀어냄.
6. **Realist "e는 저비용이니 그냥 켜자" → 부분 수정.**
   Contrarian의 "침묵 노출 리스크(계측 없이 배포하면 1% 실패 반복해도 알 방법 없음)"를 인정. **게이팅(임계 인원 전까지 숨김) 조건**을 추가.

### 서로 인정(양보)한 것
- **Visionary → Contrarian**: 표시 숫자 신뢰성 문제 인정. n이 3~5일 때 "77%가 홈승"은 과장 마케팅. **최소 참여자 수(n≥10) 게이팅** 필요.
- **Contrarian → Realist**: "너무 이르다" 프레이밍 부정확 인정 + e 기각 취소.
- **Realist → Contrarian**: 소규모 풀 반응형 UI의 침묵 노출 리스크 인정. Visionary의 "9와 1은 자연히 따라온다" 낙관도 근거 없다고 동의.

## 2. 살아남은 합의 (반박을 견딘 결론만)

1. **가교의 목표는 "글 쓰는 유저 만들기"가 아니다.** 재방문하는(반응/소비하는) 유저를 만드는 것. 커뮤니티 전환 1.5%는 이미 1-9-90의 "1"에 근접 — 글쓰기 KPI로 다시 밀면 같은 실패 반복. (3자 만장일치)
2. **진짜 병목은 커뮤니티가 아니라 예측 루프의 끊긴 보상 고리다.** 종료 후 0명 = 재방문 동력 부재. 커뮤니티는 재방문이 복구된 뒤의 파생물. (Contrarian 정정 후 3자 수렴)
3. **d(적중카드/개인 리캡)가 1순위 뼈대다.** 세 관점이 **서로 다른 이유로 같은 결론에 도달** — Contrarian: "개인 완결형이라 콜드스타트/침묵 노출 안전", Realist: "훅 루프의 끊긴 보상 고리를 정확히 겨냥", Visionary: "3자 합의 지점, 병행 1순위 유지". 이견 없는 유일한 항목 = 가장 낮은 리스크의 베팅.
4. **봇 단신 뉴스는 퇴출 대상이 아니다.** 유지하되 **KPI에서 빼고**, 살아있는 행동(betman 경기)으로 향하는 CTA 재료로만 쓴다. (3자 수렴)
5. **b(앵커 스레드)의 자동 생성 게시글/코멘트는 이번 사이클 보류.** 표본 붕괴 위험. 예측 활동이 주간 100~200건으로 회복된 뒤 재검토. (3자 수렴)
6. **c(시즌 장기 예측)는 이번 1개월 예산에서 기각.** (3자 수렴)

### 살아남은 유일한 미해결 긴장 (= 실행 순서를 가르는 핵심)
> **"계측(board_view/퍼널)이 죽어 있다"를 어떻게 다루느냐.**
> - Contrarian: e 배포의 **선행 차단 조건** — "계측 없이 배포 금지. 저비용 ≠ 저위험."
> - Realist: **게이팅으로 우회 가능** — 임계 인원 전 숨기면 침묵 노출 리스크 제거.
>
> 심판 판정: **Contrarian 쪽이 옳다.** 계측 없이 e를 켜면 효과를 확인할 수 없어 1% 실패를 무한 반복한다. 게이팅은 "민망함"은 막지만 "효과 측정 불가"는 못 막는다. → **계측 복구를 d와 같은 P0로 못박는다.**

## 3. 최종 가교 권고 — 주제문 4쟁점 확정 답 + 실행 우선순위

### 쟁점 확정 답
1. **가교의 정의** → 글 쓰는 유저 X. **읽고 반응/재방문하는 유저 O.** (합의 #1)
2. **지금 커뮤니티 활성화가 맞나** → 아니다. "너무 이르다"도 아니다. **타겟 오류.** 커뮤니티보다 예측→재방문 보상 고리를 먼저 고친다. (합의 #2)
3. **봇 단신 뉴스** → 퇴출 아님. **유지 + KPI 제외 + CTA 재료.** (합의 #4)
4. **1순위 가교** → **d(적중카드/개인 리캡).** 만장일치. (합의 #3)

### 실행 우선순위 (1인 개발 · 1개월 예산 기준)

**P0-A. 계측 복구 (선행 필수)** 🟢
Sentry 클라이언트 켜기 + 퍼널 이벤트(재방문/카드 열람/CTA 클릭) 최소 로깅. 이것 없이 P0-B 이후를 배포하면 "효과 있었나"를 영원히 모른다. **반나절~1일.** 미해결 긴장의 심판 판정 반영.

**P0-B. d — 정산 직후 적중 리캡 카드** 🟡
- 정산 파이프라인(기존)에 후처리 훅 → "이번 주 N전 M적중" 계산 → 기존 웹 알림 채널로 발송.
- 개인 완결형 = 콜드스타트/침묵 노출 리스크 0. 재방문 동력 직접 겨냥.
- 신규: 리캡 로그 테이블 1개 + 정산 cron 후처리 로직. 이미지 카드는 2단계로 미룸(텍스트/웹알림 먼저).
- **며칠~1주.** 3자 만장일치라 가장 안전한 베팅.

**P1. e — 뉴스↔예측 브리지 (조건부)** 🟢 구현 / 조건부 배포
- 뉴스 카드 하단 "이 경기 예측하기" CTA(뉴스 태깅 인프라 완성 + betman games 조인).
- **배포 3조건 (전부 충족 시에만):** ① P0-A 계측 살아있음, ② 반응/분포 노출은 참여자 **n≥10(안전하게 20)** 게이팅, ③ 미달 시 "데이터 부족" 처리하고 분포 숨김.
- Contrarian의 "계측 선행" + Realist의 "게이팅" + Visionary의 "n≥10 임계치 가드"를 모두 결합한 형태. **A안(리캡 카드 내 CTA) vs B안(뉴스 하단 CTA) 클릭률 실측 비교**로 켠다.
- 한계비용 낮음(CTA + 조인 쿼리). **1~2일.**

**보류 (이번 사이클 제외)**
- **b 앵커 스레드 풀버전** (자동 게시글/코멘트/사회적 증거): 예측 활동 회복 전까지 표본 붕괴. → 소수의견 #2.
- **c 시즌 장기 예측**: 9개월 후행 페이오프, 1개월 예산 초과. → 소수의견 #1.
- **a 픽 이유 개방**: 컬럼은 있으나(🟢) "글쓰기" 방향이라 우선순위 낮음. d/e의 부가 옵션으로만.

## 4. 소수의견 기록 (기각됐으나 조건 충족 시 부활)

**소수의견 #1 — c 시즌 장기 예측 (우승/순위/득점왕, 9개월 재방문 훅)**
- 밀었던 관점: Contrarian. 기각 사유: 신규 예측 타입+UI+9개월 후행, 1개월 예산 초과(Realist 격파).
- **부활 조건:** 8월 EPL 시즌 오픈 이벤트와 **묶어서** 재검토. d/e로 예측 재방문이 안정화되고, 시즌제라는 9개월 컨테이너가 실제로 열릴 때. 원래 논리(장기 픽 = 매주 "내 예측 맞아가나" 확인 동기)는 시즌제와 자연 정합하므로 예산만 확보되면 강력해진다.

**소수의견 #2 — b 매치데이 앵커 스레드 풀버전 (픽 분포 사회적 증거 + 자동 코멘트)**
- 밀었던 관점: Visionary. 기각 사유: 소규모 표본에서 "3명 중 2명" 분포 노출 = 공개적 민망함(Contrarian) + 생애주기 cron 비용(Realist).
- **부활 조건:** 특정 경기 예측 참여자가 **정기적으로 n≥20을 넘길 때**(진성 풀 대략 200명+). 사회적 증거(research #4)는 표본이 커야 작동한다. 그 시점엔 P1의 픽 분포 위젯을 앵커 스레드로 승격. 즉 b는 폐기가 아니라 **e가 뿌린 씨앗이 자라면 도달하는 다음 단계.**
