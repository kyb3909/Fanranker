# 토론 주제 2: 담벼락-예측 통합 IA + 앵커 스레드 재론

> 1차 토론(DEBATE-RESULT.md)의 후속. 운영자(영범님)가 새 정보와 함께 재토론을 지시했다.

## 운영자의 새 입력 (이번 토론의 전제 — 뒤집으려면 강한 근거 필요)
1. **"앵커 스레드가 필요해."** — 1차 토론에서 보류 판정했지만 운영자는 여전히 원한다. "무조건 하자"가 아니라, 기각 사유(표본 붕괴)를 존중하면서 성립시킬 방법을 찾아달라는 것.
2. **유입은 매일 ~1명씩 꾸준히 들어온다** (오가닉 트리클). 대량 유입이 아니라 한 명씩 떨어지는 상황에서의 첫 세션 설계가 문제다.
3. **가설: "베팅 메뉴와 컨텐츠 메뉴가 분리되어 있어서 유저가 (예측으로) 들어가지 못하는 것 같다."**
4. **제안: 이벤트 페이지를 메인 담벼락과 합쳐보는 건 어떨까?**

## 실제 IA 현황 (2026-07-22 코드 확인 — 추측 아님)
- GNB: **담벼락(/)** | 운동장(/explore) | **월드컵 이벤트(/worldcup)** | 게임(/games) | 스타디움(/metaverse)
- **경기 예측(/prediction)은 GNB에서 숨김 처리됨** — 월드컵 이벤트 집중을 위해. 직접 URL로만 접근 가능 (header-nav.tsx 주석 확인).
- 그런데 **월드컵 이벤트는 7/19 종료(closed)**. 즉 현재 신규 유입의 예측 진입 동선:
  - 담벼락 → 봇 단신 뉴스만 보임 (예측 진입점 없음)
  - 월드컵 이벤트 메뉴 → 끝난 이벤트의 결과 페이지
  - /prediction → 메뉴에 없어서 존재 자체를 모름
  - **결론: 지금 매일 들어오는 1명은 예측이라는 핵심 루프를 발견할 방법이 거의 없다.**
- 담벼락 피드 = 게시글 목록(봇 뉴스 포함) + 사이드바(폴 위젯 등). 경기/예측 요소 없음.
- 참고: betman 데이터에는 여름에도 야구(KBO) 등 경기가 매일 있다. EPL은 8월 중순 개막.

## 검토할 통합 스펙트럼 (이 중 선택하거나 새 안 제시)
- **A. 완전 통합**: 홈 담벼락 피드에 경기 카드/앵커 스레드를 게시글 사이에 인라인으로 섞음. 예측이 곧 콘텐츠.
- **B. 상단 위젯**: 담벼락 최상단에 "오늘의 경기" 스트립(가로 카드) 고정 + 탭하면 예측. 피드 자체는 유지.
- **C. 앵커 스레드 = 게시글**: 경기마다 자동 생성되는 앵커 스레드가 담벼락 피드에 일반 게시글처럼 흐름 (1차 토론의 b를 담벼락에 이식). 픽 분포는 n≥10 게이팅.
- **D. 현행 유지 + 브리지만**: IA는 안 건드리고 뉴스 카드에 예측 CTA만 (1차 토론 P1 그대로).

## 쟁점
1. 운영자 가설(메뉴 분리가 진입을 막는다) 검증: IA 문제인가, 콘텐츠 문제인가, 둘 다인가? 특히 "/prediction 숨김 + 이벤트 closed" 상태를 어떻게 해석하나.
2. A~D 중 무엇이 맞나? "이벤트 페이지를 담벼락과 합친다"의 올바른 해석은?
3. 앵커 스레드를 표본 n이 작아도 성립하는 형태로 재설계할 수 있나? (예: 사회적 증거 없는 버전 — 뉴스 자동 첨부 + 예측 CTA + 라이브 스코어 중심, 픽 분포/참여자수는 게이팅으로 숨김) 1차 기각 사유가 이 재설계로 해소되는지 명시적으로 판정하라.
4. 매일 1명 유입의 첫 세션: 이 사람이 처음 보는 화면은 무엇이어야 하나? (2차 이벤트 전 한 달간의 이야기이기도 함)
5. 1차 토론의 P0(계측, 적중카드)와의 우선순위 관계: 이 통합 작업이 P0를 밀어내는가, 병행 가능한가?
