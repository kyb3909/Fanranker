# gongnori 2차 이벤트 설계 브레인스토밍 결과

> 안건: **한 달 뒤(8월 하순 EPL 시즌 오픈) 2차 이벤트를 어떻게 설계해야, 이벤트 참여가 사이트 상시 유입으로 전환되는가.**
> 1차(월드컵 그룹대결) 실측 퍼널이 반면교사. 기존 2차 초안(EVENT_SEASON_OPEN.md = 유튜버 3채널 + 포인트 추첨 + 팬덤 대항전)을 **보완/차별화**하는 답이어야 함.

## 1. 왜 참여가 유입으로 이어지지 않았나 (종합 진단)

### 세 관점이 합의한 것
- **핵심 액션(예측)은 검증됐다.** 등록자의 65%(300명)가 슬립을 제출했다. 트리거도 작동했고(유튜버 홍보 = 6/29 피크) 행동도 나왔다. 여기까진 실패가 아니다.
- **끊긴 고리는 "재트리거"와 "투자" 두 곳이다.** ① 3일 내 이탈 32%는 재방문을 부르는 내부 트리거가 없어서, ② 종료 즉시 100% 이탈은 보상(경품·포디움)이 "종료 시점"에 묶여 참여 도중 아무 즉각 보상도 없었기 때문. 커뮤니티 전환 1.5%가 "투자 0"을 증명한다.
- **재소환 시도 자체가 0번이었다.** CS/피드백 채널이 없다 = 이탈 신호가 없던 게 아니라 아무도 부른 적이 없다. 유튜버(1회성 외부 트리거) 하나로 전체 루프를 돌렸고, 그게 꺼지자 루프도 같이 꺼졌다(7/6 절벽).

### 핵심 충돌 — 진짜 문제는 어느 쪽인가
- **Visionary/Realist**: "다리 하나가 없었을 뿐이다." 사람은 왔고 행동도 했다. 예측이라는 강한 루프 옆에 재트리거·즉각보상 훅만 붙이면 전환된다. → **제품의 훅 부재**가 문제.
- **Contrarian**: "참여가 높았다는 건 허영 지표다." 38%가 슬립 0건, 진성은 18%(83명)뿐. 유튜버+추첨으로 온 절반은 **경품 사냥꾼**이고 애초에 리텐션할 유저가 아니었다. 기존 유저 전환이 459명 중 4명뿐이라는 게 결정적 — 이벤트가 진짜 팬에게조차 매력이 없었다. → **획득의 질**이 문제.

### 이 충돌이 주는 통찰 (가장 값진 지점)
두 진단을 겹쳐 보면 **둘 다 반만 맞다.** Contrarian 말대로 38%는 거를 유저가 맞다. 그런데 결정적 반증이 하나 있다 — **슬립을 낸 65%도, 진성 18%(83명)도 종료 후 전원 0명으로 떠났다.** 즉 필터링만 해서 83명만 남겨도 그 83명 역시 돌아올 곳이 없어서 사라진다. 필터는 낭비를 줄일 뿐 리텐션을 만들지 못한다.

**→ 진짜 결손은 Contrarian이 처방 문단에서 스스로 짚었지만 "이벤트가 아니라 제품 문제"라며 옆으로 치운 그것이다: "이벤트가 끝난 다음 날 돌아올 구체적 이유"가 0이었다.** 1차 이벤트는 **자기완결형(끝나면 남을 이유도 같이 증발)**으로 설계됐다. 시즌 아웃 기간이라 예측할 경기도 뜸했고 담벼락 소비는 1%대였다.

**결론: 2차 이벤트를 "대량 유입 이벤트"가 아니라 "이미 돌아가고 있는 상시 루프로 유저를 밀어넣는 온램프(on-ramp)"로 재정의해야 한다.** 그리고 그 온램프의 착지 지점(시즌 오픈 = 경기가 매일 있는 시기)은 8월 시점 선택으로 이미 절반은 맞췄다 — 남은 건 "이벤트 보상이 등록이 아니라 지속 활동에 묶이도록" 메커닉을 바꾸는 것.

## 2. 이벤트 설계 전에 데이터로 확인해야 할 것 (Realist)

1차는 이탈을 **사후 수동 집계**로만 알았다. 2차는 아래를 **이벤트 시작 전에** 계측으로 박아두고 시작해야, 절벽이 오는 걸 실시간으로 보고 도중에 재트리거를 추가 투입할 수 있다.

1. **가입 → 첫 슬립 텀** (`slips.created_at` ⨯ `profiles.created_at` 조인): 175명 "행동 0"이 (a) 온보딩 UX 마찰인지 (b) 경품 목적 무관심 가입인지 구분. 처방이 갈린다 — (a)면 온보딩 수정, (b)면 필터 게이트.
2. **웹 알림 발송/오픈율**: 재트리거가 "없었다"인지 "있었는데 안 열렸다"인지가 다르다. 후자면 채널 문제, 전자면 로직 부재.
3. **디스코드 뉴스봇 서버 가입률**: 1차 땐 없었고 7/19 완료됨 → 2차에서는 "이미 있는 재트리거 채널"로 카운트. 유입 시 디스코드 조인률이 곧 실험 지표.
4. **순수 로그인(비활동) 세션 존재 여부**: 로그인만 하고 이탈 vs 완전 이탈 구분. Sentry 클라이언트가 꺼져 있어 지금은 이 데이터 자체가 없을 가능성 → **Sentry 클라 활성화가 선행 과제**.
5. **주간 코호트 뷰 자동화**: brief 4-3 쿼리(주차별 활동 등록자)를 SQL 뷰/대시보드로 고정. 기존 posts/slips 테이블로 뷰만 추가하면 됨. **이건 기능이 아니라 운영 인프라 — 안 깔면 2차도 종료 후에야 "또 이랬네"만 남는다.**

## 3. 차별화 피처 Top 5

원칙: EVENT_SEASON_OPEN.md의 핵심(팬덤 대항전 구조)은 건드리지 않고, 1차에서 실측으로 확인된 두 결손(**재트리거·즉각보상/투자**)과 한 위험(**경품 사냥꾼 유입**)만 정조준한다. 1인 개발 + 한 달 시한 → 🟢부터 쌓는다.

### 1. 이벤트 보상 = "등록 시점 추첨"이 아니라 "시즌 첫 2주 주간 미션 누적"
- **한 줄 컨셉**: 경품 응모 자격을 가입이 아니라 "매주 예측 N건 + 커뮤니티 1건"의 2주 누적으로 건다.
- **왜 차별화되나**: 스포츠 이벤트의 추첨은 "가입하면 응모권" 1회성이라 참여와 리텐션이 분리된다. gongnori는 보상 메커닉 자체에 재방문을 접붙여 — 이벤트를 자기완결형이 아니라 **2주짜리 강제 습관 창구**로 만든다. 유튜버 트리거가 꺼진 뒤(7/6 절벽 지점)에도 "아직 이번 주 미션 안 채웠다"가 재방문 이유가 된다.
- **어떤 훅**: 손실회피(누적 진행도 소실) + 주간 리셋(#8) + 미완료 과제 기억(Zeigarnik). 시즌 오픈이라 경기가 매일 있어 미션 채울 콘텐츠가 실제로 존재.
- **출처**: research #8 주간순환 + #14 주간 코호트. Contrarian(필터)·Visionary(다리)·Realist(재트리거)를 **한 메커닉으로 합침** — 경품 사냥꾼은 2주 미션을 못 버텨 자진 이탈하고, 진성은 그 2주 동안 예측+커뮤니티 루프를 완주한다.
- **구현 난이도**: 🟡 (기존 `events`/`prediction_slips` 재사용 + 주간 미션 카운트 뷰. 앱/새 결제 없음. 룰 변경 성격이 큼)
- **리스크**: Contrarian 경고 — 마찰은 필터지만 임계값을 너무 높이면 진성까지 튕긴다. 2주 데이터(항목 2-1) 보고 임계값 조정 여지 확보.

### 2. 예측 행동 → 디스코드 즉시 브로드캐스트 + 뉴스봇 다이제스트
- **한 줄 컨셉**: 슬립 제출 시 디스코드 채널에 "OOO가 예측했습니다" 자동 공지 → 살아있는 두 번째 트리거 채널.
- **왜 차별화되나**: 1차엔 재트리거 채널이 유튜버 하나뿐이었고 꺼지자 루프도 꺼졌다. 디스코드 서버는 7/19에야 완성됐다 — **1차엔 존재하지도 않았던 신무기**. 예측(검증된 강한 행동)에 사회적 가시성을 붙여 유튜버 밖의 상시 재소환 채널을 만든다.
- **어떤 훅**: 사회적 인정(#4) + 채팅 근접(#16). "내 예측에 누가 반응했나" + 23:05 다이제스트가 매일 열 이유.
- **출처**: Realist가 최고 ROI 1순위로 밀었음(#16). `lib/discord-notify.ts` + 웹훅 이미 검증됨.
- **구현 난이도**: 🟢 (웹훅 공지 추가. 새 테이블 불필요, 며칠)
- **리스크**: 저관여 유저 예측까지 다 뿌리면 노이즈 → 이벤트 참가자/일정 임계 이상만 브로드캐스트.

### 3. 예측 직후 "오늘의 팬심 질문" (검증된 루프에 심은 소셜 훅)
- **한 줄 컨셉**: 슬립 제출 버튼 직후 1탭으로 팬 질문 노출 → 답변은 담벼락으로, 반응 오면 알림.
- **왜 차별화되나**: 스포츠 앱은 베팅 탭과 커뮤니티 탭이 분리돼 "굳이 옮겨가야" 커뮤니티를 본다. gongnori는 65% 참여하는 예측 루프 한가운데 소셜 훅을 심어 **전환을 유도하는 게 아니라 전환이 필요 없게** 만든다 — 1.5% 커뮤니티 전환율을 정면으로 뚫는 각도.
- **어떤 훅**: 아이스브레이커(#7, 상호작용 후 재방문 6배) + 채팅 근접(#16). "내 답변에 누가 반응했나" 확인하러 다음 날 재방문.
- **출처**: Visionary 2번 + Realist가 🟢로 확인. **`polls` 테이블/API 이미 완성**(migration 20260701) — 콘텐츠만 채우면 즉시 재사용.
- **구현 난이도**: 🟢 (인프라 완비, 질문 콘텐츠 + 제출 후 노출 위치만)
- **리스크**: 없음에 가까움. 단, 질문 큐레이션이 지속돼야(뉴스 에이전트와 달리 이건 사람 손 필요).

### 4. 실시간 flair 진행도 바 + 개인 성적 카드 (보상을 종료가 아니라 매 행동 직후로)
- **한 줄 컨셉**: 이벤트 진행 중 "다음 호칭까지 3000점" 진행도 + "이번 달 20개 예측 8개 적중(40%)" 개인 카드를 즉시 노출.
- **왜 차별화되나**: 1차는 결과를 "종료 후"로 미뤄(TOP10 비공개, 포디움만 종료 후) 투자 루프를 스스로 죽였다. TOP10 공개 없이도(의욕상실 방지 원칙 유지) **개인화 진행도만** 보여주면 투자 심리를 종료 시점이 아니라 매 행동 직후로 당긴다.
- **어떤 훅**: 시각적 진행도(#19, Zeigarnik) + 팬 정체성(#9) + 네거티브 프레이밍 회피(#20 — "실패" 대신 "꾸준하네요").
- **출처**: Realist 최고 ROI 2순위. `flair_titles.threshold` + `user_flair_scores.score_total` 이미 존재. UI 프로그레스 바만 추가.
- **구현 난이도**: 🟢 (호칭 시스템 완성됨, UI 노출 작업 수준)
- **리스크**: 없음. 단 flair 점수가 이벤트 활동과 실제로 연동돼 오르는지 확인 필요.

### 5. 이벤트 종료 다음 날 착지 지점 = 주간 리셋 팬덤 리그
- **한 줄 컨셉**: 이벤트가 밀어넣은 유저가 착지할, 매주 월요일 0으로 리셋되는 상시 리그.
- **왜 차별화되나**: 스포츠 앱은 대개 "시즌 누적 랭킹" 하나라 뒤처지면 참여 동기가 사라진다. 주간 리셋은 "1등 못해도 다음 주는 새 기회"라는 진입장벽 제거 구조 — **7/6 절벽("이미 늦었다" 심리)과 종료 즉시 0명을 근본적으로 차단하는 유일한 구조적 장치.** 1~4번이 이벤트 안의 훅이라면 이건 이벤트 밖의 상시 루프.
- **어떤 훅**: 주간 순환(#8) + 스트릭(#1)의 "새 판" 심리.
- **출처**: Visionary 1번. worldcup 점수 모델(슬립 단위 net, project_worldcup_score_model)을 주 단위로 잘라 재사용.
- **구현 난이도**: 🟡 (주 단위 리셋+재집계 로직 신규. 타임존 경계 주의 — 볼 이중 리셋 전례 있음)
- **리스크**: Contrarian 경고 — 비시즌 공백기에 스트릭 강제는 피로·이탈 가속. 시즌 중(경기 매일)에만 유효하므로 **시즌 오픈에 맞춰 켜고, 비시즌 진입 전 강도 완화** 설계 필요.

## 4. 만약 딱 하나만 한다면

**피처 1 (이벤트 보상 = 2주 주간 미션 누적).**

1. **세 관점을 한 메커닉으로 합친다** — 경품 사냥꾼은 2주 미션을 못 버텨 자진 이탈(Contrarian 필터), 진성은 그 2주간 예측+커뮤니티를 완주(Visionary 다리), 매주 "미션 안 채움"이 재방문 이유(Realist 재트리거).
2. **이벤트를 자기완결형에서 온램프로 바꾸는 유일한 룰 변경** — 1차의 치명적 결손(종료 즉시 0명)을 보상 구조 자체로 해결한다. 새 인프라 최소.
3. **시점이 맞다** — 8월 시즌 오픈이라 2주 미션을 채울 경기가 매일 존재. 비시즌이었다면 불가능했을 설계가 지금은 가능.

단, 이 하나를 **혼자 두지 말 것**: 피처 2·3·4(전부 🟢, 며칠)를 함께 얹어야 2주 미션 창구 안에서 재트리거·즉각보상이 돌아간다. 피처 5(🟡)는 그 다음 순번 — 2주 온램프의 착지 지점으로.

## 5. 하지 말아야 할 것 (Contrarian 경고 중 새겨들을 것)

1. **유튜버 + 추첨 재탕 금지.** 기존 2차 초안(EVENT_SEASON_OPEN.md)의 "유튜버 3채널 + 포인트 추첨 + 팬덤 대항전"은 1차를 이름만 바꾼 것. **유인이 같으면 유입 인구 구성도 같고 결과도 같다.** 반면교사가 "포장만 바꾸기"가 되면 안 된다 → 그래서 피처 1(응모 자격을 활동 게이트로)이 초안의 유인 구조를 바꾸는 핵심.
2. **슬롯머신 심리를 예측 UX에 얹지 말 것.** research #2 변동비율보상("거의 맞았다" 서사), #6 손실회피 재투자("잃었으니 다음 판"), #13 실시간 스카시티 — 문자 그대로 카지노 설계 원칙. brief 6번 "현금 환전 없음·사행성 확장 금지" 컴플라이언스와 정면 충돌. 점수만 써도 심리 기법을 베끼면 실질적 도박성 설계 = 규제/평판 리스크. **도입 금지.**
3. **딥링크(#12)·매직 인바이트(#15) 착시 주의.** "링크 클릭 → 앱 자동 열림"이 전제인데 gongnori는 웹만 있고 모바일 앱이 없다. 없는 인프라를 만들다 시간 날리지 말 것 — 필요하면 웹 쿼리파라미터 딥링크(`?invite=xxx`)로 축소.
4. **비시즌 스트릭 강제 금지.** 콘텐츠 없는 공백기에 "매일 뭔가 하라"는 압박은 피로·이탈을 가속. 피처 5는 시즌 중에만 켠다.
5. **"이벤트 후 2주간 매일 뜰 경기/콘텐츠가 실제로 있는가"를 이벤트 설계보다 먼저 검증.** 이 구멍이 그대로면 이벤트를 아무리 정교하게 만들어도 종료 즉시 0명은 반복된다. 8월 시즌 오픈이 이 답을 주지만 — 캘린더로 확인하고 시작할 것.
