# 리텐션 전략 리서치 (넓은 범위)

## 패턴 목록

1. **스트릭 (Streak) 메커니즘** (Duolingo)
   - 메커니즘: 매일 완료 → 연속 일수 표시 → 1일 만료로 초기화. 손실회피 심리(진행도 소실감)로 일일 재방문 강제.
   - 왜 먹히나: 7일 스트릭 도달 시 완료율 3.6배 증가. 미루는 것이 비용(streak loss)이 되어 활동이 습관화.
   - gongnori 각도: "예측 연속일" 또는 "팬덤 활동 연속도" 시스템. 한 번 놓친 뒤 복구 어려운 심리적 장벽 이용.

2. **변동 비율 보상 (Variable Ratio)** (스포츠베팅, 슬롯머신 심리)
   - 메커니즘: 불규칙한 횟수 후에만 보상. 예: 평균 5회 중 1회 중상. 예측 불가능성이 참여 동기 증강.
   - 왜 먹히나: 다음 시도가 "이번엔 아닐까" 기대감 유발. 가장 강한 행동 유지 스케줄(슬롯머신 중독 원리).
   - gongnori 각도: 베팅 슬립 결과의 "때론 큰 배당" 변동성 강조. 정산 후 음성 피드백보다 "거의 맞았다" 서사 제공.

3. **일일 시간 압박 (Time Pressure)** (BeReal)
   - 메커니즘: 매일 랜덤 시간에 알림 + 2분 윈도우 → 2분 내 사진 업로드 필수. 68% 사용자 3분 내 진입.
   - 왜 먹히나: FOMO + 즉각성. "지금 아니면 기회 상실" 심리로 습관적 체크인 형성.
   - gongnori 각도: 라이브 경기 "예측 마감 5분 전" 경고. 시간 윈도우를 좁혀 충동적 참여 유도.

4. **사회적 인정 (Social Proof)** (Strava Kudos, Reddit Karma)
   - 메커니즘: 사용자 기여도를 공개 점수로 시각화. 높은 karma/kudos = 신뢰도·가시성·접근권 상승.
   - 왜 먹히나: 타인 인정이 내재 동기 강화. 높은 점수는 커뮤니티 상태 상징.
   - gongnori 각도: "팬 활동 점수" 또는 "팬덤 스코어" 공개 표시. 상위 랭크 유저는 뱃지·특권(채널 선입 등).

5. **세분화된 경쟁 (Segmented Leaderboards)** (Strava Segments, KOM)
   - 메커니즘: 대규모 랭킹 대신 작은 구간/세그먼트별 상위 경쟁. KOM은 90일 이내 반복 횟수 기준(속도 아님).
   - 왜 먹히나: 전체 1등 불가능 심리 제거 → "내 구간에서 1등" 달성 가능. 일관성 보상.
   - gongnori 각도: "팀별 주간 예측 상위 5명" 소규모 리더보드. "KOM" = 같은 경기 3회 이상 예측한 유저 강조.

6. **손실 회피 + 침몰 비용 (Loss Aversion)** (스포츠베팅, 슬롯)
   - 메커니즘: 손실의 고통 = 이득 기쁨의 2배. 투자한 시간/돈 소실 회피로 "다음 한 판" 유도.
   - 왜 먹히나: 합리성 배제 후 감정 기반 의사결정. 잃은 것 회복 심리.
   - gongnori 각도: 적중 실패 후 "환불 없지만, 다음 경기는 기회" 메시지. 재투자 심리 활성화.

7. **커뮤니티 상호작용 (Icebreaker Questions)** (Discord)
   - 메커니즘: 일일 질문 또는 "오늘의 토론" → 타인 응답 유도 → 상호작용 후 반복 방문 확률 6배 증가.
   - 왜 먹히나: 사람과의 연결이 강한 retention 신호. 일방적 콘텐츠 소비보다 양방향 상호작용.
   - gongnori 각도: "지난주 최고의 경기 예측은?" 일일 질문. 댓글 달면 포인트 + 답변 대기 심리로 재방문.

8. **주간 순환 구조 (Weekly Cycles)** (DFS, Fantasy Football)
   - 메커니즘: 대회·이벤트가 주 단위로 리셋. 월요일 새로운 시즌 시작 → 목표 명확화 → 주말 정산. 반복 기한 설정.
   - 왜 먹히나: 스포츠 경기력과 일치. 예측 리셋은 "새로운 기회" 심리.
   - gongnori 각도: 주간 토너먼트 (월~일) + 매주 상금/포인트 정산. 매주 신규 진입 가능.

9. **팬 정체성 (Fan Identity)** (팬덤 커뮤니티)
   - 메커니즘: 팬 호칭(Gooner, Red Devil 등)을 계정에 달기 → 개인 정체성 강화. 기부·기여 시스템으로 호칭 잠금해제.
   - 왜 먹히나: 감정적 투자 + 사회적 신원. 호칭은 소속감 상징.
   - gongnori 각도: 팀별 "팬덤 이름" 시스템 (아스날=Gooner). 호칭 잠금해제 = flair score 임계값 달성. 호칭 표시 시 재방문율 상승.

10. **Hooked 모델: External → Internal Trigger 전환** (Instagram, TikTok, Duolingo)
    - 메커니즘: 초기 외부 트리거(푸시 알림, 이메일) → 반복 후 내부 트리거(지루함, 기대감)로 전환. 습관화.
    - 왜 먹히나: 외부 의존성 제거 → 자발적 진입. 내부 신호가 더 강력한 retention.
    - gongnori 각도: 초기 "경기 시작 알림" 필수 → 3주 후 "아, 경기 시간 이 정도겠네" 자동 인식으로 전환.

11. **스트릭 부활 (Streak Revival)** (Duolingo)
    - 메커니즘: 30일 이상 스트릭 잃은 유저에게만 "스트릭 복구" 기회 제공. 재활성화 경로.
    - 왜 먹히나: 완벽성 추구 유저의 심리적 장벽 제거. "진행도는 남아있다" 프레이밍.
    - gongnori 각도: "예측 연속도 7일 이상 단절한 유저" → "지난주 경기 예측 보충" 기회. 재진입 저항 낮춤.

12. **깊은 링크 (Deep Linking)** (YouTube → 앱 전환)
    - 메커니즘: 유튜브 링크 클릭 → 앱 자동 열림 → 특정 화면(코드 입장, 초대 리그 등). 마찰 제거.
    - 왜 먹히나: 웹 → 앱 손실 >50%. 원클릭 진입이 설치율 크게 증가.
    - gongnori 각도: 유튜버 소개 링크 → 친구 리그 자동 조인. 앱 설치 후 첫 경험 이미 완료된 상태.

13. **FOMO + 스카시티 (Scarcity)** (라이브 이벤트, 제한 상품)
    - 메커니즘: 제한된 시간 + 제한된 수량. 카운트다운 타이머 + "남은 자리 3개" 표시.
    - 왜 먹히나: 심리적 압박 → 즉각 결정. 기회 비용 인식 증폭.
    - gongnori 각도: "이 경기 예측 가능까지 1시간" + "아직 참여한 팬 342명" 실시간 카운트.

14. **주간 반환 목표 (First Week Retention)** (Discord, 커뮤니티)
    - 메커니즘: 7~14일 사이 재방문율을 KPI로 삼기. "활성 유저" 기준을 DAU → WAM(주간 활성)으로 변경.
    - 왜 먹히나: DAU는 영구 사용자 아님. WAM 70% 달성 = 장기 retention 신호.
    - gongnori 각도: 가입 후 7일 내 "첫 예측" → 14일 내 "2회차 참여" 추적. 2주 checkpoint로 구분.

15. **마법 초대 링크 (Magic Invite)** (Sleeper)
    - 메커니즘: 친구 초대 링크 → 앱 자동 다운로드 + 리그 자동 조인. URL 클릭만으로 모든 단계 완료.
    - 왜 먹히나: 가입 마찰 제거 + 사회적 압박(이미 친구 그룹에 들어간 상태).
    - gongnori 각도: 친구 리그 초대 → 링크 클릭 → 앱 설치 + 해당 리그 자동 진입. 온보딩 스킵.

16. **채팅 근처 배치 (Proximity to Social)** (Sleeper)
    - 메커니즘: 모든 행동(라인업 변경, 베팅 등)이 채팅에 즉시 표시. 챗은 항상 한 스와이프 거리.
    - 왜 먹히나: 게임 행동 → 사회적 반응(댓글, 반응) 루프. 50분/일 engagement 기록.
    - gongnori 각도: 예측 제출 → 즉시 채팅에 "OOO가 예측했습니다" 공지. 댓글 달기 버튼 한 탭.

17. **시즌 오픈 프로모션 (Seasonal On-Ramp)** (DFS, Fantasy Football)
    - 메커니즘: 스포츠 시즌 시작 전 주 → "100% 매칭 보너스" 또는 "첫 진입 환불". 신규+복귀 유저 타겟.
    - 왜 먹히나: 스포츠 시즌 = 자연 재활성화 시점. 프로모션 없어도 관심 상승 → 약간의 인센티브로 전환.
    - gongnori 각도: EPL 시즌 시작 주 → "신규 팬 100 포인트 지급" + "연속 예측 5회 달성 시 보너스".

18. **참여 보너스 (Refer-a-Friend)** (DFS, Loyalty Program)
    - 메커니즘: 기존 유저 초대 → 신규 유저 첫 입금 시 양쪽 모두 보너스. 네트워크 외부성.
    - 왜 먹히나: 기존 유저는 친구 그룹 확대(사회적 만족), 신규는 가입 인센티브.
    - gongnori 각도: "친구 초대 5명 달성 시 '팬 엘리트' 호칭 잠금해제". 초대 행동 자체가 호칭 진행도.

19. **시각적 진행도 (Visual Progress)** (레벨, 배지, 프로그레션)
    - 메커니즘: 호칭 잠금해제 진행도 막대(0~50K 점수). 다음 단계까지 "2000점 남음" 표시.
    - 왜 먹히나: 구체적 목표 명확화 → 심리적 "거의 다 왔다" 감. Zeigarnik effect (미완료 과제 기억).
    - gongnori 각도: "다음 호칭까지 3000 flair score 필요" 진행도 바. 매일 +10 보면 300일 = 가시적 이정표.

20. **네거티브 프레이밍 회피 (Loss Framing Shift)** (Duolingo)
    - 메커니즘: "스트릭 실패했습니다" 대신 "당신의 학습 진도는 안전합니다" 메시지. 손실 대신 보유 강조.
    - 왜 먹히나: 손실 심리 완화 → 재시작 심리적 장벽 낮춤. 복귀 메시지 긍정성.
    - gongnori 각도: "예측 실패" 알림 대신 "지난달 20개 경기 예측, 8개 적중(40%) - 꾸준하네요" 통계.
