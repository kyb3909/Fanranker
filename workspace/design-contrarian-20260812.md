# 디자인 패널 — Contrarian (2026-08-12)

역할: 전제를 의심한다. "카드를 어떻게 다듬을까"보다 먼저 "이 카드에 애초에 이게 왜 들어가 있나"를 묻는다.

---

## 0. 전제 4개를 먼저 깬다 (냉소 금지 — 전부 대안 포함)

### 전제 1: "카드에 투표를 넣은 것" 자체가 틀린 결정이다

실측이 이미 답을 줬다. VS 투표 노출 79 → 투표 1 = **1.3%**. 그런데 카드의 **62%**가 이 위젯을
이고 있다. 이건 "위젯 스타일링 문제"가 아니라 **거의 안 쓰이는 기능이 피드 절반 이상의
레이아웃 세금을 걷어가고 있는 것**이다. 카드-안-카드, 높이 리듬 파괴, 톤 불일치(사각 박스
vs 둥근 pill) — 브리프가 나열한 증상 6개 중 3, 5, 6번은 전부 이 위젯이 피드 표면에
존재한다는 사실 하나에서 파생된다. 위젯 테두리를 얇게 하고 폰트 웨이트를 맞추는 건
증상 완화지 원인 제거가 아니다.

**그럼 무엇을**: 투표를 피드 카드에서 아예 뺀다. 브리프가 인용한 "1.3%" 실측 자체가
"글 상세 표면"에서 나온 숫자다 — 즉 투표는 이미 상세 페이지에 살아있다. 피드 카드에는
"투표중" 칩(텍스트 6자 이하, 배경 틴트) 하나만 남기고 클릭하면 상세로 보낸다. 참여율이
낮은 건 피드 디자인이 아니라 상세 페이지/투표 자체 매력의 문제이므로, 그 문제를 피드
리듬까지 같이 망가뜨리며 짊어질 이유가 없다.

### 전제 2: 구단 플레이스홀더 이미지를 만든 것 자체가 맞았나

1200×630 원본을 104×76(1.37:1) 프레임에 우겨넣어 "구 소식", "르트문트" 같은 글자
조각만 남는 건 크롭 비율 계산 실수가 아니라 **애초에 "이미지 없는 기사에 가짜 이미지를
합성해서 붙인다"는 결정 자체의 리스크**다. 사진처럼 생긴 자리에 사실은 아무 사진도
아닌 정적 배경이 매번 반복되면, 사용자가 눈치채는 순간 "이 계정은 성의 없이 찍어낸다"는
신호로 읽힌다 — 지금은 크롭이 깨져서 몰랐을 뿐 비율을 고쳐도 근본 문제(가짜 히어로
이미지의 반복)는 남는다.

**그럼 무엇을**: 이미지 없는 카드는 썸네일 슬롯 자체를 없애고 텍스트 전용 리스트 행으로
간다(아래 C-2). 구단 정보가 필요하면 사진 크기가 아니라 **뱃지 크기**(정사각 크롭,
글자 없이 크레스트/이니셜만)로 축소해 "이건 사진이 아니라 태그다"라고 정직하게 말한다.
21종 자산은 재생성 가능하다고 브리프가 명시했으니, 1200×630 히어로용이 아니라
120×120 정사각 배지용으로 다시 뽑는 게 맞는 방향이다.

### 전제 3: 타로 유도 버튼이 카드를 복잡하게 만든 주범 아닌가

브리프의 "살아있는 사실"은 "카드당 액션은 하나(투표 있으면 투표, 없으면 타로) — 이
규칙은 유지 대상"이라고 못박았다. 개수 규칙 자체는 존중한다. 다만 진짜 문제는 개수가
아니라 **뉴스 소비와 운세 게임이라는 서로 다른 범주의 CTA가 같은 카드 안에서 서로 다른
비주얼 문법(사각 박스 vs 둥근 pill)으로 경쟁**한다는 것이다. 이것도 위젯을 남긴 채
스타일만 맞추는 미봉책과, 아예 카드 밖으로 옮기는 근본책 두 갈래가 있다.

**그럼 무엇을**: 두 가지 강도로 제안한다. (a) 최소: 투표 CTA와 타로 CTA를 **완전히 같은
비주얼 토큰**(동일 pill, 동일 높이·웨이트, 라벨 텍스트만 다름)으로 강제 통일한다.
(b) 급진: 타로를 카드 반복 요소에서 빼고 **사이드바에 상시 위젯 1개**로 옮긴다(브리프가
이미 "사이드바 2개가 양옆에 있다"고 명시 — 활용 가능한 실제 공간). 카드는 콘텐츠만
남기고, 게임 유도는 매 카드가 아니라 페이지당 1회로 노출 예산을 재배분한다.

### 전제 4: "수십 개 샘플을 만들어 고르는" 접근 자체가 낭비 아닌가

운영자 요청은 "가능성을 다 보여달라"지만, 문제의 원인은 이미 진단됐다(정보 9종 과밀,
가짜 이미지 크롭, 위젯 톤 불일치). 원인이 명확한데 스타일 변주를 수십 개 늘리는 건
**같은 병을 다른 색으로 칠해보는 것**이지 새로운 정보를 만들지 않는다. 진짜 결정은
"무엇을 빼는가"라는 3개의 축(투표를 피드에 남길지, 가짜 썸네일을 쓸지, 타로를 카드마다
반복할지)에서 나오고, 이 축들의 조합만 의미가 있다 — 색상 톤·간격 몇 px 차이는
선택지가 아니라 노이즈다.

**그럼 무엇을**: 아래 변주 6개는 스타일 편차가 아니라 **위 3개 축의 서로 다른 조합**이다
(투표 존치/추방 × 가짜 썸네일 유지/폐기 × 타로 카드내/카드외). 아무 축도 안 건드리고
간격만 조정한 "안전한" 버전 하나(C-7)를 대조군으로 딱 하나만 남겨서, "역시 스타일만
고치면 증상이 재발한다"는 걸 눈으로 비교할 수 있게 했다. 그 이상 늘리지 않는다 — 축이
3개면 의미 있는 극단 조합은 이미 다 나온다.

## 1. 요구 산출물 — 레이아웃 변주 (6개)

공통 하드 제약 준수: 라이트만(다크는 밴드/푸터 전용), 좌측 액센트 보더 금지, 토큰
`--wc-burgundy` / `--wc-paper` / `--wc-card`만 사용, 데스크탑 피드 컬럼 ~600px.

---

### C-1 투표 추방형

**한 줄 의도** — 투표 위젯을 피드에서 완전히 없애서, 카드의 62%가 짊어지던 "카드 안
카드"와 높이 불균형을 원천적으로 없앤다. 대신 상세 페이지 유입 신호(칩)만 남긴다.

**구조 스케치**
```
┌─────────────────────────────────────────┐
│ [칩:토트넘]  잭 피트 브룩            3시간 │  ← 출처+말머리+시간 한 줄, 12px 400
│ 손흥민, 재계약 협상 테이블 앉는다          │  ← 제목 15px 650, 최대 2줄
│ [뱃지] 공놀이봇 · 투표중 ›                │  ← 작성자 + 투표존재 칩(클릭→상세)
│ ♡ 12   💬 4                              │  ← 좋아요/댓글, 우측 정렬 11px
└─────────────────────────────────────────┘
```
투표 있는 카드도 없는 카드도 **완전히 같은 골격** — 리듬 파괴 원인 자체가 사라진다.

**버린 것** — 투표 위젯(질문+버튼2개+안내문 통째로), 반복되는 안내문("첫 표를 던져보세요"),
썸네일(이 변주에선 텍스트 리스트로 가정, 이미지 유무와 무관하게 동일 골격 유지 목적)

**썸네일 처리** — 이 변주는 텍스트 전용 실험이므로 썸네일 슬롯 자체가 없다. 이미지가
있는 카드는 제목 앞에 32×32 정사각 축소 아이콘만 붙여 "이미지 있음"만 표시(클릭 시
상세에서 원본 노출).

---

### C-2 텍스트 전용형 (가짜 썸네일 폐기)

**한 줄 의도** — 진짜 사진이 없는 기사에 가짜 구단 이미지를 합성하지 않는다. 사진이
있는 기사만 썸네일을 달고, 없는 기사는 정직하게 텍스트 행으로 남긴다.

**구조 스케치 (사진 없는 카드)**
```
┌─────────────────────────────────────────┐
│ 토트넘 · 잭 피트 브룩                     │
│ 손흥민, 재계약 협상 테이블 앉는다          │
│ 공놀이봇 · 3시간 · ♡12 · 💬4              │
└─────────────────────────────────────────┘
```
**구조 스케치 (실사진 있는 카드만)**
```
┌───────────┬─────────────────────────────┐
│ [실사진]   │ 토트넘 · 잭 피트 브룩         │
│  88×88    │ 손흥민, 재계약 협상...        │
│  정사각    │ 공놀이봇 · 3시간 · ♡12 · 💬4  │
└───────────┴─────────────────────────────┘
```

**버린 것** — 구단 플레이스홀더 썸네일 전체(가짜 이미지 자체를 안 만듦), 투표 위젯 카드내
노출(칩으로 축소, C-1과 동일 처리)

**썸네일 처리** — 실사진이 있을 때만 88×88 정사각 크롭(중앙 크롭, 좌우 잘림 없음 —
정사각이라 crop 실수 구조적으로 불가). 실사진 없으면 슬롯 자체 미생성 → DOM 감소.
21종 플레이스홀더 자산은 이 변주에서 폐기 대상.

---

### C-3 구단 배지형

**한 줄 의도** — 가짜 히어로 이미지를 완전히 버리진 않되 "사진처럼 보이는 거짓"에서
"태그처럼 보이는 정직함"으로 격을 낮춘다. 구단 정보가 시각적으로 필요하다는 요구는
살리면서 크롭 파손 가능성을 구조적으로 제거한다.

**구조 스케치**
```
┌─────────────────────────────────────────┐
│ ⬢토트넘  잭 피트 브룩                3시간│  ← ⬢=24×24 구단 크레스트 배지(정사각)
│ 손흥민, 재계약 협상 테이블 앉는다          │
│ 공놀이봇 · ♡12 · 💬4                      │
└─────────────────────────────────────────┘
```

**버린 것** — 1200×630 히어로형 썸네일(사진 자리), 투표 위젯 카드내 노출(칩으로 축소)

**썸네일 처리** — 21종 자산을 120×120 정사각 크레스트/이니셜 배지로 **재생성**(브리프가
재생성 가능이라 명시). 텍스트("토트넘 소식" 같은 구운 글자) 제거, 로고/색상 블록만.
정사각이므로 어떤 프레임에도 크롭 손실 없음 — 이번 파손의 근본 원인(1.90:1을 1.37:1에
욱여넣기)을 재생성 단계에서 아예 없앤다.

---

### C-4 액션 통합형 (톤 강제 통일)

**한 줄 의도** — 투표는 남기되(운영 측이 완전 제거를 원하지 않을 경우의 절충안), 투표
CTA와 타로 CTA를 완전히 같은 비주얼 토큰으로 묶어 "두 종류의 액션이 따로 논다"는 증상만
정조준해서 없앤다. 위젯 자체의 존치/폐기 논쟁과 별개로 톤 문제만 푸는 안.

**구조 스케치**
```
┌─────────────────────────────────────────┐
│ 토트넘 · 잭 피트 브룩                3시간│
│ 손흥민, 재계약 협상 테이블 앉는다          │
│ 공놀이봇 · ♡12 · 💬4                      │
│ ┌───────────────────────────┐            │
│ ▸ 투표하기                  │  ← 접힌 상태, 클릭시 아코디언 펼침
│ └───────────────────────────┘            │
└─────────────────────────────────────────┘
```
펼치기 전엔 투표 카드와 타로 카드가 **완전히 동일한 높이**(pill 한 줄). 질문 텍스트·버튼
2개·안내문은 펼쳤을 때만 보여 기본 스캔 리듬을 지킨다.

**버린 것** — 투표 위젯의 기본 노출(질문+버튼+안내문 상시 표시 → 접힘 기본값으로 전환),
안내문 상시 반복 노출, 박스형 vs pill형 톤 분기

**썸네일 처리** — C-3와 동일(정사각 배지) — 이 변주는 액션 톤 문제에 집중하므로 썸네일
축은 C-3 안을 그대로 채용.

---

### C-5 사이드바 이주형

**한 줄 의도** — 타로를 카드 반복 요소에서 완전히 빼서 사이드바 상시 위젯 하나로
옮긴다. 카드는 순수 콘텐츠 스캔 리스트가 되고, 게임 유도는 페이지당 1회로 예산을
재분배한다.

**구조 스케치**
```
피드 카드 (모든 카드 동일 골격, 액션 요소 없음):
┌─────────────────────────────────────────┐
│ 토트넘 · 잭 피트 브룩                3시간│
│ 손흥민, 재계약 협상 테이블 앉는다          │
│ 공놀이봇 · ♡12 · 💬4 · [투표중 칩]        │  ← 투표 있으면 칩만, 없으면 칩도 없음
└─────────────────────────────────────────┘

사이드바 (페이지당 1개, 카드 반복 아님):
┌───────────────┐
│  오늘의 운세   │
│  [뽑기 버튼]   │
└───────────────┘
```

**버린 것** — 타로 버튼 카드 반복 노출(사이드바로 이전, 카드에는 0개), 투표 위젯 상시
노출(칩으로 축소)

**썸네일 처리** — C-2(텍스트 전용, 실사진만 정사각 소형)와 동일 원칙 — 이 변주는 액션
축 문제에 집중.

---

### C-6 정보 3단 축소형 (메타 비판 실행형)

**한 줄 의도** — "9종을 어떻게 배치할까"가 아니라 "9종 중 뭘 카드 얼굴에서 완전히 뺄까"를
가장 급진적으로 밀어붙인 안. 좋아요 수·시간처럼 의사결정에 안 쓰이는 정보를 카드 얼굴에서
제거해 정보량 자체를 줄인다.

**구조 스케치**
```
┌─────────────────────────────────────────┐
│ 토트넘 · 잭 피트 브룩                     │  ← 시간 제거
│ 손흥민, 재계약 협상 테이블 앉는다          │
│ 공놀이봇 · 💬4                           │  ← 좋아요 제거, 댓글수만(사회적 증거 최소치)
└─────────────────────────────────────────┘
```

**버린 것** — 좋아요 수(카드 얼굴에서 제거, 상세에서만 노출), 시간(카드 얼굴에서 제거,
호버/상세에서만), 투표 위젯 전체(C-1과 동일 칩 처리), 타로 버튼(카드 반복 노출 제거,
C-5와 동일 사이드바 이전), 썸네일(C-2와 동일 실사진만)

**썸네일 처리** — C-2와 동일(실사진 있을 때만 88×88 정사각, 없으면 슬롯 없음).

### C-7 온건 정리형 (대조군 — 비추천)

**한 줄 의도** — 3개 축(투표 존치 여부·가짜 썸네일 폐기 여부·타로 위치)을 하나도
안 건드리고 스타일만 다듬으면 증상이 재발한다는 걸 보여주기 위한 대조군. **채택
비추천** — 아래 변주들과 나란히 놓고 비교하는 용도로만 넣는다.

**구조 스케치**

**버린 것** — 실질적으로 없음(썸네일 비율만 104×76→맞는 crop 비율로 수정, 투표 위젯은

## 2. 추천 순위 (Contrarian 입장)

1. **C-1 + C-3 조합** (투표 추방 + 구단 배지) — 가장 근본적, 3개 증상(카드-안-카드·리듬
파괴·썸네일 파손)을 동시에 제거. 재생성 비용은 배지 21종뿐 — 감당 가능.
2. **C-5** — 타로까지 마저 빼고 싶다면. 사이드바 자리가 이미 있다는 게 핵심 근거.
3. **C-4** — 투표를 절대 못 빼는 정치적 제약이 있다면 최소 대안(톤 통일 + 접힘).
4. **C-7은 비교용으로만** — 이걸 채택안으로 고르면 브리프가 이미 예견한 실패("아무것도
안 버리는 안은 문제를 이해하지 못한 것")를 그대로 반복하는 것.
