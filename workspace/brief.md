## 0. 🎯 이번 브레인스토밍의 안건 [영범님, 2026-07-29 갱신]

**논제: 오늘 완성한 콘텐츠 자동발행 체제가 시즌 오픈 이벤트 참여율을 실제로 높이는가?**

2026-07-29 부로 콘텐츠 파이프라인이 완전 무인화됐다:
- 뉴스 자동발행: 하루 최대 20건 (사진/임베드 있는 초안만, 검수 없이)
- 커뮤 떡밥 자동발행: 하루 최대 40건 (더쿠·레딧 크롤 → 페르소나 재작성 → 자동 승인 → 20~60분 간격 분산 게시)

**질문의 본질**: 이 봇 물량이 "살아있는 커뮤니티 연출"로 신규 유입의 정착을 돕는가, 아니면 **조회 0.7짜리 물량만 쌓이고**(봇 기사 7일 52건 → 평균 조회 0.7 / 댓글 0 실측) 진짜 레버(예측 완료 직후 주입, 매치데이 공식글, 반응 유도 장치)를 놓치고 있는 것인가. 이벤트까지 남은 개발 시간을 어디에 쓸지의 우선순위 판단이 걸려 있다.

이벤트 확정 사항 (docs/EVENT_SEASON_OPEN.md):
- 유입: **Cog 채널(리버풀+첼시 공동 운영, 개인 채널 2개 포함 = 3채널 동시)** — 아스날 1채널 검증은 완료
- 팬덤 대항전 구도 (리버풀 vs 첼시), 순위는 주 1회만 공개
- 활동 포인트 추첨 — **예측만으론 응모 불가, 커뮤니티 활동(글/댓글) 최소 3회 필수** (1차의 커뮤 전환 1.5% 반면교사를 구조에 내장)
- 1차의 실측 퍼널(아래 4번)이 반면교사 재료다.

## 1. gongnori는 무엇인가 (1문단)

스포츠(축구 중심) 팬 커뮤니티 + 승부예측 플랫폼 (gongnori.fan). 가상 토큰("볼")으로 실제 경기 승부를 예측하고, 팀 담벼락에서 뉴스·글로 소통하며, 팬 활동이 팀 경기장 건설/호칭으로 쌓이는 구조. 현금 환전은 없고 점수/포인트 경제만 존재 (컴플라이언스 원칙). [repo/메모리]

## 2. 핵심 유저는 누구인가

- EPL 팬, 특히 **아스날 팬**이 핵심 (이번 이벤트가 아스날 Gooner 전용으로 리프레임됐고, 유입도 그쪽). [repo/메모리]
- 핵심 루프 가설(2026-07-19 확정): **빠른 소식 → 재접속 → 게임(예측) 참여**. 체류 공간(라이브룸 등)은 후순위. [메모리]
- 유입의 신뢰 원천은 유튜버 (팬덤 채널 시청자가 소개를 보고 옴). 플랫폼 자체 브랜드 인지는 아직 없음. [영범님+정황]

## 3. 현재 있는 기능들 (핵심만)

유저가 실제로 쓰는 것 순:
- **승부예측** (betman 연동, 토큰 베팅, 자동 정산) — 주 활동. 예측 100~200건/일 수준. [메모리]
- **담벼락/커뮤니티** (팀별 게시판, 뉴스봇 기사, 폴 위젯) — 소비 전환율 ~1%로 매우 낮음. [메모리]
- **월드컵 그룹 대결 이벤트** (/worldcup) — 이번 안건. 종료됨.
- 그 외 존재하지만 사용 미미: 경기장 건설(stadium), 메타버스(GNB 숨김), 드래프트 게임, 팬 정체성/호칭, 기자 시스템.
- 디스코드 뉴스봇 서버 구축 완료(2026-07-19) — 검수 기사 자동 전파 + 다이제스트. [메모리]

## 5. gongnori 기술 스택 (Executor 관점용) [repo]

- 프레임워크: Next.js 15 (App Router, Turbopack) + React 19 + TS strict
- Auth: Clerk (Supabase Auth 아님) / DB: Supabase (48 tables, RLS)
- UI: Radix + Tailwind 4 + shadcn / 에디터: TipTap 3 / 게임: Phaser 4
- 인프라: Vercel + Vultr 서울 VPS (betman 크롤·뉴스 crawlers cron)
- 뉴스: data/agents 멀티에이전트 뉴스룸(수동 실행) + 디스코드 봇 서버
- 계측 상태 (2026-07-29 갱신): **Sentry 클라 복원됨. 퍼널 계측 구축 완료** — 채널별 UTM 최초터치 귀속 + 가입/첫슬립/게시판 첫활동이 DB 원장(user_acquisition)에 쌓임. /admin2 채널 퍼널 카드로 조회. 즉 이번 이벤트는 채널별 정착률을 실측할 수 있다.
- 푸시/알림 채널: 웹 알림 일부 + 디스코드. 카카오 비즈앱 미신청. 모바일 앱 없음(웹).
