# 스포츠 팬 UGC 도구 조사 (공놀이 커뮤니티 적용 검토)

## 도구 목록

### 1. **Lineup Builder** (buildlineup.com, lineup11, chosen11, 11builder)
- **무엇**: 포메이션 선택 → 선수 배치 → 이미지로 저장/공유. 각 포지션마다 선수명+얼굴사진 임베드.
- **왜 공유·논쟁**: "내 일레븐이 최고다" 주장의 비주얼화. 포메이션 전술 논의+선수 평가가 동시 진행. SNS 스크린샷 전쟁.
- **DB 부담**: 선수 이미지+이름 기본 필요 (또는 자유 입력+사용자 업로드). buildlineup/lineup11은 선수DB 선 제공 (클릭으로 선택). 한국 K리그 선수 DB는 외부 소싱 필요.
- **한국 궁합**: ⭐⭐⭐ 높음. 더쿠/에펨은 "베스트XI" 스레드 문화 강함. 비주얼 이미지 없어서 텍스트 전쟁인데, 이미지 자동 생성 시 참여도 급상승 예상.
- **공놀이 적용**: `/stadium` 팀 경기장 베이스로 "우리팀 드림일레븐" 포메이션 빌더. 팬덤 결속 도구로 강함.

---

### 2. **TierMaker** (스포츠 티어표)
- **무엇**: 드래그앤드롭으로 선수/팀을 S~D 티어로 분류. 커뮤니티에 공유 가능. 템플릿 기반 (프리로드 선수 이미지).
- **왜 공유·논쟁**: 주관적 기준이 드러남 (누구를 S에? 누구는 D?). 댓글로 즉시 반박 가능. "내 취향 서열" 표현의 밈화.
- **DB 부담**: 매우 낮음. 티어 템플릿만 만들면 선수 이미지 미리로드. 추가 선수는 사용자가 직접 검색해 추가 가능. 완전 자유 입력도 지원.
- **한국 궁합**: ⭐⭐⭐⭐ 매우 높음. 한국 팬은 "순위 정하기" 취향 강함. K리그 각 팀별 티어 템플릿 + 해외 리그별 템플릿으로 확장 용이.
- **공놀이 적용**: "내가 뽑은 [팀명] 역대 레전드 티어" 또는 "현 EPL 윙어 티어". 팬덤 내 하위문화(펨코 vs 아콘 등) 표현 도구. 매우 낮은 진입장벽.

---

### 3. **ESPN Trade Machine** (NBA 선수 교환 시뮬레이터)
- **무엇**: 팀A 선수 X명 ↔ 팀B 선수 Y명 입력 → 샐러리 캡 자동 계산 → "유효한 거래인가?" 판정.
- **왜 공유·논쟁**: 현실 NBA 규칙을 따르므로 "이 트레이드는 불가능하다" vs "이렇게 하면 된다" 기술적 논쟁 생성. 복잡한 경제 규칙이 게임화 매력.
- **DB 부담**: 높음. 현재/역대 선수 풀 + 샐러리 데이터 + 팀 보유 선수 명단 필요. 자동 갱신 필수.
- **한국 궁합**: ⭐ 낮음. NBA 팬 절대수 적음. K리그는 트레이드 문화 약함. 해외 팬덤 커뮤니티는 관심 높지만 메인 타겟 아님.
- **공놀이 적용**: 축구 이적 시뮬레이터로는 변형 가능하나, 경제 규칙이 약해 매력 떨어짐. 판타지 드래프트 범위 내에서만 의미 있음.

---

### 4. **Player of the Match Voting** (경기 후 팬 투표)
- **무엇**: 경기 종료 후 진행 중인 선수 누구가 최고였나 실시간 투표. 스코어보드에 리얼타임 결과 표시. 공식/비공식 모두 운영 가능.
- **왜 공유·논쟁**: 짧은 생명주기(경기 후 2~3시간). 결과 스크린샷 공유 → "이 선수가 MOTM이라니?" 즉각적 반박. 경기력 평가의 민주화.
- **DB 부담**: 매우 낮음. 선수명만 필요 (이미지 선택사항). 투표 집계만 실행.
- **한국 궁합**: ⭐⭐⭐⭐ 높음. K리그 경기마다 "누가 핵심 선수였나" 논쟁 강함. 유명 스포츠 방송과도 연동 가능성.
- **공놀이 적용**: `/prediction` 슬립 제출 후 "경기 후 최고 선수 투표" 미니 게임. 예측 슬립과 분리된 독립 투표. 반복성 높음 (리그전 32경기 = 32번 투표 기회).

---

### 5. **Comparison Tool** (Transfermarkt/FBref 선수 비교 카드)
- **무엇**: 두 선수 통계 나란히 표시 (득점, 어시스트, 경기력 지표, xG 등). 클릭으로 상세 비교. URL 공유 가능.
- **왜 공유·논쟁**: "내가 고른 선수가 통계로는 더 낫다" 증거 제시. 주관적 팬 평가를 객관 데이터로 방어. 트위터/디스코드 토론 링크로 사용.
- **DB 부담**: 높음. 역대 선수 통계 풀 필요. 자동 갱신 및 리그별 정규화 필수. (FBref는 2026년 1월 Opta 라이선스 만료로 업데이트 중단)
- **한국 궁합**: ⭐⭐⭐ 중상. 해외 팬덤에서 매우 유행. 한국 커뮤니티도 "FBref로 봐라" 유형 논쟁 증가. K리그 선수 통계 DB는 부족.
- **공놀이 적용**: 선수 비교 기능 추가 시 공유 링크 생성. 하지만 K리그 통계 데이터 소싱 비용 높음. Betman 보유 경기 데이터 활용 검토 필요.

---

### 6. **Draft Game** (포메이션 스핀 + 선수 드래프트)
- **무엇**: 포메이션 무작위 스핀 → 해당 포메이션 선수 풀에서 순차 드래프트. 운과 선택의 조합. "이 포메이션에서 최고의 팀을 만들 수 있나?" 게임.
- **왜 공유·논쟁**: 운에만 의존하지 않음 (같은 선수 풀에서 다른 선택 가능). "내가 이렇게 드래프트하면 이 팀이 나온다" 실력 표현. 리더보드 경쟁.
- **DB 부담**: 높음. 포메이션별 선수 풀 정의 필요. 역대 시즌별 팀 명단 or 영구 "레전드" 풀 사용. 기본적으로 선수 이미지+이름 필수.
- **한국 궁합**: ⭐⭐⭐⭐ 높음. 팬들의 "보유 선수+조합" 취향 강함. K리그 각 팀별 역대 스쿼드로 템플릿 만들기 용이.
- **공놀이 적용**: `/games/draft` 현재 구현이 판타지 드래프트인데, 여기서 "포메이션 랜덤 스핀" 요소 추가. 게이미피케이션 + 팬덤 자부심 결합. 리더보드 보상(카르마/팬덤포인트) 연동.

---

### 7. **"내가 뽑은 베스트 XI" 그리드 게임** (Pick Your Team 스타일)
- **무엇**: 포지션별 선택지 4~5명 제시 → 직관적 클릭으로 1명 선택 → 다음 포지션. 모두 완성 후 최종 일레븐 시각화.
- **왜 공유·논쟁**: 빠른 의사결정(클릭 게임처럼 느껴짐). 선택 결과 이미지화되어 SNS 자연 공유. 친구들끼리 "누가 더 좋은 팀을 만드나" 대항전.
- **DB 부담**: 중간. 각 포지션별 선택지만 정의. 전체 선수를 다 로드할 필요는 없음. 필터링 (나이/국가/팀) 가능하면 재미 높음.
- **한국 궁합**: ⭐⭐⭐⭐⭐ 매우 높음. 한국 팬들이 "간단한 선택 게임" 강함. 뉴스레터/톡 공유 최적화.
- **공놀이 적용**: "EPL 중원 최고는?" / "K리그 윙어는?" 같은 포지션별 미니 투표 게임. 결과 이미지 카톡 공유 → 유입 트래픽. 댓글 논쟁 유도.

## 즉시 시도 가능한 조합 (구현 1~2주)

### A. TierMaker 클론 (제일 빠름)
- K리그 + EPL 주요 팀별 "역대 선수 티어표" 템플릿
- 드래그앤드롭 UI (라디우스, 기존 커뮤니티 컴포넌트 재사용 가능)
- 이미지 자동 렌더링 + 카톡 공유 링크

### B. Player of the Match 미니 투표 (매 경기마다)
- 경기 종료 후 4~5명 선수 투표
- 실시간 결과 그래프
- Prediction 슬립과 독립 운영

### C. "내가 뽑은 일레븐" 선택 게임 (가장 공유성 높음)
- 미드필더 선택 → 수비수 → 공격수 순차
- 각 단계 4명 선택지 (클릭하면 다음)
- 최종 이미지 생성 + 유니크 URL + 친구 도전 링크

---

## 주의사항

- **DB 선수명 매핑**: K리그·EPL 모두 현역+레전드 구분 필수 (레전드는 이미지 소싱 어려움)
- **이미지 라이선싱**: 공식 저작권 확인 (FIFA, 각 클럽 공식 이미지 또는 open-source 활용)
- **반복성**: 투표/드래프트는 "매주 새로운 선택지" 제시로 리텐션 유도
