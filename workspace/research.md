# 콘텐츠 포맷 차별화 리서치 (gongnori 용)

## 패턴 목록

1. **일일 제약 + 사회적 공유** (Wordle)
   - 포맷: 매일 1회 제약(한 퍼즐)으로 희소성 생성, 결과를 이모지 그리드로 공유 가능
   - 훅: 어제 못 본 것 = 영영 못 봄 + "내 점수" 자랑하기 = SNS 입소문
   - gongnori 응용: 일일 1회 "팬덤 예측 퀴즈" (3문제 5선지) → 맞힌 사람만 결과 공유 가능, 주간 순위

2. **반복 가능한 포맷 + 간단한 제작** (공포라디오)
   - 포맷: 음성 원본 + 음향효과 + 자막 한 장 = 매일 배포 가능한 템플릿
   - 훅: 극도로 간단하면서도 감정 전달이 극대 → "이 정도면 나도 만들 수 있을 것 같은데?" 느낌
   - gongnori 응용: "팬 스토리 낭독" (실제 팬 제출 스토리 TTS 음성 낭독 + 팀 로고 자막) 주 3회, 크리에이터 참여 유도

3. **복잡한 데이터 → 단순 시각** (Tifo Football)
   - 포맷: 전술 데이터를 짧은 텍스트+스크린샷으로 설명, "이 팀의 문제는 X" 한 문장 집중
   - 훅: 해석의 권리를 쉬운 말로 되돌려줌 = "아, 이거구나" 순간
   - gongnori 응용: "경기 분석 1분 요약" (주요 통계 3개 + 핵심 분석 140자) 매 경기 직후, 하단 투표 "누가 MVP?"

4. **아침 시간 타겟 + 개인화 큐레이션** (Morning Brew / 뉴닉)
   - 포맷: 매일 아침 고정 시간(7시) 이메일/푸시, 유저 선호도별 뉴스 3~5개 + 톤 일관
   - 훅: "아 이 시간에 이게 오겠네" = 루틴화 → 습관형 리텐션
   - gongnori 응용: "아침 공놀이 뉴스" 매일 07:00 KST 푸시 (뉴스 3개 + 예정 경기 1개 + 팬 의견 1개) + 인앱 뉴스레터 섹션

5. **인터랙티브 데이터 탐색** (The Pudding)
   - 포맷: 스크롤/클릭으로 데이터 깊이있게 탐색 가능, 각 항목마다 "next" 버튼으로 선형 스토리
   - 훅: 손으로 직접 조작 = 수동적 읽기 대신 참여 경험 → 떠나지 않음
   - gongnori 응용: "팬덤별 통계 드릴다운" (종주 팬 수 → 연령대 → 지역 → 좋아하는 선수) 인터랙티브, 매 시즌 시작 시 새로운 데이터셋

6. **일일 커뮤니티 기여 + 큐레이션** (APOD)
   - 포맷: 매일 1개 콘텐츠(사진/텍스트), 40% 커뮤니티 제출 + 전문가 기술 정보 추가
   - 훅: "내 콘텐츠가 오늘의 추천됨" = UGC의 명예욕 해소, 반복 방문
   - gongnori 응용: "일일 팬 콘텐츠 큐레이션" (팬사진 + 팬글귀 + 팬 만화) 사용자 제출 → 관리자 승인 → 메인 Featured 노출 1일

7. **규칙 기반 제약 + 스토리 추적** (Nuzleaf Challenge)
   - 포맷: 간단한 제약 규칙(게임에서 포켓몬 죽으면 OUT) 정함 → 플레이어가 여정 기록 → 커뮤니티가 순위/후기 공유
   - 훅: 단순 게임 → 규칙 추가 → 드라마 생성, 실패와 성공이 모두 콘텐츠
   - gongnori 응용: "팬 챌린지" (주제: "5경기만에 10점" 등) 제약 조건 주고 참여자가 슬립 기록 공개 → 커뮤니티가 응원 → 주간 완주자 표시

8. **변수 조작 시뮬레이터** (SimuMatch / WhatIfSports)
   - 포맷: 팀/선수 조합 선택 → 시뮬레이션 재생 → 결과 공유 가능
   - 훅: "내 상상 + 데이터" = 참여자의 가설을 검증하는 경험 → 반복 사용
   - gongnori 응용: "라인업 빌더 & 예상 점수" (선수 드래그 → 포메이션 저장 → "이 라인업이면 3점 확률 68%") 공유/비교 기능

9. **경기 전 스페큘레이션 토론** (축구 예상라인업 분석)
   - 포맷: 경기 3시간 전 자동 생성 (양팀 최근 라인업 + 부상자 + 예상 포메이션) → 커뮤니티 댓글 토론
   - 훅: "공식 라인업 발표 전까지" = 타이밍 제약이 토론 집중도 높임
   - gongnori 응용: "오늘 경기 예상 포메이션 토론방" 매 경기 kickoff 3h 전 자동 생성, 예상 라인업 시드 포함, 경기 후 실제 vs 예상 비교

10. **마이크로 테마 깊이** (떡볶이 전문 유튜버)
    - 포맷: 좁은 주제(떡볶이 하나)에만 집중, 같은 주제 반복 → 깊이 누적, 니치 팬덤 형성
    - 훅: "이 사람은 이것만 봐야 해" = 권위 & 커뮤니티 형성
    - gongnori 응용: "여돌 팬이 추천하는 팀" (각 여돌 팬층이 선호하는 구단 분석 + 구단별 여돌 팬 모임) 월간 피처 + 커뮤니티 서브게시판

## 적용 우선순위 (gongnori)

**Tier 1 (1주 구현 가능, 즉시 효과)**
- #4: 아침 뉴스 푸시 (뉴스 인프라 기존, 시간 타겟만 추가)
- #1: 일일 팬덤 퀴즈 (DB 간단, 공유 기능 기존 예측 슬립 활용)
- #3: 경기 분석 요약 (AI 파이프라인 기존, 프롬프트 최적화)

**Tier 2 (1~2주, 커뮤니티 참여 핵심)**
- #6: 일일 팬 콘텐츠 큐레이션 (UGC 컬렉션 필요)
- #9: 경기 전 예상 포메이션 토론방 (betman 데이터 + 자동 생성)

**Tier 3 (2~3주, 장기 엔지니어링)**
- #8: 라인업 빌더 시뮬레이터 (복잡 로직, 우선순위 밀림)
- #5: 인터랙티브 팬덤 통계 (D3/비주얼 엔지니어링)
