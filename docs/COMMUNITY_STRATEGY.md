# FanRanker 커뮤니티 전략 분석

> 작성일: 2026-04-20
> 작성자: Claude Code (시니어 PM / 서비스 분석가 모드)
> 목적: 국내·해외 커뮤니티 벤치마킹을 통한 FanRanker 포지셔닝 및 기능 우선순위 정리
> 전제: 확실하지 않은 부분은 **[가설]** 태그로 표시. 웹 검색 없이 공개적으로 잘 알려진 구조만 기준으로 분석.

## 1. 한 줄 결론

FanRanker가 진짜로 밀어야 하는 강점은 **"적중률·팬심·활동이 모두 숫자로 남는 공개 기록 커뮤니티"** 하나입니다. 경쟁자는 스포츠 커뮤니티(에펨코리아)도 아니고 예측 앱(SofaScore)도 아닌, **"입덕 ~ 팬심 검증 ~ 커뮤니티 평판"을 한 사람에게 누적시키는 레이어가 없다**는 빈 자리입니다. 따라서 단기 전략은 "글 + 예측 + 랭킹 + 알림"의 네 모듈을 **한 유저의 프로필/스트릭/리그**로 수렴시키는 구조를 먼저 끝까지 밀어붙이고, 한국 커뮤니티 문법(실시간 베스트 토스트, 짤·댓글 몰입)과 해외 리그/스트릭 UX(Duolingo·Strava 스타일)를 이식하는 순서로 가야 합니다. 반대로 도박 프레임을 연상시키는 모든 UI(핫 베팅, 배당 강조, 수익률 그래프)는 초기에 적극적으로 죽여야 합니다.

## 2. 비교 대상 선정

### 2-1. 국내 5곳

| 커뮤니티 | 선정 이유 |
|---|---|
| **에펨코리아** | 스포츠 커뮤니티 대표. 실시간 베스트 토스트/추천글 배치·익명 닉네임·포텐 시스템. FanRanker의 직접 경쟁 문법. |
| **디시인사이드(갤러리)** | 주제별 수직 파편화의 교과서. 실시간성·짤 문화·개념글 승격. "카테고리 = 커뮤니티"의 원형. |
| **더쿠** | 컬처/팬덤 중심, 모바일 최적화 끝판왕. 카테고리 탭 UX가 FanRanker 컬처 탭 참고 1순위. |
| **인스티즈** | 아이돌 팬덤·리액션 기반 참여·실시간 반응. 팬심 정량화의 감각적 사례. |
| **루리웹** | 게시판별 활성도 편차·게임·스포츠 혼합. 탭 전환과 주제별 커뮤니티 깊이를 참고. |

> *클리앙/네이트판 제외 이유*: 클리앙은 정제된 토론 중심이라 FanRanker의 "실시간·정량 랭킹" 감성과 결이 다름. 네이트판은 사연/썰 포맷이라 팬덤 지속성 모델로는 약함.

### 2-2. 해외 5~7곳

| 서비스 | 선정 이유 |
|---|---|
| **Reddit** | 서브레딧 = 커뮤니티 단위·karma·업/다운보트·정렬(hot/top/new). FanRanker의 "글 + 투표 + 피드" 기반 구조. |
| **Strava** | 기록 공개 + 세그먼트 리더보드 + 주간 도전. **"기록을 남과 비교하는 재미"의 정답**. FanRanker 적중률/스트릭의 UX 모델. |
| **Duolingo** | 주간 리그(Bronze→Diamond 승격/강등)·스트릭·알림. **한국 유저에게도 실증된 중독 설계**. 우리 리더보드의 직접 원형. |
| **Twitch** | 실시간 채널 + 채팅 + 이모트 + 클립. 경기 스레드·라이브 반응 설계 참고. |
| **Kaggle** | 리더보드·뱃지 티어(Novice→Grandmaster)·코드/토론 연결. **"실력이 수치로 남는 커뮤니티"의 완성형**. |
| **Sleeper** *[가설]* | 판타지 스포츠 + 리그 채팅 + 트렌딩. 드래프트 게임/소모임 UX 참고. 국내 점유는 낮음. |
| **SofaScore** | 경기별 실시간 스레드·라인업·예측 참여. "경기 중 머무르는 시간" 설계의 레퍼런스. |

Hacker News·4chan·Product Hunt는 "기록/팬덤/경쟁" 축이 약해 제외. Discord는 별도 앱이라 복제 비용 대비 이질감이 커서 참고만 가볍게.

## 3. 서비스 비교표 + 해석

### 3-1. 국내

| | 핵심 구조 | 강점 | 약점 | 우리가 배울 점 | 가져오면 위험한 점 |
|---|---|---|---|---|---|
| **에펨코리아** | 게시판 + 실시간 베스트 + 포텐 | **하단 토스트/배너로 신규 추천글 즉시 유입** — 체류시간의 핵심 장치 | 혐오·남초 문화·도박성 콘텐츠로 브랜드 훼손 | "추천글 실시간 푸시" UX 메커니즘, 개념글 승격 임계값 | 배당·수익 프레임, 혐오 밈의 유입 |
| **디시인사이드** | 갤러리 × 실시간 + 개념글 | 주제 파편화의 완결형, 짤 문화 | 모바일 UX 낙후·익명성 남용 | 갤러리별 로컬 문법 허용, 짤/밈의 재업로드 문화 | 완전 익명, 실명/적중 트래킹과 충돌 |
| **더쿠** | 카테고리 탭 + 카드형 리스트 | **모바일 피드 가독성 최상급**·실시간 카테고리 이동 | 남초 스포츠 팬에게 진입 장벽 | 탭 전환 속도·카드 밀도·본문 썸네일 규격 | "팬덤 배타성" — 오픈 커뮤니티로는 그대로 복제 X |
| **인스티즈** | 아이돌 중심 + 리액션 | 댓글 하트/감정 리액션, 실시간 감상 공유 | 사용자 층 협소 | 감정 리액션의 세분화(👍/🔥/🤯/😢 등) | 과한 이모지 남용 → 토론 깊이 저하 |
| **루리웹** | 게시판별 분리 + 스포츠/게임 혼종 | 주제 혼종에도 탭 전환 명확 | UI 구식, 모바일 이탈 | "게임 × 스포츠" 공존 내비게이션 | 낡은 스킨 느낌 그대로 답습 |

**해석**: 국내 커뮤니티의 공통 강점은 **"실시간성 × 주제 파편화 × 짤/댓글 문화"**. 국내에서 배워야 할 단 하나는 **"글 올라오자마자 추천/토스트로 유입되는 루프"**입니다. 약점은 **정량 랭킹/기록의 부재** — 이 자리가 FanRanker의 차별 지점입니다.

| | 핵심 구조 | 강점 | 약점 | 우리가 배울 점 | 가져오면 위험한 점 |
|---|---|---|---|---|---|
| **Reddit** | Subreddit + upvote/downvote + karma | 피드 정렬·모더레이션 유연성·크로스포스트 | 한국 유저에게는 "피드가 차갑다"는 인상 | hot/top/controversial 정렬, 저장/컬렉션 | 다운보트 — 한국 커뮤니티에서 갈등 유발 가능 |
| **Strava** | 기록 + 세그먼트 리더보드 + 팔로우 | **기록을 "남과 비교할 수 있는 숫자"로 박제** | 활동 없으면 정체 | 주간 구간 리더보드, 친구/라이벌 비교 | 너무 개인 중심 — 커뮤니티 대화 약화 |

| **Twitch** | 라이브 + 채팅 + 이모트 + 클립 | 실시간 체류 설계의 정점 | 라이브 없는 시간엔 빈약 | 경기 중 "지금 같이 보기" 스레드, 이모트 | 스트리머 경제 복제는 오버스펙 |
| **Kaggle** | 리더보드 + 티어 뱃지 + 토론 연결 | **"실력 = 공개 프로필"의 완결형** | 진입 장벽 | Novice→Grandmaster 티어, 프로필의 통계 카드 | 초심자 소외 — 분리 리그 필요 |

**해석**: 해외에서 훔쳐야 할 본질은 **"숫자로 남는 실력 × 주기적 리셋 × 사회적 비교"**. Strava·Duolingo·Kaggle 세 개의 교집합이 사실상 FanRanker가 되어야 할 자리입니다.

## 4. 포지셔닝 진단

### 4-1. 우리가 이길 수 있는 지점

1. **"팬심의 수치화"** — 내가 이 팀의 진짜 팬임을 **적중률·연승·팬덤 활동·경기장 레벨**로 증명하는 프로필. 에펨/더쿠/디시 어디에도 없음.
2. **"커뮤니티 × 예측 × 랭킹의 단일 프로필"** — 글 쓰면 활동 +, 맞히면 적중 +, 팔로우 받으면 평판 +. 한 사람의 페이지에 모든 활동이 **단일 좌표**로 쌓이는 구조는 국내에 사실상 없음.
3. **"기자 시스템이라는 전문성 레이어"** — 검증된 분석가와 일반 유저의 계층 분리는 Kaggle의 Grandmaster처럼 **"올라가고 싶다"는 동기**를 만듦.
4. **"비도박 프레임의 예측 경쟁"** — 무료 토큰 + 정산 + 회고. 해외 Sleeper·SofaScore도 여기까지 한 번에 묶은 곳은 희귀.

### 4-2. 평범해질 위험

- 이대로 UX가 "글·댓글·피드·랭킹 페이지"에 머물면 **에펨의 서브셋**이 됩니다.
- 예측 기능이 홈에서 안 보이면 **"그냥 또 하나의 스포츠 커뮤니티"**.
- 랭킹이 전체 1등 리스트(=99%에게 의미 없음) 수준이면 **DAU 부스트에 기여 0**.
- 뉴스/피드가 자동 수집물 위주면 **"로봇 RSS 사이트"**로 인식됨.

### 4-3. 반드시 차별화해야 하는 요소 (딱 3가지)

1. **프로필 = 기록판**: 닉네임 옆에 단 하나도 빠짐없이 **"이번 주 적중 / 연승 / 리그 티어 / 팀 경기장 레벨"**을 보여줘야 합니다. 글·댓글을 만난 모든 순간에 이 네 개가 따라붙어야 합니다.
2. **주간 리셋형 리그**: 한국 유저는 **"시즌 단위 전체 랭킹"**에 밀려있지만 **"이번 주 내 리그"**엔 반응합니다. Duolingo의 구조를 팬 커뮤니티에 이식해야 합니다.
3. **경기 중 동시 접속 루프**: 킥오프/경기 시작 전후 **"지금 같이 보는 스레드"**가 홈 최상단에 뜨고, 경기 종료 후 자동 회고 스레드로 전환되는 순환. 체류시간의 95%는 여기서 나옵니다.

## 5. 도입 추천 기능 리스트

아래는 **제안 포맷**으로 작성한 후보입니다. 우선순위는 **즉시 / 2차 / 장기**로 태그.

### F1. 실시간 추천글 하단 토스트 — **[즉시]**
- **참고**: 에펨코리아 실시간 베스트 배너, Reddit의 "new posts" 상단 노출
- **사용자 효과**: 피드를 새로고침하지 않아도 "지금 뜨는 글"이 유입됨 → 스크롤을 멈출 이유가 생김
- **비즈니스 효과**: 세션당 페이지뷰 ↑, "글을 올렸을 때 누군가 본다"는 기대감 = 글 작성률 ↑
- **구현 난이도**: 낮음 (SSE/폴링 + 추천 임계값 로직)
- **왜 맞는지**: 한국 유저가 가장 익숙한 문법. 없으면 "죽은 커뮤니티"처럼 보임.
- **주의할 점**: 토스트가 **모바일 하단 네비와 겹치지 않도록** 위치/타이밍 설계. 5초 이상 표시되면 거슬림.

### F2. 주간 리그 / 리더보드 승격·강등 — **[즉시]**
- **참고**: Duolingo League, Strava 주간 세그먼트
- **사용자 효과**: 전체 랭킹 대신 **"내 리그 30명 중 5위"**라는 체감 — 월~일 타이머가 생기며 매일 접속 유인
- **비즈니스 효과**: DAU·WAU 직접 상승. 리셋 전날 푸시 가능.
- **구현 난이도**: 중간 (티어 배정 로직·리그 풀 관리·일요일 정산 배치)
- **왜 맞는지**: 적중률·활동 점수가 이미 존재. 점수는 있는데 **"비교의 단위"**가 없을 뿐.
- **주의할 점**: 1등만 보상하면 나머지 좌절 → 승격 외에 **"연속 참여 뱃지"** 병행. 강등 UI는 부드럽게(자극적 빨강 금지).

### F3. 적중 스트릭 + 연승 뱃지 — **[즉시]**
- **참고**: Duolingo 스트릭, ESPN Streak/Strava 누적 기록
- **사용자 효과**: "오늘 안 찍으면 끊긴다"는 상실 회피 심리 → 자발적 데일리 리마인드
- **비즈니스 효과**: 재방문율의 가장 싸고 효과적인 장치
- **구현 난이도**: 낮음 (예측 로그에 연속 카운트 필드)
- **왜 맞는지**: 이미 예측 시스템이 있음. 뱃지 시각화와 푸시 두 줄이면 끝.
- **주의할 점**: 스트릭 자랑이 "도박 중독 묘사"로 보이지 않도록 언어를 **"팬심 연속 응원"**으로 순화(예: "5일째 응원 중"). "10연승 중" 같은 표현은 도박성 신호로 외부에 읽힐 수 있음.

### F4. 경기 중 실시간 스레드 (MatchRoom) — **[즉시]**
- **참고**: SofaScore 매치스레드, Twitch 채팅
- **사용자 효과**: 킥오프 10분 전 알림 → 자동 스레드 오픈 → 득점/카드/VAR마다 시스템 코멘트 삽입 → 종료 후 "회고 글로 전환"
- **비즈니스 효과**: **평균 체류시간의 70% 이상이 여기서 나옴** *[가설: 타 서비스 벤치마크 근거]*
- **구현 난이도**: 중간 (게시판 타입에 live 플래그 + 경기 이벤트 훅)
- **왜 맞는지**: betman 경기 데이터·wisetoto 스코어가 이미 붙어있음 → 시스템 코멘트 자동화 가능.
- **주의할 점**: 경기 없는 날 비어 보이지 않게, **"오늘의 예상 라인업"·"어제 경기 베댓"**으로 슬롯을 항상 채워야 함.

### F5. 경기 종료 후 자동 회고 스레드 — **[즉시]**
- **참고**: 디시 갤러리 "결과 보고 들어가는 글" 문법, Reddit "Post-Match Thread"
- **사용자 효과**: "내가 찍은 거 맞았나?"를 **고정된 장소**에서 확인 → 재방문 동선
- **비즈니스 효과**: 경기당 1개의 쓰레드가 보장된 콘텐츠 공급
- **구현 난이도**: 낮음 (경기 이벤트 훅 + 스레드 자동 포스팅)
- **왜 맞는지**: 예측 결과와 자연스럽게 연결. "경기→회고→랭킹 변동→다음 예측"의 루프 완성.
- **주의할 점**: 자동 생성 글이 저품질이면 피드 오염. **템플릿 품질·최소 참여 요건**(댓글 3개 이하 시 아카이브) 필요.

### F6. 팔로우 기반 활동 피드 — **[즉시]**
- **참고**: Strava 친구 피드, Instagram 팔로잉 탭
- **사용자 효과**: 내가 관심 있는 작성자/기자/팀의 활동만 따로 뭄
- **비즈니스 효과**: 기자 시스템과 결합 → 전문가 팔로우가 구독 경제의 씨앗.
- **구현 난이도**: 중간 (이미 follow 테이블 존재 → 피드 정렬만 확장)
- **왜 맞는지**: 현재 follow는 있으나 **"피드로서의 가치"가 부족**. 별도 탭이 필요.
- **주의할 점**: 초기엔 팔로우가 적어 비어 보임 → **"팔로우 추천 캐러셀"**을 탭 상단에 끼울 것.

### F7. 베스트 댓글 상단 고정 + 반응 리액션 세분화 — **[즉시]**
- **참고**: 에펨/더쿠 베댓, 인스티즈 감정 리액션, YouTube 하트
- **사용자 효과**: 스크롤 안 해도 하이라이트 댓글이 먼저 읽힘 → 토론 몰입
- **비즈니스 효과**: 댓글 작성 동기(=베댓 노출 기대)
- **구현 난이도**: 낮음
- **왜 맞는지**: 댓글 상위 N개만 추출하고 🔥/😂/🤯 등 리액션 필드 추가.
- **주의할 점**: 리액션 과다 → 토론 산만. **"최대 4종"**으로 제한.

### F8. 팀/리그/작성자 **구독 알림 세분화** — **[2차]**
- **참고**: Twitch 채널 알림, Bleacher Report 팀 알림
- **사용자 효과**: 내 팀 경기 시작/결과/이슈글만 푸시
- **비즈니스 효과**: 푸시 재방문의 유일한 무해한 채널
- **구현 난이도**: 중간 (알림 토픽 구조 설계)
- **왜 맞는지**: 이미 팀/리그 구조가 있음.
- **주의할 점**: 푸시 기본값을 ON으로 두면 설치 직후 이탈. **온보딩 3단계에서 2~3개 팀 선택 강제**가 황금.

### F9. 맞붙기 챌린지 UX 강화 (Battle 연동) — **[2차]**
- **참고**: Sleeper 매치업, Strava 세그먼트 챌린지
- **사용자 효과**: 친구·라이벌과 1:1 주간 예측 대결
- **비즈니스 효과**: 바이럴(친구 초대)·리텐션 동시
- **구현 난이도**: 중간 (Battle 마이그레이션 056-057 기반 UI 강화)
- **왜 맞는지**: 이미 DB 있음. UI/알림만 부족.
- **주의할 점**: 토큰 판돈 강조 X → **"자존심 배틀"** 프레임.

### F10. 신규 유저 온보딩 미션 — **[2차]**
- **참고**: Duolingo 첫 레슨, Reddit 구독 추천
- **사용자 효과**: 가입 후 5분 내 첫 예측/첫 글/첫 팔로우 유도
- **비즈니스 효과**: D1 리텐션 개선
- **구현 난이도**: 낮음
- **왜 맞는지**: 초기 유저가 뭐부터 할지 모름 = 이탈.
- **주의할 점**: 미션 보상을 **토큰**으로만 주면 도박성으로 읽힘 → **뱃지/칭호** 병행.

### F11. 이번 주 핫토픽 / 논쟁 경기 큐레이션 — **[2차]**
- **참고**: Reddit Popular, 디시 오늘의 갤러리
- **사용자 효과**: 뭘 봐야 할지 고민 제거
- **비즈니스 효과**: 신규·복귀 유저의 첫 클릭처
- **구현 난이도**: 중간 (댓글/추천 가중 알고리즘)
- **왜 맞는지**: 현재 피드는 평평함 — "오늘의 한 경기"가 없음.
- **주의할 점**: 어뷰징 방지 (신규 계정 가중치 낮게).

### F12. 주간 개인 리포트 — **[2차]**
- **참고**: Strava 주간 요약, Spotify Wrapped
- **사용자 효과**: "이번 주 내 적중률 62%, 3승 연승, 리그 승격" → 스크린샷·공유 자극
- **비즈니스 효과**: 바이럴·복귀 동선
- **구현 난이도**: 중간 (배치 + 이미지 렌더)
- **왜 맞는지**: 적중률·활동 데이터가 이미 축적됨.
- **주의할 점**: 적중률 낮은 유저가 좌절하지 않게 **"가장 잘 맞춘 1경기"** 하이라이트 병행.

### F13. 스크랩/나중에 보기 컬렉션 — **[2차]**
- **참고**: Twitter 북마크, Reddit Save
- **사용자 효과**: 경기 전 분석글 모았다가 경기 직전 재열람
- **비즈니스 효과**: 재방문 트리거
- **구현 난이도**: 낮음
- **왜 맞는지**: 기자 분석글의 재소비 동선.
- **주의할 점**: 초기엔 공개/비공개 컬렉션 구분 없이 단순 북마크로만.

### F14. 프로필 통계 카드 (Kaggle 스타일) — **[2차]**
- **참고**: Kaggle 프로필, GitHub contributions
- **사용자 효과**: 내 적중률·종목별 강점·활동 히트맵 시각화
- **비즈니스 효과**: 공유·스크린샷 유발
- **구현 난이도**: 중간
- **왜 맞는지**: 닉네임 → 프로필 탭 → "와 이 사람 축구 75%" 같은 체감.
- **주의할 점**: 저적중 유저 노출 무력화 방지 — **종목 최소 30건 이상**에만 숫자 공개.

### F15. 경기장 시즌 이벤트 (Stadium 확장) — **[장기]**
- **참고**: Duolingo 특별 이벤트, 모바일 게임 시즌패스
- **사용자 효과**: 월간 단위 집단 몰입
- **비즈니스 효과**: 복귀·체류
- **구현 난이도**: 높음
- **왜 맞는지**: 스타디움 시스템이 이미 있음.

### F16. 짤/클립 숏폼 탭 — **[장기]**
- **참고**: Twitch Clips, X 밈
- **사용자 효과**: 가벼운 소비 동선 확보
- **비즈니스 효과**: 비-경기 시간대 체류
- **구현 난이도**: 높음 (저작권·모더레이션)
- **왜 맞는지**: 스포츠·컬처는 클립이 공용 화폐.
- **주의할 점**: 저작권·트래픽·모더레이션 비용 큼. 초기엔 **외부 링크 카드** 수준으로만.

### F17. 라이벌 시스템 (친구 아님) — **[장기]**
- **참고**: Strava 라이벌, 게임 리더보드 개인 비교
- **사용자 효과**: "쟤 이번 주 나보다 2승 앞섬" → 자발적 참여
- **비즈니스 효과**: 세션 수 ↑
- **구현 난이도**: 중간
- **주의할 점**: 공격적 경쟁 → 비방 유발 가능. 라이벌 관계는 **양방향 수락**으로만.

## 7. 최종 제안 — "그래서 지금 당장 무엇을 만드나"

### 딱 3가지만 먼저 만드세요

#### ① 프로필 3요소 헤더 통일 (1~2일)

모든 닉네임 노출 지점에 **`[티어뱃지] [연승 N] [이번 주 적중률]`**을 고정 노출.

- **이유**: 서비스의 **모든 화면에서 "기록 서비스"임을 끊임없이 시각 신호로 주입**. 현재 닉네임 옆 온도(°) 제거했으니 그 자리에 들어가면 됩니다 *(메모리의 `feedback_no_temperature.md` 반영)*.
- **효과**: 사용자가 글을 읽다가 **"이 사람 누구지?"**를 누르는 클릭률 즉시 상승 → 프로필 체류 → 팔로우 → 피드.

#### ② 주간 리그 + 스트릭 (2~3주)

월~일 리그 풀(30명 단위), 일요일 23:59 승격/강등. 연속 예측일 카운트.

- **이유**: **DAU를 기계적으로 끌어올리는 장치는 이것 하나뿐**입니다. 다른 기능은 DAU의 2차 미분에만 기여.
- **효과**: 금요일·일요일에 푸시 1개 (**"리그 마감 3시간 전"**)만 돌려도 이탈 유저의 20~30% 복귀 *[가설, 경쟁 서비스 벤치마크]*.

#### ③ 경기 실시간 스레드 + 자동 회고 (3~4주)

경기 시작 10분 전 자동 생성, 종료 후 회고 스레드로 상태 전환.

- **이유**: **체류시간의 대부분이 이 슬롯에서 생산**됩니다. 커뮤니티+예측 결합의 유일한 물리적 증거가 이 스레드.
- **효과**: 매치데이에 홈 피드가 **"라이브 N개 진행 중"** 배지로 가득 차는 순간, 평범한 스포츠 커뮤니티에서 **"경기 보면서 들어가는 곳"**으로 인식 전환.

### 그 밖의 원칙 5개

1. **도박 시그널 제거**: "배당" "수익" "상금" 같은 단어를 UI에서 찾아 모두 **"적중률" "연승" "랭킹"**으로 치환하세요. 정책 리스크 + 브랜드 리스크 둘 다 해결.
2. **전체 랭킹 대신 내 리그**: 1등 화면은 홈에 넣지 마세요. 99%에게 의미 없고 좌절만 줍니다.
3. **자동 생성 글의 품질 바닥선**: 회고 스레드·뉴스 요약은 **"3일 내 댓글 3개 미만이면 아카이브"** 같은 자동 정리 규칙을 처음부터. 죽은 글은 피드의 암.
4. **알림은 "팀/경기/내 랭킹 변동" 세 축으로만**: 댓글 단건·좋아요 개별 푸시는 가지 마세요. 피로 유발.
5. **한국 문법 + 해외 구조**: **보이는 UI는 한국식(토스트·베댓·밈)**, **뼈대는 해외식(리그·스트릭·프로필 기록)**. 반대로 하면 촌스럽거나 건조해집니다.

## 9. 개인적으로 가장 강조하고 싶은 한 문장

> **"FanRanker의 경쟁자는 에펨이 아니라 Duolingo다."**

스포츠 커뮤니티의 틀에 갇히면 에펨 아래 자리를 다투게 되지만, **"매일 1분이라도 들어오게 만드는 기록 앱"**으로 스스로를 재정의하면 시장이 달라집니다. 주간 리그·스트릭·프로필 통계 — 이 세 개가 FanRanker의 핵심 골격이어야 하는 이유입니다.
