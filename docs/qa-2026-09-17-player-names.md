## 변경과 검증

- 스쿼드의 `player_id`, `source`, `status`를 읽고 같은 팀·같은 공급자 ID 체계에서만 직접 식별한다. `lfa`는 LFA, Soccerway 수확 경로인 `namu`는 Soccerway로 인정한다. `namu_pw`, `namu_league`, `operator` 등의 출처는 이름 수확 과정에서 덮어써질 수 있어 ID 체계를 추정하지 않는다.
- 공급자 ID가 다른 선수라고 말할 때 이름 폴백으로 우회하지 않는다. ID 근거 없이 같은 한글 문자열의 여러 행을 합치지 않는다. rejected를 제외하고 이적 선수의 역사 표기는 유지한다.

- 이름 폴백에서 다른 이니셜·성 일부 문자열 오매칭을 차단했다. 팀 이름/별칭이 중복돼도 첫 행을 선택하지 않는다.
