# gongnori.fan 디자인 진단 — 정 (프로덕트/UI)

> 전제부터 정리하자. "무신사·맥심처럼 힙하게"는 요구가 아니라 증상 서술이다.
> 스크린샷을 보면 이 사이트의 문제는 "무드가 없다"가 아니라 **"시스템이 위계를 안 만들고 있다"**다.
> 힙함은 폰트 하나 얹어서 나오는 게 아니라, 대비(contrast)가 있는 화면에서 나온다. 지금 화면엔 대비가 없다.
> 1인 운영이니까 아래 제안은 전부 토큰/컴포넌트 레벨이다. 페이지 리디자인은 하나도 없다.

---

## 1. 진단 — "딱딱함"의 시스템적 원인 5가지

### ① 타이포 스케일이 사실상 2단계다
홈 담벼락을 보면 게시글 제목(~15px medium), 메타(회색 12px), 이게 전부다. 히어로 이미지 카드의 오버레이 타이틀을 빼면 **화면 전체가 같은 크기·같은 굵기의 텍스트 반복**이다. 위계를 크기·웨이트가 아니라 "회색의 진하기"로만 만들고 있다. 글 상세도 마찬가지 — 제목만 볼드고 그 아래는 전부 균질한 본문 톤.
특히 치명적인 건 **숫자**다. 스포츠 프로덕트는 숫자(경기 시간 02:00, 배당, 스코어, "+2경기 더보기", 볼 10개)가 주인공인데, 지금 숫자가 본문과 같은 폰트·같은 웨이트로 흘러간다. "오늘의 경기" 위젯이 경기 일정이 아니라 회의실 예약표처럼 보이는 이유다.

### ② 무채색 95% + 브랜드 컬러보다 눈에 띄는 외부 컬러
버건디(#961e37)는 로고, 활성 탭 밑줄, "오늘의 떡밥" 필, FAB — 손에 꼽는다. 화면의 절대 다수가 흰 카드 + 연회색 배경 + 회색 텍스트. 그 와중에 우측 사이드바 **디스코드 카드가 인디고 풀필**로 페이지에서 가장 강한 컬러 블록이다. 승부예측 페이지도 마찬가지 — 월드컵 배너(버건디)를 빼면 브랜드 컬러가 배당 버튼·리그 헤더 어디에도 없다. 브랜드가 자기 집에서 세입자보다 존재감이 없다. 이게 "관리자 도구 같다"는 인상의 절반이다.

### ③ 컴포넌트가 1종류다 — 담벼락은 같은 카드 15개+의 수직 반복
데스크톱 홈 풀페이지를 보면 히어로 이미지 카드 2장 이후 **완전히 동일한 카드(제목 + 하트/댓글 + N일 전 + 우측 썸네일)가 15개 이상** 이어진다. 콘텐츠에는 이미 티어가 있다 — "✓오피셜" 체크, "★로마노/온스테인" 별, 소스명(The Athletic, BBC, Marca) 칩이 붙어 있는데 **칩만 다르고 카드는 전부 같은 대접**을 받는다. 오피셜과 4일 전 찌라시가 같은 무게. 리듬이 없으니 스크롤이 단조롭고, 단조로움이 곧 딱딱함으로 읽힌다.

### ④ 인터랙티브 요소가 정적 요소랑 구분이 안 된다 (보더·라운딩·그림자 규칙 부재)
승부예측의 배당 선택 버튼 — 이 사이트의 **핵심 전환 요소** — 이 흰 배경 + 1px 회색 보더 + 일반 웨이트 텍스트다. 비활성 input 필드처럼 보인다. 우측 사이드바 설문(기마랑이스/토날리/마페/부아디)도 똑같은 아웃라인 사각형 4개 — 와이어프레임 그대로다. 카드도 버튼도 배너도 전부 "1px 보더 + 약한 라운딩 + 그림자 없음" 한 가지 규칙이라, 누를 수 있는 것과 읽는 것의 구분이 시각적으로 존재하지 않는다.

### ⑤ 밀도 리듬이 없고, 브랜드 자산이 UI에 스며들지 않았다
좌측 사이드바는 "축구/자유 + 리소스 링크 4개"로 거의 비어 있고, 회색 광고 플레이스홀더(Medium Rectangle 300×250)가 두 군데서 "미완성 목업" 인상을 만든다. 푸터는 한 줄. 반면 모바일은 카드 하나하나가 큰 여백을 먹어서 한 화면에 글 2.5개 — 커뮤니티의 "북적임"이 안 느껴진다. 정작 이 사이트엔 좋은 브랜드 자산이 있다: 손글씨 "그깟 공놀이" 로고, 승부예측의 안경 마스코트. **마스코트는 승부예측 좌측 카드 한 곳에만 등장**하고 나머지 UI는 무표정하다. (덤: 모바일 하단 탭바가 "1 Issue" 디버그 배지에 첫 탭이 가려져 있고, FAB이 카드 썸네일을 덮는다 — 스크린샷 기준 사실만 기록.)

## 2. 낮은 비용 · 높은 효과 개선안 7가지

### 1. 타이포 스케일 재계약 (토큰) — **S**
- **무엇을**: `--wc-text-*` 스케일 정의. 리스트 제목 15→16~17px/semibold(600), 메타 12px 유지하되 시간·소스 분리(소스는 semibold, 시간은 mute), 섹션 헤더("오늘의 경기", "오늘의 설문")를 13px 대문자성 자간 스타일 or 15px bold로 승격. 숫자 전부 `font-variant-numeric: tabular-nums`.
- **왜**: 지금 위계가 회색값 하나로 지탱된다. 크기·웨이트 축 2개를 추가하는 것만으로 "문서"에서 "매체"로 넘어간다. CSS 토큰 수정만으로 전 페이지 파급.

### 2. 디스플레이 폰트 1종 — 단, **숫자·라틴 한정** — **S**
- **무엇을**: condensed 계열 산세리프(예: Barlow Condensed / Oswald 류) 1종을 웹폰트로 추가하되 적용 범위를 **경기 시간, 스코어, 배당 숫자, 볼 카운트, D-day** 로 한정. 한글 본문은 현행 시스템 산세리프(또는 Pretendard) 유지.
- **왜**: 스포츠 무드의 8할은 숫자 조판이다. "02:00 로센보르그 vs 프레드릭스타드"의 02:00이 콘덴스드 볼드가 되는 순간 전광판이 된다. 한글 디스플레이 폰트는 용량·라이선스·가독성 리스크가 커서 이 범위 제한이 1인 운영에 맞는 답이다.

### 3. 다크 서피스 "전광판 존" — 범위 한정 도입 — **M**
- **무엇을**: `--wc-surface-dark`(차콜/딥네이비) 토큰 추가하고 적용처 딱 2곳: ① 홈 "오늘의 경기" 위젯 → 다크 배경 + 흰 팀명 + 버건디 시간 = 스코어보드화. ② 승부예측 페이지 상단 밴드(탭 영역). 전면 다크모드 아님.
- **왜**: 흰 화면 바다에 다크 블록 하나가 생기면 대비 축이 생기고, 하필 그게 "경기"라는 코어 콘텐츠라 시선이 정확히 전환 지점으로 간다. 무신사·토스가 힙해 보이는 건 다크와 라이트를 **구역으로** 섞기 때문이다.

### 4. 버건디 사용 규칙 재배치 + 톤 스케일 — **S**
- **무엇을**: `--wc-burgundy-50/100/…/900` 스케일 토큰 추가. 사용 규칙 명문화: **①핵심 CTA(예측하러 가기, 배당 선택됨) ②상태(LIVE, ✓오피셜) ③활성 탭** — 이 3곳에만 진한 버건디, 배경 틴트는 50~100만. 대신 지금 아무 데도 없는 곳(오피셜 칩, 리그 헤더 액센트)에 넣는다. 디스코드 카드는 인디고 풀필 → 화이트 카드 + 버건디 액센트로 회수.
- **왜**: 브랜드 컬러는 총량이 아니라 **일관된 의미**가 있을 때 세진다. 지금은 총량도 적고 의미도 없다. 인디고가 페이지 최강 컬러인 상황부터 바로잡는 게 공짜 브랜딩.

### 5. 담벼락 카드 3티어 시스템 — **M**
- **무엇을**: post-card 컴포넌트에 tier prop: **T1** 히어로 이미지 카드(현행 유지), **T2** 오피셜/1티어 소스(로마노·온스테인) → 좌측 3px 버건디 액센트 보더 + 소스 칩 버건디 틴트, **T3** 일반 → 현행 row. 판별 로직은 이미 있는 오피셜 체크·별 데이터 재사용.
- **왜**: ③진단 직격. 같은 카드 15개 반복이 3-1-5-1 리듬으로 바뀌면 스크롤에 박자가 생긴다. 신뢰도 티어가 시각화되면 "여긴 정보가 검증되는 곳"이라는 신뢰 신호까지 겸한다 — 이게 커뮤니티의 힙함이다.

### 6. 배당 버튼·설문 버튼을 버튼답게 — **S**
- **무엇을**: 배당 선택지: 팀명 semibold + 배당 숫자(#2 디스플레이 폰트) 크게, hover 시 보더 진해짐, **선택 시 버건디 필 + 흰 글자**, radius 8px + shadow-sm. 설문 선택지 동일 패턴 + 투표 후 결과 바(버건디 틴트 게이지).
- **왜**: 핵심 전환 요소가 disabled input처럼 보이는 건 무드 문제이기 전에 매출 문제다. 상태(default/hover/selected) 3개 추가만으로 "누르고 싶은" 화면이 된다. 컴포넌트 2개 수정, 파급 최대.

### 7. 브랜드 자산 확산 — 마스코트·손글씨·푸터 — **S~M**
- **무엇을**: ① 안경 마스코트를 빈 상태(댓글 0, 광고 미판매 슬롯 — 지금 회색 300×250 목업 박스 자리)·404·완료 토스트에 배치. ② 손글씨 "그깟 공놀이"를 푸터 브랜드 블록(다크 배경 + 로고 + 한 줄 슬로건)으로 승격. ③ 광고 빈 슬롯은 자체 홍보(디스코드/승부예측)로 채움.
- **왜**: 힙한 커뮤니티의 공통점은 "사람이 만든 티"다. 자산이 이미 있는데 안 쓰고 있다 — 그리는 비용 0원, 배치만 하면 된다. 회색 목업 박스 제거는 "미완성" 인상을 지우는 최저가 수선.

## 3. 하면 안 되는 것 — "힙하게"의 함정

1. **한글 디스플레이/손글씨 폰트를 본문·리스트에 확산** — 손글씨는 로고와 푸터까지만. 리스트 제목에 들어가는 순간 가독성과 신뢰가 같이 죽는다.
2. **전면 다크모드 전환** — 뉴스·긴 글 읽는 커뮤니티다. 다크는 "존"으로만. 전면 전환은 1인 운영이 감당 못 할 대비·이미지·서드파티(TipTap 임베드, 광고) QA 비용을 만든다.
3. **버건디 대면적 배경 남용** — 이 색은 면적이 커지면 경고/손실 색으로 읽힌다. 승부예측 화면에서 특히 위험(돈 잃는 느낌). 액센트로만.
4. **그림자·그라데이션·글래스모피즘 떡칠** — "힙하게 해달라"에 대한 가장 흔한 오답. 지금 필요한 건 대비 축 2개(다크 존, 티어)지 이펙트가 아니다.
5. **라운딩 키우기로 무드 내기** — 20px+ 라운딩은 토이앱화된다. 승부예측(돈이 걸린 화면)은 오히려 각이 서야 신뢰가 산다.
6. **오피셜/루머 구분을 흐리는 강조** — T2 강조는 신뢰 티어에만. 조회수 높은 찌라시에 같은 강조를 주기 시작하면 신뢰 시스템이 광고판이 된다.
7. **빅뱅 리디자인** — 1인 운영에서 전 페이지 동시 개편은 반드시 반쯤 하다 만 상태로 배포된다. 반쯤 바뀐 사이트가 지금보다 딱딱하다.

## 4. 단계 제안

### 1주 안에 체감 (토큰·컴포넌트 수선 — 전부 S)
- #1 타이포 스케일 토큰 + tabular-nums
- #4 버건디 스케일 토큰 + 디스코드 카드 인디고 회수 + 오피셜 칩 착색
- #6 배당·설문 버튼 상태 3종
- #2 디스플레이 폰트 로드 + "오늘의 경기" 시간·배당 숫자에만 적용
- #7 중 회색 광고 목업 박스 → 자체 홍보/마스코트 교체, 푸터 브랜드 블록
- (버그성) 모바일 하단 탭 가림·FAB 겹침 정리

### 한 달 프로젝트 (구조 리듬 — M)
- #3 다크 전광판 존: "오늘의 경기" 위젯 → 승부예측 상단 밴드 순서로 2단계 롤아웃
- #5 카드 3티어: T2(오피셜 액센트)부터 vertical slice → 반응 보고 T1 배치 로직 조정
- #7 나머지: 마스코트 빈 상태 세트(댓글 0/404/완료), 모바일 피드 밀도 1단계 압축(카드 간격·패딩 축소로 화면당 3.5개)

**성공 기준 제안**: 리디자인 "느낌"이 아니라 — 배당 버튼 개선 후 슬립 제출 전환율, 오늘의 경기 위젯 다크화 후 "예측하러 가기" 클릭률. 무드 작업도 숫자로 검증한다.

## 반박 라운드 (정)

케이의 크리틱(design-critique-K.md)과 벤치마크(design-benchmark.md)를 읽고 답한다.
먼저 자세부터: 케이의 진단은 대부분 내 진단과 같은 화면을 가리킨다(버건디 점묘, 카드 무한 반복, blurple 이물감, 광고 목업 박스). 갈리는 건 **처방의 반경**이다. 그리고 인정한다 — 운영자가 요구한 건 "덜 딱딱하게"가 아니라 "무신사·브라운브레스·맥심처럼"이었고, 내 S/M 수선 목록만 실행하면 결과물은 "잘 정돈된 뉴스 리더"다. 위계는 생기지만 **태도**는 안 생긴다. 그 지점에서 케이가 옳다.

### 1. 인정할 것 — 내 목록이 못 만드는 무드

1. **카피 톤 (케이 ④) — 전면 수용.** 내 진단엔 이 축이 통째로 없었다. "예측하러 가기"가 창구 말투라는 지적은 정확하고, "오늘의 떡밥"이 이미 있는 목소리라는 관찰도 맞다. 토큰 한 줄 안 바꾸고 무드를 바꾸는 **가장 싼 개입**인데 내가 놓쳤다. 시스템 카피 사전(빈 상태·버튼·토스트·마스코트 대사)을 1주차 작업에 편입한다.
2. **이미지 트리트먼트 시스템 (케이 ③) — 원리 수용.** 나는 히어로 카드가 잘 먹힌다는 것까지만 봤고, 피를로 반 잘린 크롭·로고 스크린샷이 흰 카드에 날것으로 박히는 문제를 시스템으로 풀 생각을 안 했다. CSS 한 겹(하단 그라데이션 + 미세 다크 그레이드 + 10% 그레인 오버레이)이면 파이프라인 없이 전 썸네일에 일괄 적용된다 — 이건 S다.
3. **홈 히어로 "오늘의 메인 이벤트" 보드 (케이 ⑤) — 수용, 내 #3과 병합.** 내 "오늘의 경기 위젯 다크화"보다 케이의 "그날의 빅매치 하나를 매치 포스터로" 쪽이 상위 개념이다. 매일 바뀌는 심장박동이라는 논리는 프로덕트 논리로도 성립한다(재방문 훅). 다크 전광판 존의 1호 적용처를 이걸로 바꾼다.
4. **버건디의 면(面) 사용 — 다크 존 한정 수용.** "월드컵 배너가 사이트에서 제일 사이트다워 보인다"는 관찰은 반박 불가다. 버건디가 면으로 먹힌다는 실물 증거가 화면에 이미 있다. 내 "액센트 한정" 규칙은 라이트 존에만 적용하고, 다크 존 안에서는 면·서피스로 승격하는 이원 규칙으로 수정한다.
5. **좌측 사이드바의 약관 링크 눈높이 배치** — 케이가 잡았고 나는 "빈약하다"까지만 말했다. 푸터로 강등, 맞다.

### 2. 못 물러서는 것 — 실측 근거로

**① 베이스 전면 다크 반전 — 반대. 스코프 문제이지 취향 문제가 아니다.**

- **커뮤니티 본문 가독성**: 담벼락과 글 상세는 긴 한국어 본문 + TipTap 임베드(트위터/인스타/유튜브)로 굴러간다. 서드파티 임베드 iframe은 라이트 테마로 렌더되므로 다크 본문 한가운데 흰 박스가 뜬다 — 케이가 blurple 카드 하나에 "이물감"이라 한 그 현상이 **글마다** 재생된다. 게다가 케이 자신이 ④진단에서 지적한 언론사 원본 JPG·로고 스크린샷 문제는 다크 배경에서 더 악화된다(흰 배경 소스 이미지가 더 도드라짐).
- **광고 슬롯**: 스크린샷 기준 홈 사이드바 2곳 + 글 상세 1곳에 광고 슬롯이 있다. 네트워크 광고 크리에이티브는 라이트 기준으로 들어오고 우리가 톤을 통제할 수 없다. 다크 페이지 위 흰 광고 배너 = 매 페이지, 매 새로고침마다 무드 파괴. 광고가 실리는 서피스는 라이트로 남기는 게 광고 수익과 무드 둘 다 지키는 길이다.
- **토큰 마이그레이션 비용**: 현행 wc-* 는 라이트 단일 전제다(--wc-card=흰색, --wc-line=연회색, --wc-mute). 전면 반전은 "토큰 값만 뒤집기"가 아니다 — 토큰을 안 거친 하드코딩 유틸(bg-white, text-gray-* 계열)이 화면 전반에 깔려 있는 게 이런 코드베이스의 현실이고, 경계 표현을 보더→명도차로 재설계해야 하며, 전 페이지 대비 QA가 따라온다. 1인 운영에서 이건 한 달이 아니라 분기 프로젝트고, **반쯤 뒤집힌 채 배포되는 순간 지금보다 나빠진다.**
- **결정적으로, 케이의 레퍼런스가 전면 다크를 지지하지 않는다**: 벤치마크 파일 스스로 무신사 2025 리브랜딩을 "크림 톤 + 스테인레스"로 기록하고 있다(#13). 무신사는 라이트 베이스에 다크를 캠페인 존으로 쓴다. "무신사처럼"이 곧 "전면 다크"가 아니다.

**② 한글 컨덴스드 디스플레이 서체 — 반대.**
한글 웹폰트는 서브셋해도 라틴의 수십 배 용량이고, 헤비 컨덴스드 한글 디스플레이는 선택지·품질·라이선스가 다 좁다. 홈 LCP를 이미 1.1s대로 잡아놓은 사이트에 한글 디스플레이 폰트 로드는 측정 가능한 회귀다. 대안이 90%를 해낸다: **기존 패밀리의 최고 웨이트(800~900) + 크기 점프(히어로 28~34px) + 자간 조임**. 콘덴스드는 라틴·숫자 한정(내 #2) 유지. 케이의 "붓 텍스처를 섹션 헤더에 재사용"은 폰트가 아니라 **SVG 자산 3~4개**("오늘의 떡밥"·"오늘의 경기" 등 고정 헤더)로 수용 — 이건 용량도 라이선스도 문제없다.

**③ 벤치마크의 팔레트 교체·네온 시그널 — 반대.**
시나리오 A/C(일렉트릭 라임·사이버 핑크, 버건디 교체)는 케이 자신의 금지 조항("카지노 무드 금지")과 충돌한다. 승부예측이 있는 사이트에서 네온+다크는 정확히 슬롯머신 문법이다. 버건디는 교체가 아니라 케이 말대로 증폭 대상. 라임 시그널은 조건부 1건만 열어둔다 — **다크 존 안 LIVE 인디케이터 전용**, 그 외 사용 금지. 같은 이유로 벤치마크 #14(27° 회전 타이포, 그리드 무시)는 기각 — 1인 운영에서 유지보수 불가능하고, 요즘 화면에서 그건 힙이 아니라 템플릿 티다.

**④ 팀 컬러 듀오톤 그레이딩 — 반대.**
소스별 팀 판별 → 색 매핑 파이프라인은 1인 운영 비용을 넘고, 뉴스 사진에 팀색 틴트는 "보도 사진을 만졌다"는 신호가 돼 소스 신뢰 뱃지 시스템(케이도 지키자는 그 자산)과 충돌한다. 일괄 CSS 오버레이 1종(위 인정 ②)까지만.

### 3. 타협안 — 1인 운영으로 실행 가능한 절충 설계

**다크 스코프 (전면이 아니라 3존):**
1. **홈 최상단 "오늘의 메인 이벤트" 보드** — 매치 포스터 문법(다크 + 버건디 면 + 콘덴스드 숫자 카운트다운 + 크림 텍스트). 케이 ⑤ 수용.
2. **승부예측 메인 컬럼** — 본문 긴 글이 없고 데이터 UI 위주라 다크 비용이 가장 낮은 페이지(FotMob·SofaScore 선례). 배당 타일은 다크 위 스코어보드 타일, 선택 시 버건디 필. 단 **사이드바는 라이트 유지**(광고 격리).
3. **푸터 브랜드 블록** — 다크 + 붓글씨 로고.
담벼락 피드·글 상세는 라이트 유지 = 본문 가독성·임베드·광고 보호. 이 3존이 데이터로 검증되면 그때 확장 논의.

**컬러 규칙 (이원):**
- 라이트 존: 버건디 = CTA·상태·활성 한정 (내 #4).
- 다크 존: 버건디 = 면·서피스 허용 (케이 ① 수용), 텍스트는 순백 대신 크림 #F5EFE7 (무신사 근거, 벤치마크 #13 수용), 라임은 LIVE 전용.
- 디스코드 카드 blurple 회수는 양측 합의사항 — 1주차.

**타이포:**
- 라틴·숫자: 콘덴스드 디스플레이 (합의).
- 한글 헤드라인: 기존 패밀리 헤비 웨이트 + 히어로급 크기 점프. 한글 디스플레이 서체 도입 보류.
- 붓 텍스처: SVG 섹션 헤더 3~4개 한정.

**카피:** 케이 ④ 수용 + 가드레일 1개 — 유머·도발은 헤더, 빈 상태, 마스코트 대사, 유도 CTA까지. **돈이 걸린 확정 단계(슬립 제출 확인·정산·환불)는 명확한 표준 문장 유지.** "네 눈을 믿어?"류는 A/B로 검증.

**단계 순서 (수정판):**
- **1주차**: 기존 S 목록(타이포 토큰·버건디 스케일·배당 버튼 상태·blurple 회수·광고 목업 교체) + 시스템 카피 패스 + 썸네일 CSS 트리트먼트.
- **2~4주**: 승부예측 메인 컬럼 다크 vertical slice(배당 타일 포함) → 홈 "오늘의 메인 이벤트" 보드 → 카드 3티어.
- **분기 재논의**: 전면 다크는 위 3존의 전환·체류 데이터를 보고 결정. 데이터가 케이 편이면 그때는 내가 물러난다 — 단 그때도 광고 서피스와 임베드 처리 설계가 선행 조건이다.
