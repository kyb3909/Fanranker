# 디자인 리뷰 리포트 — "딱딱함"에서 "힙함"으로 (2026-07-27)

운영자 문제의식: **"지금 디자인이 너무 딱딱하다. 무신사·Brown Breath·맥심처럼 남자들을 유혹하는 힙한 느낌이 나야 한다."**

진행 방식: 벤치마킹 리서처(무신사·433·VERSUS·COPA90·FotMob·SofaScore·Bleacher Report 등 23개 패턴) + 아트디렉터 페르소나 "케이" + 프로덕트 디자이너 페르소나 "정"이 실제 스크린샷 5장(홈 데스크톱/승부예측/글 상세/모바일 2장)을 각자 진단 → 상호 반박 라운드 → 본 리포트로 종합. 토론 원문은 같은 폴더의 `design-critique-K.md` / `design-critique-J.md` / `design-benchmark.md`.

---

## 1. 평결

> **케이**: "그깟 공놀이"라는 이름은 펍에서 소리 지르는 놈인데, 사이트는 은행 창구 직원처럼 말하고 있다.
> **정**: 문제는 "무드가 없다"가 아니라 "시스템이 위계(대비)를 안 만들고 있다"다.

두 진단은 같은 화면을 가리킨다. **딱딱함의 정체 = 대비 부재 + 태도 부재.** 지향 무드는 두 사람 합의로 이렇게 정의됐다: **"킥오프 90분 전, 야간 조명 켜진 경기장 앞 펍"** — 참조점은 쇼핑몰이 아니라 매치데이 그래픽 문화(매치 포스터, 전광판 숫자, 테라스 말투)다.

## 2. 진단 — 딱딱함의 원인 5가지 (양측 공통)

1. **버건디가 '규정색' 취급** — 화면 95%가 흰 카드+연회색이고 버건디는 칩·FAB에 점처럼만. 심지어 디스코드 배너의 인디고가 페이지 최강 컬러 블록(브랜드가 자기 집에서 세입자보다 존재감 없음). 역설적으로 버건디가 면(面)으로 쓰인 유일한 곳(월드컵 배너)이 가장 사이트다워 보인다.
2. **타이포 스케일이 사실상 2단계** — 8500만 파운드 특종과 단신이 같은 크기·같은 웨이트. 스포츠의 주인공인 숫자(킥오프 시각·배당·스코어)가 본문과 동일 폰트로 흘러가 "오늘의 경기"가 회의실 예약표처럼 보인다. 로고 붓글씨만 혼자 힙하고 나머지는 엑셀.
3. **동일 카드 15개+ 무한 반복 — 리듬 제로** — 오피셜 체크·티어 별 데이터가 이미 있는데 칩만 다르고 카드 대접은 전부 동일. 위계가 없으니 긴장도 없다.
4. **이미지를 '자료'로 취급** — 언론사 원본 JPG가 얼굴 잘린 크롭 그대로 흰 카드에. 반면 다크 히어로 카드(비니시우스)는 매치 포스터 문법을 반쯤 갖춰 "아는데 안 하는" 상태. 회색 광고 플레이스홀더 2개는 공사장 인상.
5. **창구 직원 말투 + 인터랙션 무존재감** — "예측하러 가기", "우승자를 확인하세요". 핵심 전환 요소인 승/무/패 버튼이 비활성 input처럼 생김. "오늘의 떡밥"이라는 최고의 커뮤니티 어휘가 있는데 그 톤이 거기서 끝남.

## 3. 토론 — 쟁점별 공방과 결론

| 쟁점 | 케이 (아트디렉터) | 정 (프로덕트) | **결론** |
|---|---|---|---|
| 전면 다크 전환 | 베이스를 나이트 매치 다크로 → 반박 후 철회 | TipTap 임베드·광고 크리에이티브가 라이트로 렌더돼 글마다 이물감, wc-* 토큰이 라이트 단일 전제라 분기급 마이그레이션. 무신사 리브랜딩도 크림 톤(전면 다크 아님) | **전면 다크 기각. 다크는 3존 한정** |
| 다크 존의 크기 | "위젯 하나는 대비 축이 아니라 얼룩. 첫인상은 뷰포트 상단 밴드 전체가 톤을 선언해야 바뀐다" | 위젯 다크화 제안 → 케이 논리 수용 | **홈 최상단을 '오늘의 메인 이벤트' 다크 밴드로** (위젯+톱뉴스 히어로 통합) |

| 한글 디스플레이 폰트 | 컨덴스드 헤비 한글 도입 → LCP·라이선스 근거에 1단계 보류 수용 | 한글 웹폰트 용량 = LCP 1.1s 회귀. 대안: 기존 패밀리 헤비 웨이트(800~900)+크기 점프가 90% 해냄 | **한글 디스플레이 보류. 콘덴스드는 숫자·라틴 한정(Barlow Condensed/Oswald류)** |
| 네온 팔레트 (벤치마크 A/C안) | "라임/시안 네온은 도박장으로 직행하는 색" — 본인이 기각 | 동의 + 라임은 다크 존 LIVE 인디케이터 전용으로만 조건부 | **버건디 교체 기각. 라임 = LIVE 전용 1건만** |
| 팀 컬러 듀오톤 | 첼시 뉴스=블루 틴트 제안 | 팀 판별 파이프라인 비용 + "보도 사진을 만졌다" 신호가 소스 신뢰 뱃지와 충돌 | **기각. 일괄 CSS 트리트먼트 1종만** (다크 그레이드+하단 그라데이션+10% 그레인) |
| 카피 톤 | 창구 말투 → 테라스 말투 ("오늘 밤 픽 걸어") | 전면 수용 ("내 진단에 이 축이 통째로 없었다") + 가드레일: 돈 확정 단계(슬립 제출 확인·정산·환불)는 표준 문장 유지 | **수용 + 가드레일. 토큰 한 줄 안 바꾸는 가장 싼 무드 개입** |
| 검증 방식 | 전환율만으로 무드를 재면 영원히 회색 — 재방문·체류 병행 | 무드도 숫자로 검증 | **슬립 전환율·예측 클릭률 + 홈 재방문율·세션 체류. 히어로 밴드는 A/B** |

기각 목록 (추가): 27° 회전 타이포·그리드 무시(유지보수 불가, 템플릿 티), 붓글씨 확산(로고+푸터+SVG 섹션 헤더 3~4개까지만), 20px+ 라운딩(토이앱화), 글래스모피즘/이펙트 떡칠.

## 4. 합의된 설계

### 다크 3존 (전면 아님)
1. **홈 최상단 "오늘의 메인 이벤트" 보드** — 오늘의 경기 위젯 + 그날의 톱뉴스 히어로를 하나의 다크 밴드로 통합. 매치 포스터 문법: 다크 배경 + 버건디 면 + 콘덴스드 숫자 카운트다운 + 크림 텍스트(#F5EFE7). 그 아래 피드부터 현행 라이트 = 스캔 속도 보존.
2. **승부예측 메인 컬럼** — 긴 글이 없는 데이터 UI라 다크 비용 최저(FotMob·SofaScore 선례). 배당 버튼은 스코어보드 타일(배당 숫자 콘덴스드 크게) + 선택 시 버건디 필. **사이드바는 라이트 유지(광고 격리)**.
3. **푸터 브랜드 블록** — 다크 + 붓글씨 로고 + 한 줄 슬로건. 페이지가 다크로 열리고 다크로 닫히는 샌드위치 구조. 좌측 사이드바의 약관 링크 4종은 여기로 강등.

### 컬러 이원 규칙
- 라이트 존: 버건디 = ①핵심 CTA ②상태(오피셜·LIVE) ③활성 탭, 틴트는 50~100만. `--wc-burgundy-50~900` 스케일 토큰화.
- 다크 존: 버건디 면·서피스 허용, 텍스트는 순백 대신 크림, 라임은 LIVE 인디케이터 전용.
- 디스코드 카드 인디고 회수(화이트 카드+버건디 액센트로 재도색) — 양측 합의 1순위.

### 타이포
- 스케일 토큰: 리스트 제목 16~17px/600, 섹션 헤더 승격, 숫자 전부 `tabular-nums`.
- 콘덴스드 디스플레이(라틴·숫자 한정): 킥오프 시각·스코어·배당·볼 카운트·D-day.
- 한글 헤드라인: 기존 패밀리 헤비 웨이트 + 히어로급 크기 점프(28~34px).
- 붓 텍스처: "오늘의 떡밥"·"오늘의 경기" 등 고정 섹션 헤더용 SVG 3~4개 한정.

### 카드 3티어 (담벼락 리듬)
T1 히어로 이미지 카드(현행) / T2 오피셜·1티어 소스 → 좌측 3px 버건디 액센트 + 소스 칩 틴트 / T3 일반 row. 판별은 기존 오피셜 체크·티어 별 데이터 재사용. 신뢰 티어의 시각화 = 커뮤니티의 힙함.

### 이미지·카피
- 전 썸네일 일괄 CSS 트리트먼트(다크 그레이드+하단 그라데이션+미세 그레인), 크롭 룰 통일. 광고 빈 슬롯은 회색 목업 대신 자체 배너(디스코드/승부예측)+마스코트.
- 시스템 카피 사전: "오늘의 떡밥" 톤을 빈 상태·버튼·토스트·마스코트 대사로 확장. 단 슬립 제출 확인·정산·환불은 표준 문장.

## 5. 실행 로드맵

**1주차 (전부 S — 토큰·컴포넌트 수선)**
- 타이포 스케일 토큰 + tabular-nums
- 버건디 스케일 토큰 + 디스코드 카드 인디고 회수 + 오피셜 칩 착색
- 배당·설문 버튼 상태 3종 (default/hover/**selected=버건디 필**)
- 콘덴스드 폰트 로드(라틴·숫자) + 오늘의 경기 시간·배당 적용
- 회색 광고 목업 → 자체 홍보/마스코트, 푸터 브랜드 블록, 약관 링크 강등
- 시스템 카피 패스 + 썸네일 CSS 트리트먼트
- (버그) 모바일 하단 탭 가림·FAB 썸네일 겹침 정리

**2~4주 (M — 구조 리듬)**
- 승부예측 메인 컬럼 다크 vertical slice (배당 스코어보드 타일 포함)
- 홈 "오늘의 메인 이벤트" 다크 밴드 (A/B 권장)
- 카드 3티어 (T2 오피셜 액센트부터)
- 마스코트 빈 상태 세트, 모바일 피드 밀도 압축(화면당 3.5개)

**분기 재논의**
- 전면 다크는 3존의 전환·체류 데이터를 보고 결정. 선행 조건: 광고 서피스·임베드 처리 설계.

## 6. 버리면 안 되는 자산 (합의)

1. 붓글씨 "그깟 공놀이" 로고와 네이밍 — 리브랜딩이 아니라 **증폭** 대상
2. "오늘의 떡밥" 등 커뮤니티 어휘 — 이미 갖고 있는 목소리
3. 버건디 그 자체 — 색은 죄가 없다, 덜 쓴 게 죄
4. 소스 신뢰 뱃지(온스테인·로마노·티어) — 매거진 바이라인급 에디토리얼 권위
5. 다크 히어로 카드 — 유일하게 목표 무드에 닿은 화면, 리디자인의 씨앗
6. 정보 밀도·스캔 속도·예측 동선 — 무드는 옷이지 뼈대가 아니다

## 7. 검증 지표

배당 버튼 개선 → 슬립 제출 전환율 / 메인 이벤트 보드 → 예측 클릭률 / 무드 지표 → 홈 재방문율·세션 체류. "내가 틀렸으면 숫자가 말해줄 거고, 그 숫자는 받아들인다" (케이) — 히어로 밴드는 A/B로.
