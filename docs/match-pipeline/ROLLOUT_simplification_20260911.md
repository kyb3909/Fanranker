## 되돌릴 때

DB에 추가한 표/함수는 이전 코드와 공존할 수 있으므로 코드 복구를 위해 바로 삭제하지 않는다. 필요 시 접속 중단·기존 함수 종료 대기 후 이전 배포를 다시 promote하고 접속을 재개한다. Vercel Instant Rollback만으로 크론 설정도 복구된다고 가정하지 말고, 운영 ID와 `crons.deploymentId` 및 크론 목록을 반드시 확인한다.
