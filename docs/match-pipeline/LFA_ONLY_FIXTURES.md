# 베트맨 미판매 인기팀 경기

## 범위

베트맨 일정이 기본이다. 대상 대회의 인기팀 경기 중 베트맨에서 찾지 못한 경기만
LFA에서 보충한다. 베트맨 가짜 마켓이나 배당은 생성하지 않는다.

## 동일 처리 흐름

1. `getFixturesForDay`가 기존 대회·날짜·시각·팀 매핑을 적용한다.
2. 미판매 인기팀 경기를 `lfa_fixtures`에 등록한다. 공급자 경기 ID에 unique를 걸고,
   내부 UUID는 DB에서 한 번만 발급한다. 번역과 킥오프가 바뀌어도 UUID/투표 키는 유지된다.
3. 기존 `/match/[gameId]`에서 동일한 매치센터를 렌더한다. 전용 경기의 상세는 저장된
   LFA ID로 직접 찾는다. 번역 이름으로 다른 경기에 재매핑하지 않는다.
4. 라인업은 기존 LFA 파서와 `match_lineups` 저장소를 쓴다. 예상 라인업은 저장하지 않고,
   확정 전에는 기존 불판 생성 조건을 통과하지 못한다.
5. 기존 `lfa-warm` 및 매치센터 갱신이 같은 ID의 스코어·스탯·타임라인을 적재한다.
6. 기존 `match-threads`가 같은 posts/댓글/위젯으로 불판을 만든다.
7. 기존 `motm-sync`가 전용 경기 원장도 스캔한다. LFA의 실제 종료+양쪽 점수 증거를
   요구하고, 기존 후보 계산으로 선발과 교체 투입이 확인된 선수만 올린다.
   연장전/승부차기 진행 중에는 종료로 판정하지 않는다.

기존 주기(불판 10분, LFA 예열·MOM 15분)와 킥오프+110분 이후 MOM 스캔 조건은 유지한다.
소스가 누락한 스탯·선수·이벤트는 만들어내지 않는다. 이 변경은 즉시성 보장이 아니다.

## 늦게 들어오는 베트맨 경기

나중에 확실하게 매핑되면 `betman_game_id`를 원장에 연결하고 기존 LFA UUID를 유지한다.
베트맨 형제 마켓 ID로 들어와도 같은 매치센터·캐시·불판·MOM을 찾는다. 투표 키는
`lfa_<provider match ID>`이므로 번역 변경과 마켓 추가에 영향받지 않는다.
이미 잘못 연결된 과거 데이터나 두 개의 기존 투표를 자동으로 합치거나 삭제하지 않는다.

피드가 비거나 일부 경기가 빠져도 등록된 원장에서 일정과 링크를 복원한다. 새 원장 등록이
실패하면 오류를 로그에 남기고 존재하지 않는 UUID 링크는 내보내지 않는다.

## 제외되는 것

- 미판매 경기의 승부예측/배당/정산: 생성하지 않으며 매치센터의 예측 안내도 숨긴다.
- Soccerway 기사 기반 리포트: 별도 소스 기능이므로 LFA 전용 경기에 자동 생성하지 않는다.
- 현재 인기팀/대회 목록 확대 및 기존 오매핑 데이터 정리.

## 적용 순서와 되돌리기

1. 운영 DB 백업/적용 권한을 확인한다. 이 저장소에는 별도 스테이징 DB가 없다.
2. `20260905_lfa_fixtures.sql`을 먼저 적용한다. 신규 테이블만 추가하고 기존 데이터를
   수정하지 않는다. RLS + 권한 회수로 클라이언트 직접 읽기/쓰기를 차단한다.
3. 앱 배포 후 실제 미판매 경기에서 등록→라인업→불판→실황→FT→투표를 확인한다.
4. 롤백 시 이전 앱으로 되돌리되 신규 테이블과 생성된 불판/투표는 삭제하지 않는다.
   이전 앱에서는 전용 경기 링크가 열리지 않을 수 있으므로 사용자 동선도 확인한다.

초기 구현 당시에는 운영 DB 적용·배포·커밋을 하지 않았다. 이후 두 커밋을 main에 푸시했고,
2026-09-06 운영 DB에 이 마이그레이션을 적용했다. 트랜잭션 리허설·제약·RLS/역할 권한·REST
조회 검증 결과는 `DB_APPLIED_20260906.md`에 기록했다. 실제 운영 경기 체인 검증은 별도다.

## 회귀 테스트

최종 검증: 전체 **203개 파일 / 2,177개 테스트 통과** (`--maxWorkers=2`). 이번 경로의
아래 6개 파일은 합계 45개 테스트다. 타입 검사·수정 TS/TSX 파일 ESLint·diff 공백 검사도 통과했다.
첫 전체 실행은 관리자 잔액 조정 테스트 1건이 15초 시간 초과로 실패했고, 검사 동시 실행을
줄여 재실행했다. 테스트 시간 제한이나 판정 조건을 완화하지 않았다.

- `supplemental-fixtures.test.ts`: 등록/재수집/번역·시각 변경/늦은 마켓/저장 실패/피드 장애.
- `supplemental-lineup.test.ts`: LFA 직접 조회/예상 저장 금지/미발표 재시도/확정 저장분.
- `supplemental-motm.test.ts`: LFA FT/선발+투입 선수/진행 중·예상 라인업 차단/중복 방지.
- `thread-sweep.test.ts`: 동일 불판 생성 및 기존 ID 유지.
- `match-refresh.test.ts`: 공급자 ID 직접 해석/타 경기로 폴백 금지/스탯.
- `cup-status.test.ts`: FT/AET/PEN 종료와 진행 중 승부차기 구별.
