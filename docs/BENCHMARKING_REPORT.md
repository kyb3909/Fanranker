# FanRanker 경쟁 벤치마킹 리포트

> **분석 일시**: 2026-02-28
> **대상 사이트**: community-app-brown.vercel.app (FanRanker)
> **핵심 타겟**: ⚠️ 추측 — 한국어 사용 스포츠/엔터테인먼트 팬 (20~30대 남성 중심)
> **핵심 성공지표**: ⚠️ 추측 — DAU, 가입→활성 전환율, 예측 참여율, 재방문율
> **핵심 플로우**:
> - Flow 1: 랜딩 → 가입 → 게시판 팔로우 → 첫 글/투표
> - Flow 2: 승부 예측 탭 → 경기 선택 → 볼 베팅 → 결과 확인
> - Flow 3: 탐색 → 콘텐츠 소비 → 댓글/투표 → 재방문
>
> **비교 지역/언어**: KR 중심 + 글로벌 참고

## 3) 개선 기회 Top 20

### 1. 콘텐츠 Cold Start 해결 (크롤러 확장)

- **문제(관찰)**: 피드에 동일 게시글("아스날 16강은 레버쿠젠입니다")이 반복 노출. 10개 게시판 중 대부분이 비어있음
- **왜 문제인가**: 첫 방문자가 "콘텐츠 없는 사이트"로 인식하면 즉시 이탈. 커뮤니티 사이트의 치명적 약점
- **경쟁사는 어떻게 하는가**: 젠토토는 라이브 경기 + AI 분석으로 24시간 콘텐츠 자동 생성. 에펨코리아는 수만 명의 UGC로 피드 유지
- **개선안**: MEMORY.md에 기록된 크롤러 확장 계획(Reddit 8개 서브레딧 + 네이버 뉴스 fetcher) 즉시 실행. 게시판당 최소 10개/일 콘텐츠 확보
- **난이도**: 중
- **예상 임팩트**: 높음
- **리스크/부작용**: 크롤링 콘텐츠 품질 관리 필요. 저작권 이슈
- **측정 지표**: 게시판별 일일 콘텐츠 수 (현재 ≈2 → 목표 ≥10/일/게시판), 피드 스크롤 깊이
- **관련 화면/플로우**: 홈 피드, /explore, /community/[slug]

### 2. 온보딩 워크스루 구현

- **개선안**: 게시판 상단에 1~2줄 설명 + 규칙 링크. 메타 description에 게시판별 고유 키워드 반영
- **난이도**: 낮음
- **예상 임팩트**: 중
- **리스크/부작용**: 없음
- **측정 지표**: 게시판 페이지 오가닉 유입량
- **관련 화면/플로우**: /community/[slug]

### 17. 예측 결과 공유 기능

- **문제(관찰)**: 예측 결과를 외부(SNS, 카카오톡 등)로 공유하는 기능 없음
- **왜 문제인가**: 바이럴 성장 동력 부재. 예측 적중 시 자랑하고 싶은 심리를 활용하지 못함
- **경쟁사는 어떻게 하는가**: 젠토토 — 픽 공유센터. 글로벌 앱(PICKEM 등) — SNS 공유 카드
- **개선안**: 예측 적중 시 ①카카오톡 공유 카드 ②트위터/X 공유 ③이미지 생성(적중률 + 결과 카드)
- **난이도**: 중
- **예상 임팩트**: 중
- **리스크/부작용**: OG 이미지 동적 생성 필요
- **측정 지표**: 공유 횟수, 공유 경유 신규 가입
- **관련 화면/플로우**: /my-predictions, 예측 결과 알림

### 18. 골드 획득 경로 명확화

- **문제(관찰)**: 골드가 필요한 기능(예측 열람 500G)은 있으나, 골드를 어떻게 얻는지 불명확
- **왜 문제인가**: 수익화 퍼널 단절. 사용자가 골드 시스템을 이해하지 못하면 유료 기능 전환 불가
- **경쟁사는 어떻게 하는가**: 젠토토 — 젠스토어(캐시 충전) + 활동 포인트 수입 경로 명시
- **개선안**: ①골드 획득 방법 안내 페이지 ②활동 보상으로 골드 소량 지급 ③골드 충전 페이지 구현(향후)
- **난이도**: 낮음(안내) / 높음(결제)
- **예상 임팩트**: 중
- **리스크/부작용**: 결제 구현 시 법적 검토 필요
- **측정 지표**: 골드 보유 사용자 비율, 유료 기능 사용률
- **관련 화면/플로우**: /payments, 프로필

### 19. 피드 개인화 강화 ✅ 부분 완료

- **문제(관찰)**: 피드가 팔로우 게시판 기반이나, 비로그인/팔로우 0일 때 빈 피드. 추천 알고리즘 부재
- **왜 문제인가**: "텅 빈 피드" → 가치 인지 실패 → 이탈
- **경쟁사는 어떻게 하는가**: Reddit — 비로그인 시 인기 게시글 자동 피드. 에펨코리아 — 포텐 터짐 기본 노출
- **개선안**: ①빈 피드 시 전체 인기글 폴백 → **완료 (api/posts/route.ts)** ②온보딩에서 관심사 기반 게시판 자동 팔로우 추천 ③"이 게시판 관심있으신가요?" 인라인 추천
- **난이도**: 낮음(완료) ~ 중(추천)
- **예상 임팩트**: 높음
- **리스크/부작용**: 없음
- **측정 지표**: 빈 피드 노출 비율 (→ 0% 목표), 피드 스크롤 깊이
- **관련 화면/플로우**: / (홈 피드)

### 20. 이미지 alt 텍스트 및 접근성 보완

- **문제(관찰)**: 다수의 `<img>` 태그에 alt 텍스트 미지정. 아이콘 이미지도 alt 없음
- **왜 문제인가**: 스크린리더 사용자 접근 불가. WCAG 2.2 Level A 위반. SEO에서 이미지 검색 노출 저하
- **경쟁사는 어떻게 하는가**: 업계 전반적으로 미흡하나, FanRanker는 시맨틱 HTML 기반이 좋아 개선 여지가 큼
- **개선안**: 모든 의미있는 이미지에 서술적 alt 텍스트 추가. 장식용 이미지는 `alt=""` 명시
- **난이도**: 낮음
- **예상 임팩트**: 낮음
- **리스크/부작용**: 없음
- **측정 지표**: WCAG 2.2 Level A 준수율
- **관련 화면/플로우**: 전체 사이트
