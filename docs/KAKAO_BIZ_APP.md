# 카카오 비즈앱 신청 가이드 (2026-07-29)

> 목적: 시즌 오픈 이벤트 전 카카오 로그인 확보. **개발보다 심사 대기가 병목이므로 신청부터.**
> 신청은 영범님이 직접(사업자 정보 필요), 승인 후 Clerk 연동 개발은 Claude 가 진행.

## 왜 필요한가 (한 줄씩)

- **가입 마찰**: 유입 = 유튜브 시청자·10~20대·모바일. "카카오로 3초 가입"이 없으면 퍼널 최상단에서 이탈.
- **다계정 억제**: 카카오 계정 ≈ 전화번호 1개당 1개 → 치킨 추첨·포인트 이벤트의 다계정 어뷰징 비용을 크게 올림 (구글은 이메일 무한 생성 가능).
- 비즈앱이어야 **이메일(필수 동의)** 을 받을 수 있고, Clerk 연동에 이메일이 필수.

## 신청 절차 (약 30분)

1. https://developers.kakao.com → 내 애플리케이션 → **애플리케이션 추가**
   - 앱 이름: `공놀이판` / 회사명: `블루버드홀딩스`
   - 카테고리: **커뮤니티** (또는 스포츠) — "게임/사행성" 계열 선택 금지
2. 앱 설정 → 플랫폼 → **Web 플랫폼 등록**: `https://gongnori.fan`
3. **비즈 앱 전환** (앱 설정 → 비즈니스): 사업자등록번호 입력 → 심사
4. 카카오 로그인 활성화 + **동의항목** 설정:
   - 닉네임·프로필 사진: 선택 동의
   - **카카오계정(이메일): 필수 동의** ← 비즈앱 승인 후 신청 가능. 수집 목적 예시:
     > "회원 식별 및 계정 생성, 서비스 관련 중요 고지사항 전달을 위해 이메일을 수집합니다."
5. Redirect URI 는 Clerk 연동 시 추가 (개발 단계 — Clerk 대시보드가 제공하는 URI 입력)

## 서비스 소개 문구 (심사·앱 설명란에 그대로 사용)

> 공놀이판(gongnori.fan)은 스포츠 팬을 위한 커뮤니티 플랫폼입니다. 해외 축구 소식을
> AI 파이프라인이 자동 수집·번역·요약해 하루 20여 건 발행하고, 팀별 게시판에서 팬들이
> 그 소식을 두고 이야기를 나눕니다. 이적설의 전개를 시간순 문서로 쌓아 보여주는
> '이적 사가' 기능도 제공합니다. 여기에 더해, 무료로 지급되는 가상 포인트(볼)로 경기
> 결과를 예측하는 부가 오락 기능이 있습니다. 포인트는 구매·환전·양도가 불가능한 서비스
> 내 점수이며, 예측 결과에 따른 금전적 보상은 일절 없습니다.

프레임 원칙: **"스포츠 뉴스·커뮤니티"가 본체, 예측은 부가 오락 기능.** "베팅"이라는 단어를
신청서·설명에 쓰지 않는다.

⚠️ **예측 기능을 숨기지 않는다** (2026-08-10 확정). `/prediction` 은 비로그인도 열람
가능해서 심사자가 사이트를 열면 바로 보인다. 누락하면 사행성 의심이 아니라 **허위 신청**이
되고, 그건 재신청으로 회복되지 않는다 — 거절은 사유를 받고 보완하면 되지만(아래 "거절 시
대응") 허위는 앱 키를 잃는다. 대신 실제로 가장 큰 비중인 **뉴스·커뮤니티를 앞세워** 예측이
부가 기능임을 구성으로 보여준다. 위 문구가 그 순서다.

2. **문의 이메일 실제 수신 테스트** — 존재하지 않는 메일 기재는 R6 재반려 사유
3. ✅ **어휘 grep 0건 확인** (2026-08-10 완료): `grep -rn "베팅|배팅|프로토" components app hooks lib --include="*.ts*"` 에서 유저 노출 문자열 0건 (admin·주석·약관의 "금전 베팅 미제공" 선언 제외). "배당"도 유저 노출분 0건 (남은 건 디스코드 운영 알림·주석뿐).
   - 이번 점검에서 **라이브 공개 페이지 2곳**을 잡았다. 1차 정비가 `.tsx` 사용자 문자열을 훑었는데도 남아 있었다:

     · `/design-demo/success-modal` — "3볼 **베팅** 완료!" (미들웨어 차단 없음 = 공개)

## 사행성 판단 방어 논리 (문의·소명 요청 시 사용)

사행행위의 법적 3요소 중 **"재물을 건다"가 성립하지 않는다**:
1. 볼은 무료 지급(매일 리셋)이며 구매 불가 — 거는 재물이 없음
2. 적중해도 서비스 내 점수만 획득 — 재산상 이익 없음, 환전·환급 불가 (약관 제6조의2)
3. 경품 이벤트는 예측 성적과 무관한 **활동 기준 추첨** — 예측 결과와 보상의 연결 차단
4. 유사 선례: 다음스포츠(카카오 계열) 승부예측, 네이버 스포츠 승부예측 — 무료 포인트 예측은
   포털에서도 통용되는 오락 포맷

## 거절 시 대응

거절은 종결이 아니다 — **사유를 받고 보완 후 재신청 가능**하며 신청 이력이 불이익을 만들지
않는다. 그래서 일찍 신청할수록 좋다(사유 파악 → 보완 시간 확보). 사유별 예상 대응:
- "사행성 우려" → 위 방어 논리 + 약관 제6조의2 링크로 소명
- "서비스 확인 불가" → 심사 계정용 둘러보기 경로 안내 (비로그인도 담벼락·예측 화면 열람 가능)
- 최종 불가 시 → 구글 로그인만으로 개막 (P1 이지 P0 이 아님 — 이벤트 자체는 진행 가능)
