# 공놀이봇 디스코드 서버 — 설정 가이드 (스텝 바이 스텝)

> 작성: 2026-07-19. 설계 배경은 `docs/DISCORD_NEWSBOT_DESIGN.md`, 코드는 커밋 `6cb3ec70`(배포됨).
> **이 서버의 성격**: 사람들이 모여 떠드는 곳이 아니라 **메시지를 배달만 하는 봇 서버**.
> 그래서 핵심은 채널 만들기가 아니라 **"아무도 못 쓰게 잠그기"(6단계)** 다.
> 각 단계는 독립적이라 아무 때나 이어서 하면 된다. 막히면 Claude에게 단계 번호를 말하면 됨.

## 3단계 — 채널 골격 만들기

목표 모양:

```
📌 안내
 └ #공지
⚽ 뉴스
 ├ #해외축구-종합
 ├ #아스날
 ├ #리버풀
 └ #첼시
🏐 공놀이
 └ #오늘의-공놀이
```

- [ ] 3-1. 왼쪽 채널 목록에서 **음성 채널 `일반`에 우클릭 → 채널 삭제하기** (봇 서버에 음성 불필요)
- [ ] 3-2. 채널 목록의 **빈 공간에 우클릭 → "카테고리 만들기"** → 이름 `📌 안내` → 만들기
- [ ] 3-3. 같은 방법으로 카테고리 `⚽ 뉴스` 만들기
- [ ] 3-4. 같은 방법으로 카테고리 `🏐 공놀이` 만들기
- [ ] 3-5. 기존 채팅 채널 **`일반`에 우클릭 → 채널 편집 → 개요 탭 → 채널 이름을 `공지`로 변경** → 변경사항 저장 → 설정 닫기
- [ ] 3-6. **`공지` 채널을 마우스로 끌어서 `📌 안내` 카테고리 아래로** 이동
- [ ] 3-7. `⚽ 뉴스` 카테고리 이름 오른쪽의 **`+` 버튼 클릭 → 텍스트 채널** → 이름 `해외축구-종합` → 만들기
- [ ] 3-8. 같은 방법으로 `아스날` 채널 만들기
- [ ] 3-9. 같은 방법으로 `리버풀` 채널 만들기
- [ ] 3-10. 같은 방법으로 `첼시` 채널 만들기
- [ ] 3-11. `🏐 공놀이` 카테고리의 `+` → 텍스트 채널 `오늘의-공놀이` 만들기

> 참고: 원래 설계에는 "#피드백(유일한 쓰기 가능 채널)"이 선택 항목으로 있는데, **일단 만들지 않는다.**
> 완전 무음 서버로 시작하고, 문의가 생기면 그때 추가하는 게 관리가 편하다.

## 4단계 — 운영실(비공개) + 커뮤니티 채널 지정 정리

지금 디스코드 공식 안내 메시지(Community Updates)가 일반 채널로 들어오고 있다. 운영자 전용 비공개 채널을 만들어 거기로 옮긴다.

- [ ] 4-1. `📌 안내` 카테고리의 `+` → 텍스트 채널 → 이름 `운영실` → **"비공개 채널" 토글 ON** → 만들기 (멤버 추가는 건너뛰기 — 서버 주인은 자동으로 볼 수 있음)
- [ ] 4-2. **서버 이름 클릭 → 서버 설정 → 왼쪽 메뉴 "커뮤니티" 섹션의 "개요"** 로 이동
- [ ] 4-3. **"규칙 또는 가이드라인 채널"** 을 `#공지` 로 지정 (이미 그렇게 돼 있으면 통과)
- [ ] 4-4. **"커뮤니티 업데이트 채널"** 을 `#운영실` 로 변경 → 저장
- [ ] 4-5. `#공지` 채널에 서버 성격 안내 글 1개 올려두기 (예시 그대로 복붙 가능):

```
🏐 공놀이봇 서버에 오신 걸 환영합니다!

이 서버는 gongnori.fan의 소식 알림 서버입니다.
· ⚽ 뉴스 채널 — 해외축구 소식이 실시간으로 올라옵니다 (팀 채널은 온보딩에서 고른 팀)
· 🏐 오늘의-공놀이 — 매일 밤 11시 5분, 오늘의 경기와 볼 충전 소식이 도착합니다

대화·토론은 사이트에서 만나요 👉 https://gongnori.fan
```

## 5단계 — 역할 5개 만들기

역할은 "누가 어떤 멘션(알림)을 받는지" 표시용이다. 권한은 전부 기본값 그대로 두면 된다.

- [ ] 5-1. **서버 설정 → 역할 → "역할 만들기"**
- [ ] 5-2. 역할 이름 `아스날`, 색상 빨강 계열 → 저장 (다른 설정 손대지 않음)
- [ ] 5-3. 같은 방법으로 `리버풀` (빨강 계열)
- [ ] 5-4. 같은 방법으로 `첼시` (파랑 계열)
- [ ] 5-5. 같은 방법으로 `축구팬` (회색/초록 아무거나 — 3팀 외 유저용)
- [ ] 5-6. 같은 방법으로 `데일리알림` (아무 색) — 매일 밤 다이제스트 멘션을 받을 사람들

## 6단계 — 전체 쓰기 잠금 ★ 이 서버의 핵심

멤버 전원이 "읽기만" 가능하게 만든다. 채널마다 만질 필요 없이 **@everyone 역할에서 한 번에** 잠근다.

- [ ] 6-1. **서버 설정 → 역할 → 목록 맨 아래 `@everyone` 클릭 → "권한" 탭**
- [ ] 6-2. 검색창에 "메시지"라고 쳐서 아래 항목들을 찾아 **끈다(OFF)**:
  - [ ] **메시지 보내기** ← 제일 중요
  - [ ] **스레드에서 메시지 보내기**
  - [ ] **공개 스레드 만들기**
  - [ ] **비공개 스레드 만들기**
- [ ] 6-3. **켜진 상태로 둘 것(확인만)**: `채널 보기`, `메시지 기록 보기`, `반응 추가하기` (이모지 반응은 유일하게 허용되는 참여 — 놔둔다)
- [ ] 6-4. 변경사항 저장

> 이렇게 하면 서버 주인(사장님)은 관리자라서 계속 쓸 수 있고, 웹훅(봇)도 영향 없다. 일반 멤버만 잠긴다.

## 7단계 — 뉴스 채널을 "공지 채널"로 전환

공지 채널로 바꾸면 **다른 서버(예: 유튜버 서버)가 우리 채널을 "팔로우"** 해서 자기 서버에 자동 중계할 수 있다.

- [ ] 7-1. `#해외축구-종합` 우클릭 → **채널 편집 → 개요 탭 → "공지 채널" 토글 ON** → 저장
- [ ] 7-2. `#아스날` 도 동일하게
- [ ] 7-3. `#리버풀` 도 동일하게
- [ ] 7-4. `#첼시` 도 동일하게
- [ ] 7-5. `#오늘의-공놀이` 도 동일하게

---

## 8단계 — 온보딩 질문 설정

새 멤버가 서버에 들어올 때 "어느 팀 팬이세요?"를 물어서 역할을 자동으로 다는 기능. 디스코드 내장 기능이라 봇이 필요 없다.

- [ ] 8-1. **서버 설정 → 왼쪽 메뉴 "온보딩"** → 설정 시작
- [ ] 8-2. 진행 중 "기본 채널(Default Channels)"을 고르라고 하면 **모든 공개 채널 선택** (우리는 채널 숨김을 안 쓰므로 전부 보여줘도 됨)
- [ ] 8-3. **질문 1 만들기** — 질문: `어느 팀 팬이세요?` / 답변 옵션 4개, 각 옵션에 역할 연결:
  - [ ] `🔴 아스날` → 역할 `아스날`
  - [ ] `🔴 리버풀` → 역할 `리버풀`
  - [ ] `🔵 첼시` → 역할 `첼시`
  - [ ] `⚽ 다 본다` → 역할 `축구팬`
- [ ] 8-4. **질문 2 만들기** — 질문: `매일 밤 11시, 오늘의 경기 + 볼 충전 알림을 받을까요?` / 옵션 1개:
  - [ ] `🔔 네, 받을게요` → 역할 `데일리알림` (안 받을 사람은 그냥 선택 안 하면 됨 — 질문을 "선택 사항"으로 설정)
- [ ] 8-5. 미리보기 확인 → 활성화(저장)

> 디스코드가 "요구 조건 미충족"을 띄우면(채널 수 등) 안내 문구에 뭐가 부족한지 나온다 — 그대로 채우면 되고, 막히면 Claude 호출.

## 9단계 — 웹훅 5개 만들기

웹훅 = "이 채널로 메시지를 넣을 수 있는 비밀 주소". 우리 서버 코드가 이 주소로 뉴스를 쏜다.
**⚠️ 웹훅 URL은 비밀번호처럼 취급** — 아는 사람은 누구나 그 채널에 글을 쓸 수 있다. 어디 공개적으로 붙여넣지 말 것.

각 채널마다 반복 (5회):

- [ ] 9-1. `#해외축구-종합` 우클릭 → 채널 편집 → **연동(Integrations) → 웹훅 → 새 웹훅**
  - 이름을 `공놀이봇` 으로 변경 (선택 — 메시지에 표시되는 발신자 이름)
  - **"웹훅 URL 복사"** 클릭 → 메모장에 `해외축구-종합: (URL)` 로 붙여넣어 두기
- [ ] 9-2. `#아스날` 동일 → URL 복사·기록
- [ ] 9-3. `#리버풀` 동일 → URL 복사·기록
- [ ] 9-4. `#첼시` 동일 → URL 복사·기록
- [ ] 9-5. `#오늘의-공놀이` 동일 → URL 복사·기록

(선택) 다이제스트에 @데일리알림 멘션을 달려면 역할 ID도 하나 복사:

- [ ] 9-6. **유저 설정(톱니) → 고급 → 개발자 모드 ON**
- [ ] 9-7. 서버 설정 → 역할 → `데일리알림` 우클릭 → **"역할 ID 복사"** → 메모장에 기록

## 10단계 — Vercel 환경변수 등록 + 재배포

- [ ] 10-1. vercel.com → 공놀이 프로젝트 → **Settings → Environment Variables**
- [ ] 10-2. 아래 5개를 추가 (Environment 는 **Production** 체크, 값은 9단계에서 복사한 URL):

| Key | 값 |
|---|---|
| `DISCORD_NEWS_WEBHOOK_FOOTBALL` | #해외축구-종합 웹훅 URL |
| `DISCORD_NEWS_WEBHOOK_ARSENAL` | #아스날 웹훅 URL |
| `DISCORD_NEWS_WEBHOOK_LIVERPOOL` | #리버풀 웹훅 URL |
| `DISCORD_NEWS_WEBHOOK_CHELSEA` | #첼시 웹훅 URL |
| `DISCORD_DIGEST_WEBHOOK_URL` | #오늘의-공놀이 웹훅 URL |

- [ ] 10-3. (선택) 멘션용 — Key `DISCORD_DIGEST_MENTION`, 값 `<@&역할ID>` (9-7의 ID를 꺾쇠 안에. 예: `<@&1234567890>`)
- [ ] 10-4. **재배포** — env는 다음 배포부터 적용된다. Deployments 탭 → 최신 배포의 `⋯` 메뉴 → **Redeploy** (또는 Claude에게 "재배포 트리거해줘")

## 11단계 — 동작 테스트

- [ ] 11-1. **발행 테스트**: 사이트 관리자 뉴스 검수(`/admin/news-review`)에서 기사 1건 발행 → 몇 초 안에 해당 팀(또는 종합) 채널에 카드가 뜨는지 확인
- [ ] 11-2. **다이제스트 테스트**: Claude에게 "다이제스트 테스트 쏴줘"라고 하면 크론을 수동 실행해줌. (아니면 그날 밤 23:05 자동 발송을 기다려도 됨)
- [ ] 11-3. 카드의 링크를 눌러 사이트로 잘 이동하는지 확인 (주소 뒤에 `utm_source=discord`가 붙어 있으면 정상)

## 12단계 — 초대 링크 만들기

- [ ] 12-1. 서버 이름 클릭 → **초대하기** → 하단 **"초대 링크 편집"**
- [ ] 12-2. **잔여 유효 기간: 무제한 / 최대 사용 횟수: 제한 없음** → 새 링크 생성 → 복사
- [ ] 12-3. 이 링크를 Claude에게 전달 → 사이트 노출 작업(예측 완료 화면·사이드바 배너)에 사용

---

## 13단계 — 운영 루틴 (이후 매일)

- **뉴스 검수·발행 하루 2회** (예: 오전 1회 / 저녁 1회) — 발행 버튼만 누르면 디스코드 전파는 자동
- 서버 관리는 사실상 없음 (쓰기 잠금 + AutoMod). 주 1회 멤버 목록만 훑어보기
- 이벤트 확정 시: 유튜버에게 서버 링크 + "채널 팔로우" 안내 전달

## 이후 개발 예약 (Claude 담당)

1. 속보 자동 전송 (티커 → 팀 채널, 1일)
2. 뉴스 글 하단 "이 팀 경기 예측하기" 카드 (F14, 1~2일)
3. 사이트에 디스코드 초대 배너 (12단계 링크 나온 뒤, 0.5일)
