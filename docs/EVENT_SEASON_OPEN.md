## Problem Statement

유튜버 3채널(첼시·리버풀·아스날 팬 채널, 젊은 연령대 타겟)에서 유입될 트래픽을 받아 **가입 → 첫 예측 → 커뮤니티 정착**까지 이어지는 온보딩 이벤트를 설계한다. 핵심 제약: 예측만 소비하고 증발하는 트래픽이 아니라 **커뮤니티(게시판)로 넘어오는 트래픽**이어야 한다.

## Demand Evidence

- 월드컵 이벤트(2026-06-28~): 32강~16강 슬립 **1,175건**, 일 50~200건 — 예측 루프는 실전 검증됨.
- 시스템 안정성: 월드컵 기간 중 정산·동기화·이벤트 풀 플로우 정상 작동 확인(2026-07-08 사용자 확인).
- **반증 데이터**: 콘텐츠 소비 전환 ~1% (예측 100~200/일 대비 게시판 열람 1~2명). 자발적 전환은 실패로 검증됨 → 이번 이벤트의 전환 장치는 "유도"가 아니라 "구조"여야 함.

## Status Quo

- 타겟 유저(젊은 EPL 팬)는 유튜브 댓글창·오픈채팅·기존 대형 커뮤니티(해축갤 등)에서 활동. 예측은 프로토/베트맨 실물 또는 안 함.
- 우리 사이트: 게시판은 축구만 활성(온보딩 축소 상태), 예측은 작동, 팬 정체성(flair·호칭 141종)·활동점수 시스템 구축 완료.
- **재사용 자산**: 월드컵 이벤트의 3팀 그룹 구조(event_groups에 kop/blues 행 잔존), 그룹 평균 리더보드, 순위 스냅샷 공개 장치(2026-07-08 구축, `WORLDCUP_SCORING_SNAPSHOT_AT` 패턴), flair 활동점수 체계(글 +10/댓글 +1/추천 +1, 삭제 시 자동 회수 — 이벤트 포인트는 이 트리거를 재사용하지 않고 설계 패턴만 참조).

## Target User & Narrowest Wedge

- **타겟**: 첼시·리버풀·아스날 유튜버 3채널의 구독자, 10~20대. 팀 정체성이 강하고 인증·경쟁 문화에 익숙.
- **쐐기**: "우리 팬덤 vs 쟤네 팬덤 승부예측 대항전 + 유니폼 추첨". 범용 커뮤니티 가입 권유가 아니라, 자기 팀을 위해 싸우는 이벤트 하나로 진입.

## Constraints

- 커뮤니티 전환이 이벤트 구조에 내장돼야 함 (1% 교훈).
- 사행성 컴플라이언스: **베팅 재화(볼/점수)의 현금성 환전 금지 원칙 유지.** 경품은 무상 참가 마케팅 이벤트의 경품으로 별개 영역 — 참가에 금전 투입이 없으므로 사행행위 구성요건(재산상 손실 위험) 자체가 성립하지 않음. 보너스 상품의 "성적 상위권 중 추첨"도 같은 이유로 허용(순위 직결 확정 지급이 아닌 추첨 유지).
- 지는 팬덤의 중도 이탈 방지 (월드컵 스냅샷 정책과 동일한 문제의식).
- 가입 마찰 최소화: 젊은 타겟에게 본인인증류 장벽 금지.
- 예산: 상품 실물 기준 약 195~205만원 선 (아래 상품 구성 + 보너스 상품 ~20만원 포함).

## Premises

1. **예측만으로는 응모가 불가능해야 한다** — 커뮤니티 활동이 응모 자격에 포함되지 않으면 월드컵의 1% 전환이 재현된다.
2. **강제하는 활동은 "매치데이 글 댓글"이지 "글 작성"이 아니다** — 흩어진 억지 글은 도배로 보이고, 한 판에 모인 댓글은 커뮤니티를 살아있어 보이게 한다.
3. **경품은 유입 스파크, 정착은 콘텐츠** — 강제 접촉 시점에 볼거리(대항전 현황·매치데이 글·뉴스)가 준비돼 있어야 전환이 일어난다.
4. **팀 순위는 실시간 비공개, 주 1회 공개** — 격차 실시간 노출 = 하위 팀 이탈. 주간 발표는 역전 희망 유지 + 매주 콘텐츠 비트 생성.
5. **실명인증은 도입하지 않는다** — 신원 수집은 5만원 초과 경품(유니폼) 당첨자 5명에게만, 수령 단계에서.

## Approaches Considered

### Approach A: 유도만 (자연 동선)
예측 완료 화면 CTA + 팀 본부 위젯으로 게시판 유도. 강제 없음.
- Effort: S / Risk: High
- Pros: 마찰 없음, 글 품질 유지
- Cons: 월드컵 1% 데이터가 실패를 예고. 유도만으로는 안 넘어옴.

### Approach B: 강제만 (응모 조건)
추첨 응모 = 예측 N회 + 게시판 글/댓글 조건. 동선 설계 없음.
- Effort: S / Risk: Med
- Pros: 전환 100% 보장
- Cons: "응모합니다" 도배 위험, 접촉 이후 정착 장치 부재.

### Approach C (채택): 포인트 통합 + 구조 결합
활동 포인트(예측+커뮤니티)로 응모 자격을 통합하고, 자연 동선(A)과 가벼운 강제(B)를 함께 설계.
- Effort: M / Risk: Low
- Pros: 전환 보장 + 도배 방지 + 기존 flair 점수 인프라 재사용
- Cons: 셋 중 개발 범위 가장 큼 (그래도 대부분 재사용)

## Recommended Approach — 이벤트 설계 전문

### 1. 기본 구조: 오픈 기념 활동 포인트 추첨
- 이벤트 기간 내 **활동 포인트 기준점 이상** 달성한 유저 전원을 대상으로 추첨. 티어 간 중복 당첨 없음(상위 티어 당첨 시 하위 제외), 추첨은 자격자 균등 확률.
- **포인트는 이벤트 전용 원장(신규 테이블)** — 기존 flair 활동점수(평생 누적, 호칭용)와 별개. flair 점수를 건드리지 않고 이벤트 기간 내 활동만 자체 집계한다. 적립 대상과 수치(수치는 확정 필요, 원칙 고정):

| 활동 | 포인트 | 일일 상한 |
|---|---|---|
| 승부예측 1회 | +2 | 10점 |
| 매치데이 공식글 댓글 | +2 | 10점 |
| 일반 게시글 댓글 | +1 | 5점 |
| 게시판 글 | +10 | 20점 |
| 받은 추천 | +1 | 10점 |

- **응모 기준: 총점 X점 + 커뮤니티 활동 최소 3회** (커뮤니티 활동 = 매치데이 댓글·일반 댓글·게시판 글 합산) — 예측만으로는 응모 불가(전제 1).
- 스팸 4중 방어: 일일 상한 / 이벤트 기간 내 삭제된 글·댓글은 원장에서 점수 회수 / 당첨자 발표 전 활동 수동 검수(무성의 도배 시 당첨 취소 약관) / **다계정 검수** — 계정 생성일·중복 배송지·행동 패턴 확인, 약관에 다계정 참여 시 전 계정 실격 조항 명시.

### 2. 상품 구성 (총 36명 — 보너스 1명 포함 + 전원 보상. 전 상품 간 중복 당첨 없음, 보너스 포함)

| 티어 | 상품 | 인원 | 예상 비용 |
|---|---|---|---|
| 대상 | 이번 시즌 유니폼 (+선수 마킹 옵션 권장) | 5명 | ~75만 (마킹 시 ~85만) |
| 중간 | 스팀 기프트카드 5만원 | 10명 | 50만 |
| 볼륨 | BBQ 치킨 | 20명 | ~50만 |
| 보너스 | 대항전 승리팀 미스터리 상품 (§3) | 1명 | ~20만 |
| 전원 | 한정 호칭 "창단 멤버" (응모 기준 달성자 전원) | 무제한 | 0원 |

- 볼륨 티어 20명 = "나도 될 만하다" 체감 확률 담당. 한정 호칭 = 낙첨자 빈손 방지 + 영구 잔류 유인.
- 유니폼은 클럽 공식 스토어 정품 필수 (짝퉁 논란 = 팬덤 신뢰 즉사).

### 3. 팬덤 대항전 (첼시 vs 리버풀 vs 아스날)
- **팀 소속 규칙**: 이벤트 참가 = 3팀 중 택1로 event_group 가입(해당 팀 플레어 자동 등록). 3팀 외 팬도 3팀 중 하나를 골라 참가 가능(유니폼도 선택한 팀 것). **이벤트 중 팀 변경 불가.**
- 팀 승리 기준: **팀별 예측 평균 성적** (월드컵 리더보드 방식 재사용). 소표본 왜곡 방지: **유효 참여자(슬립 5개 이상 제출자)만 평균 산입.** 동점 시 팀 적중률 → 유효 참여자 수 순으로 판정.
- **보너스 상품**: 이긴 팀의 **예측 성적 상위 20명 중 추첨 1명**에게 비공개 상품 증정 (성적은 자격 필터, 지급은 추첨 — Constraints의 컴플라이언스 정리 참조).
- 비공개 상품은 "???"로 가리고 **이벤트 2주차에 공개** → 유튜버 중간 점검 영상 소재 (노출 2회 확보). 상품은 유니폼보다 한 급 위 (풀옵션 유니폼+굿즈 박스 또는 유튜버 싸인템).
- **공개 정책**: 참여자 수·누적 슬립 수는 실시간 노출, **팀 순위·평균 성적은 주 1회만 공개** (월요일 팬덤 순위 발표). 월드컵 스냅샷 컷오프 패턴을 주간 반복형으로 일반화해 사용.

### 4. 커뮤니티 동선 (전제 2·3 구현)
- **매치데이 공식글**: 매 경기 자동/운영 게시 ("오늘 아스날 vs 첼시, 어떻게 보세요?"). 댓글 = 포인트. 댓글이 모이는 단일 판 = 살아있는 커뮤니티 연출.
- **예측 완료 직후 주입** (검증된 최대 레버): 완료 화면에 "포인트 +2 적립, 응모까지 N점 · 우리 팀 본부 가기 →".
- 마이페이지/이벤트 페이지에 **포인트 진행바** ("응모 자격까지 32점").

### 5. 온보딩 퍼널
```
유튜버 영상 (채널별 UTM 링크) → 이벤트 랜딩 → 팀 선택(플레어 등록) → 가입(카카오/구글 — 네이버는 P2 옵션)
→ 첫 예측 (볼 지급) → 완료 화면 포인트 주입 → 매치데이 글 댓글 → 재방문(일일 볼 리셋 23:00)
```
- 비로그인도 이벤트 안내·대항전 현황 열람 가능, 예측 버튼에서만 가입 요구.
- 채널별 UTM으로 유튜버별 유입 성과 측정 → 유튜버에게 리포트 제공(협업 지속 유인).

### 6. 하지 않는 것 + 당첨자 처리
- **실명인증/본인인증 전면 도입 안 함** (전제 5). 유니폼·보너스 당첨자(6명)만 수령 단계에서 신원·배송 정보 수집(제세공과금 처리, 개인정보 동의 포함). 스팀 5만원권·치킨(30명)은 과세 최저한 이하라 **과세용 신원은 불요하되, 전달용 연락처(카톡/문자)는 수집** — 두 정보는 목적·항목을 구분해 고지.
- **미성년 당첨자**: 5만원 초과 경품(유니폼·보너스) 당첨 시 법정대리인 동의서 수령 후 지급. 약관에 명시.
- 현금성 보상 없음 (컴플라이언스 유지).

## Open Questions (사용자 확정 대기)

1. **이벤트 기간** — 제안: 시즌 개막(8월 중순) 후 4주.
2. **유튜버 3채널 협의 상태** — 확정/접촉 중 여부. 미스터리 상품 공개(2주차) 영상 협조 가능 여부.
3. **포인트 수치·응모 기준점 확정** — 원칙(예측만으로 응모 불가)은 합의됨, 숫자만 미정.
4. **보너스(미스터리) 상품 실물** — 풀옵션 유니폼 박스 vs 유튜버 싸인템.
5. **예산 상한 최종 확인** — 현재 구성 약 195~205만원 (보너스 상품 포함).

## Success Criteria

- 가입 전환: 이벤트 랜딩 → 가입 (측정 체계 신설 필요, 목표치는 첫 주 데이터로 캘리브레이션)
- 첫 예측 전환: 가입 → 24시간 내 첫 슬립 제출 ≥ 50%
- **커뮤니티 전환: 이벤트 참여자의 게시판 활동(댓글 1회 이상) ≥ 30%** (월드컵 1% 대비 30배 — 응모 조건이 이걸 구조적으로 담보)
- 리텐션: 이벤트 종료 2주 후 주간 재방문 잔존 ≥ 15%
- 채널별 유입: UTM 기준 유튜버별 기여 측정 가능 상태

## Dependencies (개발/운영 준비물)

**개발 (P0 = 트래픽 받기 전 필수 / P1 = 이벤트 개시 전 필수 / P2 = 컷 가능)**

## What I noticed about how you think

- "맨날 치킨이나 이런 건 너무 구려서" — 타겟 유저의 눈으로 상품을 고르는 감각이 있음. 그리고 치킨을 볼륨 티어로 다시 받아들인 것도 역할 분리를 이해했다는 신호.
- "그게 커뮤니티로도 트래픽이 넘어오게끔 해야 하거든" — 이벤트를 트래픽 이벤트가 아니라 정착 장치로 정의한 건 본인이 먼저였음. 1% 데이터를 이미 체감하고 있었다는 뜻.
- "승리하는 팀에게는 하나의 상품이 더 공개되고" — 미스터리 박스 + 팀 스테이크를 직접 설계함. 메인 상품과 분리해서 얹은 구조라 하위 팀 이탈 문제를 자연스럽게 피해갔음.
- 실명인증을 먼저 꺼낸 건 운영자 관점(부정 방지·세금)이 이미 작동한다는 것. 다만 그 해법이 유저 마찰로 전가되지 않게 조정한 것이 이번 세션의 가장 중요한 수정.
