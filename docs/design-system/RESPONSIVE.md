## Breakpoint — 실질적으로 2단이다

Tailwind 기본값을 쓴다. 실측 사용 분포:

| 접두사 | 최소 폭 | 사용 횟수 | 판정 |
|---|---:|---:|---|
| `sm:` | 640px | **401** | 주력 — 모바일 ↔ 그 외 |
| `lg:` | 1024px | **161** | 주력 — 데스크톱 2단 레이아웃 |
| `md:` | 768px | 21 | 드묾 |
| `xl:` | 1280px | 2 | 거의 안 씀 |
| `2xl:` | 1536px | 0 | 안 씀 |

**결론: 이 사이트는 `sm` / `lg` 두 지점으로 돌아간다.**
새 코드도 그 둘만 쓴다. `md`·`xl`은 정말 필요할 때만.

```tsx
// ✅
<div className="grid gap-4 lg:grid-cols-[minmax(0,1fr)_300px]">
<p className="text-[20px] sm:text-[26px]">

// ❌ 임의 breakpoint — 현재 TSX 에 0곳이다. 지키자.
<div className="min-[760px]:flex">
```

## 3단 사고 모델

| 구간 | 폭 | 레이아웃 |
|---|---|---|
| 모바일 | ~639px | 1열. 하단 탭바 노출. 사이드바 숨김 |
| 태블릿 | 640~1023px | 1열 + 넉넉한 여백. 헤더 GNB 노출, 탭바 유지 |
| 데스크톱 | 1024px~ | 2~3열 (본문 + 우측 레일 300px). 탭바 숨김 |

콘텐츠 최대 폭: **1280px** (`max-w-[1280px]`), 좌우 패딩 `px-6 sm:px-10`.

---

## 원칙

1. **모바일 우선.** 기본 클래스가 모바일이고 `sm:`/`lg:`로 넓혀 나간다.
   `max-*` 방향으로 좁히지 않는다.

2. **사이드바는 `lg`에서만.** 우측 레일(300px)은 `lg:` 이상에서 등장한다.
   모바일에서 레일 내용이 필요하면 **탭 안으로** 넣는다 (매치센터 미니 순위표가 그 예).

3. **한쪽이 비면 접는다.** 2열 그리드에서 한쪽 데이터가 0일 수 있으면 1열로 떨어뜨린다.
   `/explore`에서 이걸 안 해서 **655px 흰 벽**이 생겼다.

4. **넓은 콘텐츠는 자기 안에서 스크롤한다.** 표·코드·도면은
   `overflow-x: auto` 컨테이너에 넣는다. `body`가 가로로 스크롤되면 안 된다
   (globals.css에 `overflow-x: hidden` 방어가 있지만 그건 최후 수단이다).

5. **모바일 하단 여백.** 탭바(56px)와 safe-area를 피해야 하는 콘텐츠는
   `.safe-area-pb-tabbar` 유틸을 쓴다. `pb-[env(...)]` 임의값 금지 —
   Turbopack dev에서 하이드레이션 불일치를 낸 전례가 있다.

## 네비게이션 대응표

데스크톱 GNB와 모바일 탭바는 **같은 목적지를 담는다.**

| 데스크톱 GNB | 모바일 탭바 |
|---|---|
| 담벼락 | 담벼락 |
| 운동장 | 운동장 |
| 경기 | 경기 |
| 승부예측 | 승부예측 |
| — | 타로 |
| (사용자 메뉴) | 마이 |

⚠️ 2026-08-25 이전 모바일 탭바에 **"경기"가 없었다.** 매치센터를 보는 동안 하단에서
현재 위치를 찾을 수 없었다. **GNB에 항목을 추가하면 탭바도 같이 본다.**

## CSS 안의 임의 미디어쿼리 (정리 대상)

TSX는 깨끗한데 CSS 파일에 비표준 지점이 남아 있다.

| 값 | 횟수 | 비고 |
|---|---:|---|
| `max-width: 760px` | 6 | 정리 대상 → `sm`(640) 또는 `md`(768) |
| `max-width: 980px` | 1 | 정리 대상 |
| `max-width: 860px` | 1 | 정리 대상 |
| `min-width: 640px` / `max-width: 640px` | 3 | ✅ `sm` 과 일치 |
| `min-width: 1024px` | 1 | ✅ `lg` 와 일치 |
| `prefers-reduced-motion` / `pointer: coarse` | 각 1 | ✅ 정상 (기능 쿼리) |

**지금은 안 고친다** — 이 값들은 특정 레이아웃에 맞춰 눈으로 조정된 것이라,
640/768로 옮기면 그 지점에서 레이아웃이 달라진다. 그건 systematize가 아니라 redesign이다.
**새 CSS는 640 / 768 / 1024만 쓴다.**
