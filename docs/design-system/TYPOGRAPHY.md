## 서체 — 셋. 역할이 다르다

| 역할 | 토큰 | 서체 | 쓰는 곳 |
|---|---|---|---|
| 본문 | `--font-pretendard` (Tailwind `font-sans` 기본) | Pretendard Variable | **거의 전부** |
| 디스플레이 | `--font-display-ko` | Aggro | 페이지 밴드 제목, 푸터 로고, 섹션 헤딩 |
| 숫자·키커 | `--font-cond` | Barlow Condensed | 스코어, 순위, 라틴 대문자 키커 |

**규칙: 별도 지정이 없으면 Pretendard다.** 서체를 바꾸려면 그 이유를 말할 수 있어야 한다.

⚠️ **SUIT은 이 시스템에 없다.** 2026-08-25 이전 `--font-title` 스택의 맨 앞이었는데,
실측하니 사이트 전체 텍스트 285개 중 **3개**만 SUIT으로 그려졌다 — 그것도 하필
홈 히어로 카드 제목(화면에서 제일 큰 자리)이었다. 3개면 서체 시스템이 아니라
**마이그레이션 잔재**다. "페이지마다 다른 사이트 같다"는 인상의 뿌리가 여기였다.
`--font-title`은 이제 Pretendard로 해석된다.

⚠️ 드래프트 게임(`--draft-font-title`)은 자체 스코프라 SUIT을 계속 쓴다. **의도된 분리**다.

### 라틴 키커 규약

`.gn-num` / Barlow Condensed 슬롯에는 **라틴만** 넣는다. 자간이 0.2em이라 한글이
들어가면 폴백 서체로 떨어지며 깨진다. 한글 라벨은 옆에 별도 요소로 둔다.

```tsx
// ✅ 키커는 라틴, 라벨은 한글
<span className="gn-num">LALIGA</span> <span>라리가</span>

// ❌ 한 슬롯에 한글
<span className="gn-num">라리가</span>
```

## 크기 스케일 — 8단계

2026-08-25에 **30종 → 8종**으로 정리했다.

| 이름 | px | 쓰는 곳 |
|---|---:|---|
| Caption | **12** | 배지, 메타, 타임스탬프, 리그 칩, VS |
| Body Small | **13** | 표 셀, 보조 설명, 사이드바 항목 |
| Body | **14** | 기본 본문, 목록 |
| Body Large / Title | **16** | 카드 제목, 강조 본문 |
| H3 | **20** | 서브 섹션 제목 |
| H2 | **26** | 섹션 제목 |
| H1 | **31** | 페이지 제목 |
| Hero | **42** | 밴드 대제목 |

**허용 값은 이 여덟 개뿐이다.** `text-[11px]`, `text-[15px]`, `text-[11.5px]` 전부 금지.

### 왜 11px을 버렸나

종전 최다 사용 크기가 **11px(홈에서만 124회)** 였다. 리그 배지·"VS" 같은 부속이라
작아도 된다고 판단했겠지만, 124번이면 그건 부속이 아니라 **화면의 질감**이다.
한글 11px은 읽히지 않는다. 전부 12px로 올렸다.

### 왜 0.5px 사다리를 버렸나

11 / 11.5 / 12 / 12.5 / 13 / 13.5 / 14 / 14.5 가 동시에 존재했다(299곳).
**사람이 11px과 11.5px을 눈으로 구분할 방법은 없다.** 스케일이 아니라 파편이었다.

> 방어를 시도했다가 반증됐다: "유동형 타이포(clamp)라 뷰포트마다 소수로 떨어지는 것"
> 이라 가정하고 1024px에서 다시 쟀는데 1440px과 목록이 **완전히 같았다**. 하드코딩이었다.

### 문서화된 예외

| px | 위치 | 사유 |
|---:|---|---|
| 9 | 포메이션 도면 선수 마커, `px-1.5` 마이크로 배지 | 본문이 아니라 **데이터 시각화 라벨**. 12px로 밀면 도면이 깨진다 |
| 56 / 64 / 68 | 매치 스코어, 404, 시즌 히어로 숫자 | 일회성 디스플레이 숫자. 수렴 대상이지만 **바꾸면 redesign** |

## 굵기

| weight | 이름 | 쓰는 곳 |
|---:|---|---|
| 400 | Regular | 긴 본문 |
| 500 | Medium | **기본 UI 텍스트** |
| 600 | Semibold | 약한 강조 |
| 700 | Bold | 제목, 강한 강조 |
| 800 | Extrabold | 밴드 대제목, 숫자 강조 |

### ⚠️ 미해결 — 700 남용

실측: 홈 화면 텍스트 285개 중 **191개(67%)가 weight 700**이다.
**전부 굵으면 아무것도 안 굵다.** 강조는 나머지가 얌전할 때만 성립한다.

**아직 고치지 않았다.** 191곳을 일괄 치환하면 사이트 인상이 한 번에 바뀌어
redesign이 된다. 대신 **새 코드는 아래 규칙을 따른다** — 기존 코드는 손댈 때마다 수렴.

> 제목 700 · 강조 600 · **기본 UI 500** · 긴 본문 400

`font-weight: 650`은 비표준처럼 보이지만 Pretendard가 **가변 폰트**라 정상 렌더된다.
사용처 2곳(홈 피드 제목·카드뉴스)은 의도된 선택이므로 **그대로 둔다.**

## 줄 간격 · 자간

| 상황 | 값 |
|---|---|
| 기본 body | `line-height: 1.6`, `letter-spacing: -0.01em` (globals.css) |
| 제목 | `leading-[1.25]` 안팎, `letter-spacing: -0.02em` |
| 라틴 키커 | `letter-spacing: 0.12em ~ 0.2em`, `uppercase` |
| 숫자 열 | `font-variant-numeric: tabular-nums` (`.gn-num` / `tabular-nums`) |

### 한글 조판 필수 규칙

```tsx
// 제목 — 줄바꿈 균형 (globals.css 에서 h1/h2/h3 에 자동 적용)
<h2 style={{ textWrap: "balance" }}>

// 긴 한글 문장 — 단어 중간에서 안 끊기게
<p style={{ wordBreak: "keep-all" }}>
```

## 미사용 토큰 (정리 대상)

`--wc-fs-hero` / `--wc-fs-h1` / `--wc-fs-h2` / `--wc-fs-eyebrow` 는 정의돼 있지만
**TSX에서 0회 사용**된다. 정의만 하고 전부 `text-[Npx]`로 우회한 결과다.

지우지 않고 남긴다 — 나중에 크기를 진짜 토큰화할 때 쓸 자리다. 다만 **지금은
스케일(위 8단계)이 정본**이니 이 토큰을 새로 끌어다 쓰지 말 것. 둘이 갈리면 또 드리프트다.
