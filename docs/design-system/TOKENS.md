## 그림자

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--wc-shadow-1` | `0 1px 3px rgba(20,20,40,.06)` + 1px 링 | 카드 기본 (실사용 89회) |
| `--wc-shadow-2` | `0 4px 16px rgba(24,18,21,.07)` + 링 | 떠 있는 패널 |
| `--wc-shadow-3` | `0 12px 40px rgba(119,22,41,.14)` + 링 | 모달·최상위 |

⚠️ 세 토큰 모두 **보더를 그림자에 내장**했다(`0 0 0 1px var(--wc-line)`).
그래서 그림자를 쓰면 보더를 따로 주지 않는다 — 주면 선이 두 겹이 된다.

Tailwind `shadow-*` 유틸도 웜 잉크 축(`rgba(24,18,21,…)`)으로 재정의돼 있다
(`globals.css` `@theme`). 순검정 그림자는 이 사이트에 없다.

## Radius

| 클래스 | 실제 값 | 쓰는 곳 |
|---|---|---|
| `rounded-sm` | 4px | 작은 칩·배지 |
| `rounded` / `rounded-md` / `rounded-lg` | **8px** | 기본 |
| `rounded-xl` | 12px | 카드 |
| `rounded-full` | 알약 | 필터 칩·아바타·FAB |

⚠️ **`rounded-md` 와 `rounded-lg` 는 현재 같은 값(8px)** 이다
(`--radius-md: var(--radius)`, `--radius-lg: var(--radius)`).
실사용 280곳이 서로 다른 의도로 쓰였는데 결과가 같다.

**지금은 고치지 않는다** — `rounded-lg`를 12px로 바꾸면 186곳의 외형이 한꺼번에
변한다. 이건 systematize 가 아니라 redesign 이다. 대신 **새 코드는 `rounded`(8px)와
`rounded-xl`(12px) 둘만 쓴다.** md/lg 는 레거시로 취급한다.

## Spacing

Tailwind 기본 스케일(4px 그리드)을 그대로 쓴다. 별도 토큰을 만들지 않는다.
실측상 임의값이 104곳뿐이라 **이 영역은 이미 건강하다** — 굳이 손대지 않는다.

자주 쓰는 값: `gap-1.5`(6) `gap-2`(8) `gap-3`(12) `gap-4`(16) ·
`p-3`(12) `p-4`(16) `px-4 py-3` · 섹션 간 `mt-8`(32)

## z-index

| 값 | 쓰는 곳 |
|---:|---|
| 0~2 | 카드 내부 레이어 (밴드 위 카드 등) |
| 30 | 홈 배너 오버레이 |
| 40 | FAB (글쓰기) |
| 50 | 헤더 (sticky), 모바일 탭바 |
| 100 | 스킵 링크 (포커스 시) |
| Radix portal | 모달·드롭다운 — 자체 레이어, 건드리지 않는다 |

⚠️ 새 값을 발명하지 말 것. 위 다섯 단계 안에서 고른다.
