# 컨텍스트

당신은 gongnori.fan 의 드래프트 게임 화면을 디자인합니다.

## 사이트 톤
- gongnori.fan 은 스포츠 + 컬처 통합 커뮤니티. NYT / Verge / Pitchfork 같은 에디토리얼 톤을 추구합니다.
- 디자인 시스템: 기존 `wc-*` 토큰 활용 (paper 그라디언트, burgundy `#a0203b` 메인 색, ink `#1a1416`, soft `#f4ece6`).
- 폰트: Pretendard (본문) + SUIT (제목 wght=700).
- 모바일 우선. 데스크톱은 col 3분할이 기본 패턴.
- 접근성 WCAG 2.1 AA 이상. CLS < 0.1 유지.

## 게임 본질
- 판타지 드래프트 — 한정된 예산으로 라인업을 짠다.
- **다종목** 지원: EPL 현역, 아스널 역대, 슬램덩크 캐릭터, 삼국지 무장, K-pop 그룹 등 5+개 게임이 같은 코드/UI 위에서 작동.
- 게임마다 포지션 / 라인업 사이즈 / 통화 / 포메이션이 다름:
  - EPL: 11명, GK/DF/MF/FW, 4-3-3, £80
  - 슬램덩크: 5명, PG/SG/SF/PF/C, positional, 100점
  - 삼국지: 5명, 군주/책사/맹장, roles, 80 충성도
- 모드: 솔로 vs AI (현재) / 멀티플레이어 (향후 PvP)
- **스네이크 드래프트**: 1→2→...→N→N→...→2→1 순환. 마지막 픽이 다음 라운드 첫 픽.

# 화면 1 — 게임 선택 (`/games/draft`)

## 목적
사용자가 어떤 드래프트 게임을 할지 고르는 진입 화면. 현재는 EPL 하나뿐이지만 곧 5+개 추가.

## 필요 요소
- 헤더: "드래프트 게임" 제목 + 짧은 설명 ("나만의 드림팀을 만들어 보세요")
- **게임 카드 그리드** (반응형 — 데스크톱 3-4 col / 태블릿 2 col / 모바일 1 col)
- 각 카드:
  - 이모지 + 게임명 (예: ⚽ EPL FPL 드래프트, 🔴 아스널 레전드, 🏀 슬램덩크 드림팀)
  - 한 줄 설명
  - 메타 정보 (라인업 사이즈, 예산, 후보 풀 크기, 평균 플레이 시간)
  - 테마 색상 (game_meta 의 `theme_color` 활용 — 카드 좌측 stripe 또는 hover 시 active border)
  - 플레이 수 / 인기도 배지 ("HOT", "NEW")
- 하단: "내 드래프트 기록" 링크 (지난 플레이 결과 보기)

## 인터랙션
- 카드 hover → 살짝 들리는 애니메이션 + theme color border
- 클릭 → 화면 2 (게임 설정) 로 라우팅 `/games/draft/{slug}/setup`
- 비활성 게임 (is_active=false) 은 "Coming soon" 배지 + 카드 dimmed

## 빈 상태
없음 — 최소 1개 게임 (EPL) 은 항상 존재.

# 화면 2 — 게임 설정 (`/games/draft/{slug}/setup`)

## 목적
드래프트 시작 전 옵션 선택. 현재 EPL 페이지가 이미 이 패턴 (스크린샷 참조 가능).

## 필요 요소

좌측 또는 상단 (모바일 stacked):
- 선택한 게임의 헤로 (이모지 + 이름 + 한 문장 설명)

설정 폼 (중앙):
- **게임 모드**
  - 솔로 (vs AI) — 활성
  - 멀티플레이어 — "준비 중" disabled
- **닉네임** (text input)
- **포메이션** (게임이 formation_options 지원 시)
  - EPL: 4-4-2 / 4-3-3 / 3-5-2 등 시각 카드
  - 슬램덩크: positional (포메이션 고정 — 이 필드 hide)
- **AI 상대 수** (1 / 2 / 3명 — pill buttons)
- **내 드래프트 순서** (1번째 / 2번째 / ... AI 수 + 1)
  - 1번째 = 첫 픽 빠름, 마지막 = 연속 2픽 유리 (snake)
- **규칙 요약** (접힌 카드)
  - 스네이크 순서 설명
  - 라운드 수
  - 포메이션별 포지션 슬롯
  - 픽 제한시간 (30초)

하단:
- 큰 버튼: "드래프트 시작!" (theme_color 적용)
- 작은 링크: "← 게임 선택으로"

## 인터랙션
- 포메이션 변경 시 포지션 슬롯 시각화 즉시 갱신 (예: 4-3-3 → 골키퍼 1, 수비 4, 미드 3, 공격 3 표시)
- 시작 버튼 클릭 → 화면 3 (드래프트 진행)

### 모바일 (< 768px)
탭 전환 또는 sticky 하단 nav:
- [선수 풀] / [내 라인업] / [참가자]
- 또는 좌측 슬라이드 drawer + 우측 슬라이드 drawer (메인은 라인업)

## 좌측 — 선수 풀

### 필터 (sticky 상단)
- **포지션 탭** (전체 / GK / DF / MF / FW) — pill buttons. 각 옆에 가능한 선수 수 표시 (예: "FW (14)")
- **검색바** — 이름 / 한글이름 부분 매치
- **고급 필터** (collapsible accordion):
  - 가격대 (slider, £1-£15)
  - 팀 / 시대 (multi-select, 예: 아스널 / Invincibles / 현역)
  - 추정값 (estimated=true 만 표시 / 제외)
  - 핀 표시 only
- **정렬** (dropdown 또는 segmented control):
  - 추천순 (기본 — 가치/가격 ratio)
  - 가격 ↓
  - 가격 ↑
  - 골 ↓ (게임이 goals attribute 가질 때)
  - 이름순

### 선수 카드 (리스트)
각 카드에 표시:
- 한글 이름 + 영문 (작게)
- 포지션 배지 (색 — position.color)
- 팀 + 시대 (작게)
- 가격 (오른쪽 큰 글씨)
- 능력치 mini visualization (작은 bar 또는 star)
- 액션 버튼:
  - "영입" (가능 시 — theme_color 강조)
  - "포지션 슬롯 가득참" (해당 포지션 max 도달)
  - "예산 초과" (못 사면 disabled + 빨간색)
  - "이미 누군가 픽함" (이름 + AI 표시)
- 우측 상단: 핀 아이콘 (즐겨찾기 — 다음 라운드 빠른 영입)
- 카드 클릭 → 상세 모달 (전체 stats, era, 설명, source)

### 비어있을 때
"조건에 맞는 선수가 없어요. 필터를 조정해보세요."

## 중앙 — 내 라인업 (핵심 시각화)

포메이션 모양으로 배치:
- 4-3-3 → 위 3 공격, 중 3 미드, 아래 4 수비, 맨아래 1 골키퍼
- 5-out → 5개 슬롯 horizontal (basketball)
- roles → 3 영역 (군주 / 책사 / 맹장) box 형식 (삼국지)

빈 슬롯:
- 점선 outline + "?" + 포지션명 ("골키퍼 영입 필요")
- 클릭 시 좌측 필터를 해당 포지션으로 자동 설정

채워진 슬롯:
- 선수 카드 미니 (얼굴 / 이미지 placeholder + 이름 + 가격)
- X 버튼 (해제 — 비싸지 않게, 확인 모달 X, 바로 undo 가능)

하단 메타:
- 예산: £80 / 사용 £42 / 남은 £38 (progress bar — theme_color)
- 평균 tier (예: B+ avg)
- "이 라인업 강점": 자동 분석 ("공격 강력, 수비 약함")
- 현재 raster size (예: 5/11)

## 우측 — 다른 참가자 (AI)

각 참가자 카드 (컴팩트):
- 닉네임 (AI는 "AI 1", "AI 2" 등)
- 진행률 (4/11)
- 픽한 선수 리스트 (작은 리스트, 최근 픽 강조)
- 예산 사용량 (작은 bar)
- 현재 픽 중인 참가자는 강조 (theme_color border + 펄스 애니메이션)

## 상단 바
- **타이머**: 30초 카운트다운. 5초 남으면 빨간색 + 진동/사운드 (옵션)
- **Snake 순서 시각화**: ● ● ○ ○ ○ ● ● (마름모/원, 현재 픽 = 큰 동그라미, 지나간 픽 = 채워진, 다음 = 비어있음)
- **현재 픽**: "Pick 12 / 44" + "당신 차례입니다" / "AI 2 가 픽 중..."
- **종료 버튼** (확인 모달 후 결과 화면으로 — 미완성 라인업이라도)

## 인터랙션 / 애니메이션
- 영입 클릭 → 선수 카드가 라인업 슬롯으로 날아가는 애니메이션 (200ms 이내)
- AI 픽 진행 → 좌측 풀에서 해당 선수 fade out + 우측 AI 라인업에 추가
- 타이머 0 도달 → 자동 픽 (추천 selection 자동) + "자동 픽 — Henry 영입됨" toast
- 픽 완료 → 다음 픽 표시 + Snake order 갱신

## 빈 상태
드래프트 시작 직후 — 양쪽 라인업 비어있음. "첫 픽을 선택하세요" CTA.

# 화면 4 — 결과 / 라인업 분석

## 목적
드래프트 완료 후 내 라인업과 AI 라인업 비교. 만족감 / 공유 욕구 유도.

## 레이아웃

### 헤로
- 큰 그라디언트 배너 (theme_color)
- "드래프트 완료!" + 게임명
- 소요 시간 (예: "4분 23초")

### 라인업 비교 (탭 또는 carousel)
- 내 팀 (default 활성)
- AI 1
- AI 2
- AI 3

각 탭에서:
- 포메이션 시각화 (화면 3 의 중앙과 동일 — 단 read-only)
- 총 가격 / 예산 / 남은 예산
- **평점 카드**:
  - 전체 점수 (0-100)
  - 카테고리별 (공격 / 미드 / 수비 / 골키퍼 평점)
  - 강점 1-2개 (예: "S급 공격수 보유")
  - 약점 1-2개 (예: "센터백 가격 낮음")

### 매치업 결과 (선택 — 사용자 / 환경에 따라)
- "시즌 시뮬레이션 결과" (programmatic Game Balance Simulator 가 N회 돌린 결과)
  - 1위: AI 2 (회별 우승 횟수 / 12)
  - 2위: 내 팀 (4/12)
  - ...
- "1:1 매치업 결과" (AI 1 vs AI 2 vs 나 vs AI 3 라운드 로빈)

### 라인업 카드 자동 생성 (공유용)
- 큰 이미지 카드 (1200×630 — Open Graph 사이즈)
- 포메이션 + 선수 이름 + 점수
- 하단 "gongnori.fan 에서 만들기" workmark
- 다운로드 버튼 / 공유 버튼

### 하단 액션
- **공유 카드 생성** → 화면 5
- **이 라인업 저장** (계정 있으면)
- **다시 드래프트** → 화면 1 또는 2
- **커뮤니티 라운드 갤러리** → 화면 6

# 화면 5 — 공유 카드 (`/games/draft/share/{share_id}`)

## 목적
SNS / 메신저로 공유. 다른 사용자가 클릭하면 진입.

## 레이아웃

### 첫 화면 (Open Graph)
- 라인업 카드 (큰 이미지)
- 작성자 닉네임 + 시간
- 게임명 + 점수

### 액션
- "이 라인업 보기" → 풀 결과 화면 (read-only)
- "내 라인업과 비교" → 화면 3 진입 (해당 게임 / 같은 설정)
- "좋아요" (회원만)
- "댓글" (회원만 — 가벼운 코멘트)

## 카드 디자인 detail
- 게임 theme_color 메인
- 포메이션 그래픽 SVG
- 선수 이름 list (포지션별 그룹)
- "{닉네임} 의 드림팀" 큰 글씨
- 총 가격 / 점수 / 강점 한 줄
- gongnori.fan 워크마크 (작게, 우측 하단)

# 화면 6 — 커뮤니티 / 베스트 드래프트

## 목적
다른 사용자의 라인업 둘러보기. 투표 / 좋아요 / 댓글로 engagement. 매주 베스트 발굴.

## 레이아웃

### 상단 — 게임별 필터
- 게임 탭 (EPL / 아스널 / 슬램덩크 / 삼국지 ...)
- 정렬: 최신 / 좋아요 / 댓글 / 매치업 승률

### 메인 — 라인업 카드 그리드 (반응형)
각 카드:
- 라인업 그래픽 mini (포메이션 시각화)
- 작성자 닉네임 + avatar
- 게임 이모지 + 점수
- 좋아요 수 / 댓글 수
- "투표" 버튼 (옵션)

### "오늘의 매치업" 섹션 (1:1 투표)
- 두 라인업 좌우 비교
- "어떤 팀이 더 강한가?" 투표
- 결과 % 표시 (투표 후만)
- 매일 자정 리셋
- 우승한 라인업 작성자에게 카르마 보상 (gongnori.fan 의 fan score 시스템과 연동)

# 필터 / 검색 — 패턴

## 기본 원칙
- **첫 화면에 핵심 필터 (포지션 / 검색) 항상 보임**
- 고급 필터는 accordion / drawer 로 숨김
- 필터 적용 시 결과 즉시 갱신 (300ms debounce)
- 적용된 필터 chip 표시 (각각 X 로 제거 가능)
- "초기화" 링크 (모든 필터 해제)

## 모바일 패턴
- 필터 버튼 (FAB 또는 sticky bottom) → bottom sheet drawer
- 검색바는 상단 sticky
- 적용된 필터 갯수 배지 (예: "필터 3")

# 디자인 시스템 통합

## 색상 (반드시 사용)
- 메인: `var(--wc-burgundy)` (#a0203b)
- 배경: `var(--wc-paper)` (#fbf6f0)
- 카드: `var(--wc-card)` (#ffffff)
- ink: `var(--wc-ink)` (#1a1416)
- soft: `var(--wc-soft)` (#f4ece6)
- mute: `var(--wc-mute)` (#807370)

게임별 theme_color 는 카드 stripe / hover border / 강조 element 에만. 메인 색은 전역 burgundy 유지.

## 폰트
- 제목: `font-title` (SUIT 700)
- 본문: `font-body` (Pretendard)
- 숫자 (가격, 점수): tabular numerals (`tabular-nums` Tailwind class)

## Shadow / Radius
- `var(--wc-shadow-1)` 카드, `var(--wc-shadow-2)` hover
- radius `rounded-lg` 기본, 큰 컨테이너는 `rounded-xl`

## 애니메이션
- 200-300ms ease-out 기본
- hover lift: `-translate-y-0.5`
- 펄스 (현재 픽): `animate-pulse`
- 영입 애니메이션: 200-400ms spring

## 접근성
- 모든 인터랙티브 element 키보드 navigable
- 포커스 outline 명시 (burgundy 2px)
- 색맹 대응: 포지션 색에 의존하지 말고 텍스트 라벨 병기
- 스크린리더: 픽 진행 / 타이머 라이브 region 처리

# Edge cases / 상태

1. **로딩**: 게임 데이터 fetch 중 → skeleton 카드 (포메이션 모양 점선)
2. **에러**: 데이터 로드 실패 → 친절한 메시지 + 재시도 버튼
3. **타이머 0**: 자동 픽 (best available by tier) + toast 알림
4. **모든 포지션 채움 + 예산 남음**: "라인업 완성! 드래프트 종료 → 결과 보기"
5. **예산 초과 임박**: 영입 버튼 옆 경고 ("£3 남음 — 다음 픽 신중히")
6. **선수 풀 비어있음** (모든 영입 가능 선수 픽됨): 다음 라운드 자동 진행
7. **모바일 회전**: landscape 도 대응 (특히 결과 화면)
8. **인증 X**: 게임 자체는 가능. 저장 / 공유 / 투표는 로그인 prompt
