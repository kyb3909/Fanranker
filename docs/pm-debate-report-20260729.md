## 1. Executive Summary

- 이 제품은 현재 **커뮤니티로서가 아니라 예측 도구로서 팔리고 있다** — 최고 반응 세그먼트는 프로토 실유저("합법·무료 연습장+공개 성적표"), 최악 반응은 기존 커뮤니티 정착민.
- 치명적 약점은 **재소환 채널 0**: 알림·카톡·푸시가 없어 모든 유입이 소모품이 되며, 방치 시 8월 유튜버 홍보는 월드컵 이벤트(스파이크→증발)의 재판이 된다.
- Aha Moment는 2단계 — "슬립 제출→픽 분포 비교(D0)"와 "적중 결과가 기록으로 쌓임(D+1)". 이 사이를 잇는 다리(적중 알림)가 최우선 과제.
- 그로스 전략 (운영자 확정 반영): **1채널(아스날) 검증은 완료**된 상태. 다음 수는 **Cog 채널 동시 공략** — 리버풀 팬과 첼시 팬이 공동 운영하고 각자 개인 채널도 보유해, 한 번의 이벤트로 **리버풀·첼시 팬덤이 3개 채널을 통해 동시 유입**된다. 단일 팬덤 편중은 커뮤니티의 치열함(라이벌 구도)을 죽이므로, **양 팬덤 동시 유입 → 팬덤 대항전 구도**가 활약도 설계의 핵심. + 개막 빅매치 **경기 스레드 올인**(유튜버 실참여 계약 조건부) + 프로토 유저는 제품 자력 유인.
- 착수 전 전제조건: **계측 복구** (board_view 死·코호트 측정 불가 상태로는 Go/No-Go 판정 자체가 불가능).

## 6. 그로스 전략 + Go/No-Go

- **타겟**: 주 = 유튜버 채널 팬덤(빅클럽 팬 중 커뮤니티 미정착 20대). 부 = 프로토 유저(광고 금지 — 제품 자력 유인. 도달 채널이 음지라 브랜드 리스크).
- **채널 전략 (운영자 확정)**: 아스날 1채널 검증 완료 → 다음 = **Cog 채널** (리버풀 팬 + 첼시 팬 공동 운영, 각자 개인 채널 보유). Cog 한 곳과의 이벤트로 **본채널 + 개인 채널 2개 = 3채널 구독자 동시 유입**. 설계 의도: 단일 팬덤만 들어오면 대결의 치열함이 죽는다 — **리버풀 vs 첼시 양 팬덤 동시 유입으로 라이벌 대항 구도**를 만든다. 토론에서 나온 "순차 집행" 권고는 이 구도로 대체 — 단, 레드의 밀도 경고는 유효하므로 **양 팬덤이 각자 자기 구역(리버풀·첼시 게시판)이 아니라 서로 부딪히는 한 판(대항전·경기 스레드)에서 만나게** 동선을 설계할 것.
- **콜드스타트**: "좁게 빽빽하게" — 개막 주 빅매치 경기 스레드에 올인, **유튜버 본인 실시간 참여를 협찬 계약 조건에 포함**(P2-03 재소환: "유튜버가 직접 떠들면 걔 보러는 감"). 리버풀·첼시 팬덤 대항전(월드컵 이벤트 포맷 재사용 — 팬덤 등록→예측 대결→팬덤 현황판)이 이상적인 "한 판". 운영 윤리: 유저 위장 봇 금지, 봇은 공식 계정으로.
- **보조 채널**: 자체 디스코드 + X(이적시장 카드). 펨코·디시 직접/잠입 홍보 금지.
- **Go/No-Go (개막 D+30 ≈ 9/20)**:

| 지표 | Go | No-Go 트리거 |
|---|---|---|
| 유튜버 코호트 D7 | ≥15% | <8% → 후속 채널 집행 중단 |
| 주간 슬립 제출 유저 | ≥300 | <120 |
| 예측→담벼락 클릭 | ≥5% (현 1%) | 무개선 → F16 계열 중단 |
| 빅매치 스레드 동시 참여 | ≥50 | <15 → 스레드 확장 보류, 예측 단일 루프 축소 피벗 검토 |
