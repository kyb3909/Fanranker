# 기사 데스킹 탐색

`/admin/news-review/desk`에서는 대기함의 실제 기사를 연속으로 검수한다.

- 준비된 기사가 있으면 전체 기사 검색은 접어두고 편집기를 먼저 보여준다.
- 기사 위에는 이전 기사, 다음 기사, 현재 대기 건수를 표시한다.
- 편집기의 하단 작업 막대에서 수정 저장 또는 검수 완료·다음을 실행한다. 검수 완료는 공개 발행을 하지 않는다.
- 대기함에서 고른 기사도 검수 완료·다음으로 이어갈 수 있다. 저장 실패 시 입력과 현재 기사를 유지한다.
- 저장 중에는 목록과 이전·다음 이동을 잠근다. 저장하지 않은 내용이 있으면 이동 전에 확인한다.
- 저장으로 바뀌는 수정 시각 대신 데스킹에 들어온 시각으로 작업 순서를 유지한다. 다음 대상은 미완료 기사이며, 이전 이동으로 방금 검수한 기사도 다시 볼 수 있다.
- 선택한 기사 ID를 주소의 `item`에 보관해 새로고침과 링크 공유 후 같은 기사를 연다.

기존 Button, Textarea와 카드·색상 토큰을 사용한다. 작업 목록은 데스크톱에서 고정되고 모바일에서는 높이를 줄여 본문에 빨리 도달하게 한다. 기사 전환 시 편집기 시작으로 스크롤하고 초점을 옮긴다.
