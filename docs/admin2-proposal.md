# /admin2 — 새 운영 작업대 (검토용)

기존 `/admin` 은 **그대로 둔다.** `/admin2` 를 보고 판단한 뒤 교체 여부를 정한다.

## 왜 만들었나 — 실측 근거

| 발견 | 수치 |
|---|---|
| 관리자 페이지 | **27개**, 실제 admin **1명**, 모더레이터 0명 |
| 매일 하는 일 | 사실상 **AI 검수 1가지** (나머지 큐는 대부분 0건) |
| 그런데 검수 메뉴 위치 | 접힌 그룹 안 **12번째** — 가장 깊은 곳 |
| 검수 대기 | 뉴스 **143건** + 커뮤글 **31건** |
| 스캐너 생산 vs 발행 | 약 47건/일 생산, 발행 0~24건/일 → 나머지 48h 후 자동 소멸 |
| 최근 7일 봇 기사 성과 | 52건, 평균 조회 **0.7** / 댓글 0 / 추천 0 |
| 3~5월 이후 손 안 댄 페이지 | operations · stats · settlements · matches · notes · analytics · experts |

### 결정적 결함 2개 (기존 admin)

1. **대기 건수 뱃지가 사실상 안 보인다.** 뱃지 렌더 코드가 접이식 그룹 분기에만 있고
   (`admin-sidebar.tsx` 241–245), 평면 메뉴 분기(176–195)엔 없다. 게다가 뱃지 달린 5개가
   전부 접이식 그룹 소속인데 `/admin` 에서는 그 그룹이 닫혀 있다 →
   **"지금 처리할 게 있나"를 사이드바에서 알 수 없다.**
2. **대시보드와 운영 모니터링이 같은 화면이다.** 동일 API(`/api/admin/operations/dashboard`),
   동일 4종 알림, 동일 링크. 색상·문구만 다르다. 사이드바 뱃지까지 하면 한 엔드포인트를 3곳에서 폴링.

또한 검수 대기 큐(뉴스 143·커뮤글 31)에는 **뱃지가 아예 없어** 어디서도 보이지 않았다.

## /admin2 의 구조 — 단일 화면

운영자가 실제로 묻는 3가지 순서 그대로 배치했다 (사용자 지정 우선순위).

```
① 자동으로 도는 것        ← "크롤링에 오류 났나?"
   ● 승부예측 경기 크롤링   정상   마지막 확인 6분 전 · 최신 경기 등록 13시간 전
   ● AI 뉴스 수집(스캐너)   정상   마지막 초안 유입 40분 전 · 24시간 유입 47건
   ● AI 기사 발행           정상   마지막 발행 5분 전 · 24시간 발행 9건
   ● 뉴스 티커 크롤러       정상   마지막 갱신 1.6시간 전

② 내가 처리할 것          ← "신고·검수 들어온 거 있나?"
   [143] AI 뉴스 검수    48시간 지나면 자동 만료된다        처리 →
   [ 31] AI 커뮤글 검수                                     처리 →
   [  3] 미정산 슬립     15분 크론이 대부분 자동 처리       처리 →
   비어 있음: 신고 · 메타버스 신고 · 환불 큐 · 스티커 승인

③ 돈 정합성 경고          ← 문제 있을 때만 나타남
   (현재 이상 없음 — 카드 자체가 안 보임)

24시간: 기사 발행 9건 · 신규 초안 유입 47건
가끔 여는 곳: 사용자 · 정산 · 경기 · 게시글 · 설문 · 시스템 · 통계
```

### 설계 원칙

- **0건인 큐는 화면에서 사라진다** — 한 줄로 접어 "비어 있음: …" 으로만 표시.
  없는 일을 매일 쳐다보지 않게 한다.
- **할 일이 없으면 그렇다고 말한다** — 전부 정상이면 초록 배너로
  "오늘 처리할 일이 없습니다". 1인 운영에서 *안 들어와도 되는 날*을 아는 건 큰 가치다.
- **상태 판정을 서버가 한다** — 화면은 색만 칠한다. 임계값 근거는 API 주석에 기록
  (betman 3h/6h, 스캐너 4h/10h, 티커 2h/6h — 각 파이프라인 실제 주기 기반).
- **문제일 때만 힌트가 나온다** — 예: betman 지연이면 "Vultr /opt/betman/sync.sh 확인".
- **노동의 산출을 항상 보여준다** — 하단 24시간 발행 건수. 검수가 성과로 이어지는지
  매일 눈에 띄게 한다 (평균 조회 0.7 문제를 숨기지 않음).

## 기술 메모

- `app/admin2/` (layout · page · workbench) + `app/api/admin2/dashboard/route.ts`
- 데이터 소스 하나로 통합, 30초 폴링 (기존은 60초 × 3곳)
- 보호: 미들웨어 `adminGuard` 가 `/admin(.*)` 로 `/admin2` 도 커버 + layout `requireAdmin()` +
  API `requireAdminApi()` 3중
- 기존 `/admin` 코드는 **한 줄도 건드리지 않았다** — 언제든 되돌릴 수 있다
- 링크는 전부 기존 페이지로 연결 (검수·정산 등 실제 작업 화면은 그대로 재사용)

## 아직 안 한 것 (검토 후 결정)

| 항목 | 내용 | 규모 |
|---|---|---|
| 검수 화면 개선 | 일괄 반려 · 키보드 단축키(J/K/P/R) · 50건 제한 해제 | 1일 |
| `editor` 권한 | 돈 버튼 없이 검수만 위임 — 현재 moderator 는 admin 패널 진입 자체가 불가 | 1일 |
| 돈 버튼 안전장치 | 일괄 정산 확인창 · 환불 resolve 지급확인 · adjust-economy 음수 클램프 | 반나절 |
| 고아 라우트 | `/admin/event` 는 사이드바에 없음 — 노출 또는 정리 | 10분 |

## 교체 방법 (승인 시)

1. `/admin2` → `/admin` 으로 경로 이동, 기존 대시보드를 이 작업대로 교체
2. 사이드바는 3그룹(매일 / 가끔 / 설정·기록)으로 재편하고 뱃지 렌더 버그 수정
3. `/admin/operations` 는 작업대에 흡수 (중복이므로 제거)
