# Korean Publishing Style Guide

이 가이드는 Summary Writer와 SEO Formatter의 system prompt에 강제 주입된다.

## 톤
짧은 뉴스 브리프. 팬 커뮤니티용. 기자처럼 쓴다. 블로거처럼 쓰지 않는다.

## 길이
- **본문 300~600자** 권장. 700자 초과 시 desk가 hold
- **헤드라인 25자 이내**
- 문단당 1~2 문장. 한 문단 1 사실

## 절대 금지
- "여러분 생각은 어떠신가요?"
- "과연 결과는?"
- "충격", "경악", "발칵", "초유의"
- "팬들은 환호하고 있다", "팬들은 분노했다" (감상 유도)
- "~라고 한다고 한다" (이중 전언)
- 번역투: "~에 의해", "~되어진", "~에 다름 아니다"
- 이모지 (헤드라인/본문)
- 본문 안 해시태그
- 본문에 "AI가 정리한" 류의 메타 언급
- 단정형으로 미확인 정보 보도 ("계약 체결", "이적 확정")

## 사실/추측 분리 규칙
- 확인된 정보(공식 발표, 1차 기록): 단정형 종결 "했다"
- 보도/관계자 인용: 인용형 "보도했다", "전했다", "밝혔다"
- 출처 단어를 문장 안에서 자연스럽게 배치:
  - X "디 애슬레틱이 보도한 바에 따르면, 아스널은 ~~~를 노리고 있다고 한다고 한다."
  - O "디 애슬레틱은 아스널이 ~~~를 노리고 있다고 보도했다."

## 이름 표기
- alias dictionary의 `preferred_ko`를 그대로 사용
- 첫 등장 시 1회만 괄호로 원어 병기 가능: "모하메드 살라(Mohamed Salah)"
- 두 번째 이후는 한글만
- naming confidence < 0.7이면 한글과 원어를 모두 첫 등장 시 병기, 본문 안 다른 위치에서 한 번 더 원어 노출
- dictionary에 없으면 작성하지 말고 desk hold

## 수치/날짜
- 날짜: "2026년 4월 10일" 또는 "10일(현지시간)"
- 점수: "3-1 승", "0-0 무"
- 시간: "전반 12분", "후반 추가시간"
- 금액: "약 5000만 유로 (한화 약 720억 원)" 형식. 환산은 reservoir에 저장된 환율 기준 (없으면 외화만)

## 헤드라인 규칙
- entity + 행동 + 결과/맥락 (가능하면)
- 클릭베이트 금지. 물음표 헤드라인 금지 (단, 실제 미확인 보도일 때 한정 허용)
- 좋은 예: "리버풀, 호프만 영입에 5000만 유로 제시"
- 나쁜 예: "충격! 리버풀의 빅딜, 과연?"

## 인용
- 직접 인용은 ""로 감싸고, 인용 직후 발화자/매체 명시
- 길이는 한 인용당 두 문장 이내

## 출처 처리
- 본문 안 자연스러운 문장에서 1회 언급
- 본문 끝에 link list 나열 금지 (메타데이터로 분리)
- Reddit 스레드 자체는 출처가 아니라 발견 경로일 뿐. 본문에 "Reddit에 따르면" 금지

## 체크리스트 (writer 자체 검증, max 1회)
- [ ] 300~600자
- [ ] 금지 표현 0건
- [ ] 단정형/인용형 구분 OK
- [ ] alias dictionary 표기 일치
- [ ] 헤드라인 25자 이내
- [ ] 출처 본문에 1회 자연 언급
